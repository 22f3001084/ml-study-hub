The one-minute story

Think of it like this

Picture a huge room of tiny voters. Each voter looks at a few numbers, decides how much to trust each one, adds up their opinion, and then gives a "how excited am I?" answer between low and high. Their answers are passed to a second row of voters, who weigh those answers in the same way, and so on, until a final row announces "this photo is a cat (92%)".

That room is a neural network. Each voter is a neuron; each row is a layer. A single neuron is just logistic regression from last week. Stacking layers lets the network build complicated features out of simple ones: edges, then shapes, then faces.

Training means starting with random trust levels (weights) and nudging them: show an example, see how wrong the answer was, and send the blame backwards through the network (backpropagation) to see how each weight should change. Repeat many times: that is gradient descent.

By the end of this week you can:

  • describe a neuron, activation functions, and a layer;
  • run a forward pass and count parameters;
  • use softmax and cross-entropy for multiclass classification;
  • explain backpropagation as the chain rule and do a small example;
  • list practical issues: overfitting, vanishing gradients, learning rate.

  • Activation function ggg - the non-linear "squish".

Why non-linear? If ggg were just the identity, then two layers compute W2(W1x)=(W2W1)xW_2(W_1\mathbf x)=(W_2W_1)\mathbf xW2​(W1​x)=(W2​W1​)x, which is one linear layer. Stacking would add nothing. Non-linear activations are what let depth create richer and richer functions.

Idea 2: Layers and the forward pass

For a layer with weight matrix WWW (one row per neuron), bias vector b\mathbf bb and activation ggg applied entry by entry:

h=g(Wx+b)\mathbf h=g(W\mathbf x+\mathbf b)h=g(Wx+b)

and the next layer takes h\mathbf hh as its input.

Idea 3: Multiclass output with softmax

For KKK classes, the output layer has KKK neurons producing scores (logits) z1,…,zKz_1,\dots,z_Kz1​,…,zK​. Softmax turns them into probabilities:

pk=ezk∑jezjp_k=\frac{e^{z_k}}{\sum_je^{z_j}}pk​=∑j​ezj​ezk​​

(All positive, adding to 1; the biggest score gets the biggest share.) The loss is the cross-entropy: −ln⁡py-\ln p_{y}−lnpy​ where yyy is the true class (with one-hot labels, −∑kykln⁡pk-\sum_ky_k\ln p_k−∑k​yk​lnpk​). With K=2K=2K=2 this is the logistic loss of week 9.

Idea 4: Training and backpropagation

Define a loss LLL (squared error for regression, cross-entropy for classification), then run gradient descent on all weights:

w←w−η ∂L∂ww\leftarrow w-\eta\,\frac{\partial L}{\partial w}w←w−η∂w∂L​

The gradients come from the chain rule (MLF week 2). Backpropagation is simply an efficient bookkeeping of it: compute everything forward and remember the intermediate values, then walk backwards from the loss, multiplying local derivatives and reusing results, so one backward pass yields all the gradients.

Idea 5: Practical matters

  • Non-convex: the loss surface has many local minima and saddles, so results depend on the random start (weights are initialised randomly, not to zero: if all weights start equal, all neurons in a layer stay identical).
  • Mini-batch SGD with a sensible learning rate (too big diverges, too small crawls).
  • Vanishing gradients: with sigmoid/tanh in deep nets, gradients multiply many numbers below 1 and shrink to nothing; ReLU helps.
  • Overfitting: networks have huge numbers of parameters and can memorise the training data. Remedies: more data, weight decay (an ℓ2\ell_2ℓ2​ penalty, as in ridge), early stopping (stop when validation error rises), dropout.
  • Universal approximation: even one hidden layer with enough neurons can approximate any reasonable function; depth makes it far more efficient.
  • Scale your inputs before training.

Watch out - real exam trap
  • Count the biases too: mn+nmn+nmn+n per layer.
  • Without non-linear activations, depth adds nothing.
  • Softmax outputs sum to 1; sigmoid outputs do not need to.
  • Do not initialise all weights to the same value.
  • Sigmoid derivative is σ(z)(1−σ(z))≤0.25\sigma(z)(1-\sigma(z))\le0.25σ(z)(1−σ(z))≤0.25, which is why deep sigmoid nets suffer vanishing gradients.
