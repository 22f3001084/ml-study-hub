The one-minute story

Think of it like this

Spread red and green marbles on a table and try to lay a straight stick between them so all the reds are on one side and all the greens on the other. That stick is a linear classifier, and the whole job is to find it.

The perceptron is a very simple teacher. Start with any stick. Pick up one marble at a time; if it is on the wrong side, nudge the stick a little towards the right side for that marble. Keep going round until nobody is on the wrong side. If a straight stick can separate the marbles, this is guaranteed to work.

Logistic regression is a gentler teacher. Instead of a hard "this side / that side", it gives a probability: far on the red side means "99% red", right on the stick means "50/50". Instead of nudging only on mistakes, it nudges a little for every marble, in proportion to how wrong the probability was.

Both are discriminative: they learn the boundary directly and never model what the marbles look like.

By the end of this week you can:

  • describe a linear classifier and its decision boundary;
  • run the perceptron algorithm by hand and state its convergence theorem;
  • write the logistic regression model, loss and gradient;
  • compare the perceptron and logistic regression.

Idea 1: Linear classifiers

Predict y^=sign⁡(wTx+b)\hat y=\operatorname{sign}(\mathbf w^T\mathbf x+b)y^​=sign(wTx+b). The weight vector w\mathbf ww is perpendicular to the boundary and points towards the positive side. The value wTx+b\mathbf w^T\mathbf x+bwTx+b says which side and, divided by ∥w∥\|\mathbf w\|∥w∥, how far from the boundary.

A trick to avoid carrying bbb around: add a constant feature 1 to every x\mathbf xx and absorb bbb into w\mathbf ww. Then the prediction is just sign⁡(wTx)\operatorname{sign}(\mathbf w^T\mathbf x)sign(wTx).

A point (x,y)(\mathbf x,y)(x,y) with y∈{±1}y\in\{\pm1\}y∈{±1} is classified correctly exactly when y wTx>0y\,\mathbf w^T\mathbf x>0ywTx>0.

Idea 2: The perceptron algorithm

The idea

Perceptron (labels y∈{−1,+1}y\in\{-1,+1\}y∈{−1,+1}, bias absorbed):

  1. Start with w=0\mathbf w=\mathbf 0w=0.
  2. Go through the training examples. For each (x,y)(\mathbf x,y)(x,y): if y wTx≤0y\,\mathbf w^T\mathbf x\le0ywTx≤0 (a mistake), update
w←w+y x\mathbf w\leftarrow\mathbf w+y\,\mathbf xw←w+yx
  1. Repeat passes over the data until a full pass makes no mistakes.

Why does the update help? After the update the new score for that same example is y(w+yx)Tx=ywTx+∥x∥2y(\mathbf w+y\mathbf x)^T\mathbf x=y\mathbf w^T\mathbf x+\|\mathbf x\|^2y(w+yx)Tx=ywTx+∥x∥2, which is larger by ∥x∥2>0\|\mathbf x\|^2>0∥x∥2>0. So the mistake gets less wrong (it may still need more nudges).

Convergence theorem. If the data is linearly separable with margin γ\gammaγ (every point is at least γ\gammaγ from some separating boundary, with ∥w∗∥=1\|\mathbf w^*\|=1∥w∗∥=1) and every ∥x∥≤R\|\mathbf x\|\le R∥x∥≤R, then the perceptron makes at most (R/γ)2(R/\gamma)^2(R/γ)2 mistakes and stops. If the data is not linearly separable (the classic example: XOR), it never converges, cycling forever. Also, the solution it finds is not unique: it depends on the order of the data.

Idea 3: Logistic regression

Instead of a hard sign, model the probability of class 1:

P(y=1∣x)=σ(wTx)=11+e−wTxP(y=1\mid\mathbf x)=\sigma(\mathbf w^T\mathbf x)=\frac1{1+e^{-\mathbf w^T\mathbf x}}P(y=1∣x)=σ(wTx)=1+e−wTx1​

Equivalently, the log-odds are linear: ln⁡P(y=1∣x)P(y=0∣x)=wTx\ln\dfrac{P(y=1\mid\mathbf x)}{P(y=0\mid\mathbf x)}=\mathbf w^T\mathbf xlnP(y=0∣x)P(y=1∣x)​=wTx. The class is predicted as 1 when P>0.5P>0.5P>0.5, i.e. wTx>0\mathbf w^T\mathbf x>0wTx>0, so the decision boundary is still the straight line wTx=0\mathbf w^T\mathbf x=0wTx=0.

Try it yourself

Slide www and bbb to bend and shift the S-curve through the data. The dashed vertical line is the decision boundary, where the probability is 0.5.

Training by maximum likelihood. With labels yi∈{0,1}y_i\in\{0,1\}yi​∈{0,1} the likelihood of the data is ∏piyi(1−pi)1−yi\prod p_i^{y_i}(1-p_i)^{1-y_i}∏piyi​​(1−pi​)1−yi​ with pi=σ(wTxi)p_i=\sigma(\mathbf w^T\mathbf x_i)pi​=σ(wTxi​). Taking the negative log gives the cross-entropy (log) loss:

L(w)=−∑i=1n[yiln⁡pi+(1−yi)ln⁡(1−pi)]\mathcal L(\mathbf w)=-\sum_{i=1}^n\Big[y_i\ln p_i+(1-y_i)\ln(1-p_i)\Big]L(w)=−i=1∑n​[yi​lnpi​+(1−yi​)ln(1−pi​)]

It is convex with a lovely gradient:

∇L(w)=∑i=1n(pi−yi) xi\nabla\mathcal L(\mathbf w)=\sum_{i=1}^n(p_i-y_i)\,\mathbf x_i∇L(w)=i=1∑n​(pi​−yi​)xi​

("prediction minus truth, times the input"). There is no closed-form solution, so use gradient descent: w←w−η∑i(pi−yi)xi\mathbf w\leftarrow\mathbf w-\eta\sum_i(p_i-y_i)\mathbf x_iw←w−η∑i​(pi​−yi​)xi​.

Extras. If the classes are perfectly separable the likelihood keeps improving as ∥w∥→∞\|\mathbf w\|\to\infty∥w∥→∞, so add a regulariser λ∥w∥2\lambda\|\mathbf w\|^2λ∥w∥2 (as in ridge) to keep w\mathbf ww finite. For more than two classes, replace the sigmoid with softmax (week 12).

Watch out - real exam trap
  • Perceptron labels are ±1\pm1±1; logistic labels are 0/10/10/1. The gradient formula (pi−yi)xi(p_i-y_i)\mathbf x_i(pi​−yi​)xi​ assumes 0/10/10/1.
  • Update w+yx\mathbf w+y\mathbf xw+yx only on a mistake (including the "score =0=0=0" case).
  • Don't forget the bias: add a feature of 1.
  • The perceptron solution is not unique; logistic regression's is (when regularised).
  • Linearly separable is required for perceptron convergence, not for logistic regression to run.
