Read the words of the video
  1. Imagine a tiny dot drawn on paper, surrounded by a big ring. Can you draw a straight line to separate the dot from the ring? No matter where you draw, the line will always cut through the ring, right? That’s because simple lines can’t do curvy jobs.
  2. Now, gently push the paper's middle down, forming a bowl shape. See? The ring goes high, and the dot settles at the bottom. A simple, flat cut at the right height can now easily separate them. We just added a new dimension, 'height', allowing a straight line to work. This is the main idea of kernel PCA!
  3. Let's try this with numbers. Imagine points on a line: minus one, zero, one in the middle; and minus three, three on the outside. No single point can split them. But if we lift each point using its 'x squared' value, the middle points become low, and the outside points become high. A simple flat cut now separates them.
  4. For your exam, remember to always 'centre the Gram matrix' before finding its components. Also, the number of components is at most the number of data points, no matter how many 'lifted' dimensions there are. So, kernel PCA helps straight lines do curvy jobs by secretly adding new dimensions.

The one-minute story

Think of it like this

Draw a small dot on a sheet of paper and a big ring around it. No straight line can separate "the dot" from "the ring": whichever way you cut, you slice the ring in two. PCA only knows straight lines, so it is stuck.

Now take the paper and push the middle down into a bowl. The ring is now high up, the dot is at the bottom, and one flat cut at the right height separates them perfectly. We did not change the data. We gave it a new dimension (height) where a straight line is enough.

That is kernel PCA. We secretly map each point into a bigger, richer space where PCA's straight lines can do curvy jobs. And here is the miracle, called the kernel trick: we never have to go to that bigger space. A simple formula, the kernel, tells us what the dot products would be there, and dot products are all PCA needs.

By the end of this week you can:

  • explain why linear PCA fails on curved data and how a feature map helps;
  • define a kernel and compute one from a feature map;
  • decide whether a function is a valid kernel (Mercer's condition and closure rules);
  • run kernel PCA on a small example, including centring the kernel matrix.

Words you need

Words you need
  • Feature map ϕ\phiϕ - a rule that sends each point x\mathbf xx to a longer list of numbers ϕ(x)\phi(\mathbf x)ϕ(x).
  • Kernel k(x,y)=ϕ(x)Tϕ(y)k(\mathbf x,\mathbf y)=\phi(\mathbf x)^T\phi(\mathbf y)k(x,y)=ϕ(x)Tϕ(y) - the dot product of two points after mapping.
  • Gram (kernel) matrix KKK - the table with Kij=k(xi,xj)K_{ij}=k(\mathbf x_i,\mathbf x_j)Kij​=k(xi​,xj​).
  • Positive semi-definite (PSD) - symmetric with all eigenvalues ≥0\ge0≥0. Gram matrices must be PSD.
  • Kernel trick - using kkk in place of ϕ(x)Tϕ(y)\phi(\mathbf x)^T\phi(\mathbf y)ϕ(x)Tϕ(y) so we never compute ϕ\phiϕ.
  • RBF / Gaussian kernel - k(x,y)=exp⁡ ⁣(−∥x−y∥2/2σ2)k(\mathbf x,\mathbf y)=\exp\!\big(-\|\mathbf x-\mathbf y\|^2/2\sigma^2\big)k(x,y)=exp(−∥x−y∥2/2σ2), a similarity score that drops to 0 as points move apart.

Idea 1: Lifting data to where lines work

A tiny 1-D version: the points −3-3−3 and 333 (class A) and −1, 0, 1-1,\,0,\,1−1,0,1 (class B) sit on a line, and class B is sandwiched inside class A, so no single threshold separates them. Map x↦(x,  x2)x\mapsto(x,\;x^2)x↦(x,x2). Now class B has heights 1, 0, 11,\,0,\,11,0,1 and class A has height 9, 99,\,99,9: a flat cut at height 555 separates them.

The cost of lifting: the new space can have hundreds or even infinitely many coordinates. Computing ϕ(x)\phi(\mathbf x)ϕ(x) directly would be slow or impossible. Enter the kernel.

Idea 2: Kernels

A kernel returns the dot product of the lifted points, computed from the original points only:

k(x,y)=ϕ(x)Tϕ(y)k(\mathbf x,\mathbf y)=\phi(\mathbf x)^T\phi(\mathbf y)k(x,y)=ϕ(x)Tϕ(y)
Solved example: 1. A kernel and the feature map it hides

Question. For x,y∈R2\mathbf x,\mathbf y\in\mathbb R^2x,y∈R2 take k(x,y)=(xTy)2k(\mathbf x,\mathbf y)=(\mathbf x^T\mathbf y)^2k(x,y)=(xTy)2. Find a feature map ϕ\phiϕ, and check it on x=(1,2)\mathbf x=(1,2)x=(1,2), y=(3,1)\mathbf y=(3,1)y=(3,1).

Solution. Expand: (x1y1+x2y2)2=x12y12+2x1x2y1y2+x22y22(x_1y_1+x_2y_2)^2=x_1^2y_1^2+2x_1x_2y_1y_2+x_2^2y_2^2(x1​y1​+x2​y2​)2=x12​y12​+2x1​x2​y1​y2​+x22​y22​. This is the dot product of

ϕ(x)=(x12,  2 x1x2,  x22)\phi(\mathbf x)=\big(x_1^2,\;\sqrt2\,x_1x_2,\;x_2^2\big)ϕ(x)=(x12​,2​x1​x2​,x22​)

with ϕ(y)\phi(\mathbf y)ϕ(y). Check: xTy=3+2=5\mathbf x^T\mathbf y=3+2=5xTy=3+2=5, so k=25k=25k=25. Via the map: ϕ(x)=(1, 22, 4)\phi(\mathbf x)=(1,\,2\sqrt2,\,4)ϕ(x)=(1,22​,4) and ϕ(y)=(9, 32, 1)\phi(\mathbf y)=(9,\,3\sqrt2,\,1)ϕ(y)=(9,32​,1), dot product 9+22⋅32+4=9+12+4=259+2\sqrt2\cdot3\sqrt2+4=9+12+4=259+22​⋅32​+4=9+12+4=25. ✓

So computing the 2-number dot product and squaring gives the same answer as building two 3-number vectors, and for degree 5 in 100 dimensions the saving is astronomical.

Which functions are legal kernels? (Mercer's condition)

A function kkk is a valid kernel exactly when, for every finite set of points, the Gram matrix KKK is symmetric and positive semi-definite. That is equivalent to kkk being a dot product in some feature space.

The idea

Closure rules. If k1,k2k_1,k_2k1​,k2​ are valid kernels, so are:

  • c k1c\,k_1ck1​ for c>0c>0c>0
  • k1+k2k_1+k_2k1​+k2​
  • k1⋅k2k_1\cdot k_2k1​⋅k2​
  • f(x) k1(x,y) f(y)f(\mathbf x)\,k_1(\mathbf x,\mathbf y)\,f(\mathbf y)f(x)k1​(x,y)f(y) for any function fff
  • exp⁡(k1)\exp(k_1)exp(k1​) and any polynomial of k1k_1k1​ with non-negative coefficients

Not valid in general: k1−k2k_1-k_2k1​−k2​, and c k1c\,k_1ck1​ with c<0c<0c<0.

Quick disproof recipes: (i) kkk not symmetric, like k(x,y)=x−yk(x,y)=x-yk(x,y)=x−y; (ii) a Gram matrix with a negative eigenvalue or negative determinant; (iii) a negative number on the diagonal (k(x,x)=∥ϕ(x)∥2≥0k(\mathbf x,\mathbf x)=\|\phi(\mathbf x)\|^2\ge0k(x,x)=∥ϕ(x)∥2≥0 always).

Question. Decide for 1-D points: (a) k(x,y)=xy−1k(x,y)=xy-1k(x,y)=xy−1; (b) k(x,y)=(1+xy)3k(x,y)=(1+xy)^3k(x,y)=(1+xy)3; (c) k(x,y)=xy+exyk(x,y)=xy+e^{xy}k(x,y)=xy+exy.

The diagonal entry −1-1−1 is negative (impossible for a dot product), and det⁡=0−1=−1<0\det=0-1=-1<0det=0−1=−1<0. Invalid.

Idea 3: Kernel PCA

Ordinary PCA needs the eigenvectors of C=1n∑xixiTC=\frac1n\sum\mathbf x_i\mathbf x_i^TC=n1​∑xi​xiT​. In the lifted space the same idea gives C=1n∑ϕ(xi)ϕ(xi)TC=\frac1n\sum\phi(\mathbf x_i)\phi(\mathbf x_i)^TC=n1​∑ϕ(xi​)ϕ(xi​)T, which may be gigantic or infinite. The trick:

  1. Every eigenvector of CCC with non-zero eigenvalue is a combination of the lifted data points: w=∑iαiϕ(xi)\mathbf w=\sum_i\alpha_i\phi(\mathbf x_i)w=∑i​αi​ϕ(xi​).
  2. Substituting, the eigenproblem turns into one about the Gram matrix KKK, which is only n×nn\times nn×n:
Kα=nλ αK\boldsymbol\alpha=n\lambda\,\boldsymbol\alphaKα=nλα
  1. Dot products ϕ(xi)Tϕ(xj)\phi(\mathbf x_i)^T\phi(\mathbf x_j)ϕ(xi​)Tϕ(xj​) are exactly the kernel values. We never touch ϕ\phiϕ.

Important: centre in the lifted space too. PCA needs centred data, but we cannot subtract a mean we cannot compute. The fix is to centre the kernel matrix:

K~=K−1nK−K1n+1nK1n,1n=1n11T\tilde K=K-\mathbf 1_nK-K\mathbf 1_n+\mathbf 1_nK\mathbf 1_n,\qquad\mathbf 1_n=\tfrac1n\mathbf 1\mathbf 1^TK~=K−1n​K−K1n​+1n​K1n​,1n​=n1​11T

(Each entry becomes KijK_{ij}Kij​ minus its row mean, minus its column mean, plus the grand mean.)

The idea

Kernel PCA algorithm

  1. Compute Kij=k(xi,xj)K_{ij}=k(\mathbf x_i,\mathbf x_j)Kij​=k(xi​,xj​) (n×nn\times nn×n).
  2. Centre it to get K~\tilde KK~.
  3. Find the eigenvalues μ1≥μ2≥…\mu_1\ge\mu_2\ge\dotsμ1​≥μ2​≥… and unit eigenvectors v1,v2,…\mathbf v_1,\mathbf v_2,\dotsv1​,v2​,… of K~\tilde KK~.
  4. The coordinate of training point iii on component jjj is μj  vj,i\sqrt{\mu_j}\;v_{j,i}μj​​vj,i​. (The variance of the data along component jjj is μj/n\mu_j/nμj​/n.)

Facts: there are at most nnn components (not ddd or the huge feature dimension); with the linear kernel you get ordinary PCA back; and the eigenvalues of K~\tilde KK~ are nnn times the eigenvalues of the lifted covariance.

The most common MSQ is "which of the following are valid kernels?" built from the closure rules (sums and products valid, differences and negative multiples not). Next: "write the feature map for this kernel" and "centre this Gram matrix".

Watch out - real exam trap
  • k1−k2k_1-k_2k1​−k2​ is not a valid kernel in general.
  • Always centre KKK before the eigen-analysis. Using the raw KKK is a different (and wrong) problem.
  • The number of kernel PCA components is limited by nnn, the number of points, not the feature dimension.
  • A kernel needs k(x,x)≥0k(\mathbf x,\mathbf x)\ge0k(x,x)≥0 and symmetry. A single violation rules it out.
  • Small σ\sigmaσ in an RBF kernel ⇒\Rightarrow⇒ very local, can overfit; large σ⇒\sigma\Rightarrowσ⇒ nearly constant, can underfit.

Quick quiz

A valid kernel must produce a Gram matrix that is...

  • diagonal
  • symmetric and positive semi-definite
  • invertible
  • all positive entries
Mercer's condition: symmetric PSD for every finite set of points.

k1 and k2 are valid kernels. Which is NOT guaranteed to be valid?

  • k1 + k2
  • k1 times k2
  • k1 minus k2
  • 5 times k1
A difference can have negative eigenvalues. Sums, products and positive multiples are safe.

The linear kernel in kernel PCA gives...

  • nothing
  • ordinary PCA
  • k-means
  • a random projection
With phi(x) = x the kernel is x dot y and kernel PCA reduces to ordinary PCA.

Recap

Remember this
  • Linear PCA fails on curved data. Lift points with ϕ\phiϕ, then run PCA there.
  • Kernel k(x,y)=ϕ(x)Tϕ(y)k(\mathbf x,\mathbf y)=\phi(\mathbf x)^T\phi(\mathbf y)k(x,y)=ϕ(x)Tϕ(y) gives lifted dot products without computing ϕ\phiϕ.
  • Valid   ⟺  \iff⟺ Gram matrix symmetric PSD. Closure: +++, ×\times×, positive multiples, exp⁡\expexp OK; −-− not.
  • Kernel PCA: build KKK, centre to K~\tilde KK~, eigen-analyse; coordinate =μj vj,i=\sqrt{\mu_j}\,v_{j,i}=μj​​vj,i​; at most nnn components.
