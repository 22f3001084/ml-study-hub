Read the words of the video
  1. Imagine trying to guess if a flower is red or blue. Logistic regression helps by giving you a number between 0 and 1. A number like 0.9 means "almost certainly red", while 0.1 means "almost certainly blue". It tells you how likely something is to belong to a specific group.
  2. First, it calculates a simple "score" for the flower, like summing up points for its petal length and width. Then, it uses a special S-shaped curve, called a sigmoid. This curve transforms the score into a probability, so big scores become high chances, and small scores become low chances.
  3. Let's try an example. If a flower has petal length 4 and width 2, we first calculate its score. Using our model's recipe, this score turns out to be 0.6. Then, using our S-shaped curve, this 0.6 score becomes a probability of about 0.65. So, it's about 65% likely to be class 1.
  4. Remember to know your methods: predict_proba gives you percentages, and decision_function gives the raw score. Also, lowering 'C' makes your model simpler and less likely to overfit. Keep practicing how scores become probabilities. You've got this, great job learning logistic regression!

The one-minute story

Think of it like this

Despite the name, logistic regression is a classifier. It answers "how likely is it that this flower is class 1?" with a number between 0 and 1.

It works in two small steps. First it computes a score for the example, exactly as a linear model would: a weighted sum of the features plus a bias. Then it squeezes that score through an S-shaped curve (the sigmoid) so that big positive scores turn into "almost certainly yes", big negative scores into "almost certainly no", and a score of exactly 0 into "50/50".

Everything else in this week (probabilities, thresholds, C, three classes) is just how scikit-learn lets you read and tune those two steps.

By the end of this week you can:

  • train LogisticRegression and read coef_, intercept_, classes_;
  • tell predict, predict_proba and decision_function apart and convert between them;
  • explain the role of C and the default settings;
  • handle more than two classes with softmax regression;
  • use SGDClassifier(loss="log_loss") for the incremental version.

Words you need

Words you need
  • Class / label - the category being predicted.
  • Score / logit / decision function - the raw number z=wTx+bz=\mathbf w^T\mathbf x+bz=wTx+b.
  • Probability - σ(z)\sigma(z)σ(z), between 0 and 1.
  • Decision threshold - the probability above which we say "class 1" (default 0.5).
  • C - inverse regularisation strength (small C = strong regularisation).
  • Softmax regression - the multi-class version of logistic regression.
  • Log loss / cross-entropy - the training loss.

Idea 2: Training and reading the model

We take the iris flower data, keep only two species (setosa =0=0=0 and versicolor =1=1=1) and two features (petal length and width):

from sklearn.datasets import load_iris
from sklearn.linear_model import LogisticRegression

X, y = load_iris(return_X_y=True)
mask = y < 2
X2, y2 = X[mask][:, 2:], y[mask]            # petal length, petal width
clf = LogisticRegression().fit(X2, y2)

clf.coef_, clf.intercept_, clf.classes_
coef_       [[2.583 1.069]]      # one row of weights: shape (1, 2) for a binary problem
intercept_  [-7.808]
classes_    [0 1]

A different threshold? predict always uses 0.5. To use another cut-off, take the probabilities yourself: (clf.predict_proba(X)[:, 1] > 0.3).astype(int). This matters for precision/recall in week 6.

Idea 3: The knobs: C, penalty, solver

LogisticRegression(penalty="l2", C=1.0, solver="lbfgs", max_iter=100)   # classic defaults
  • C (default 1.0) is the inverse of the regularisation strength. Small C = strong regularisation (weights shrink, simpler boundary); large C = weak regularisation. On the iris data, the total size of the weights ∑∣wj∣\sum|w_j|∑∣wj​∣ is 0.62 for C=0.01 and 8.85 for C=100.
  • penalty: 'l2' by default (shrinks all weights), 'l1' (sparse weights; needs a solver such as liblinear or saga). In the newest scikit-learn versions this argument is being replaced by l1_ratio; the idea is unchanged.
  • solver: lbfgs (default), liblinear, newton-cg, sag, saga. Different solvers support different penalties and sizes of data.
  • max_iter (default 100): raise it if you see a ConvergenceWarning (and scale your features, which helps convergence a lot).
  • If the classes are perfectly separable, without regularisation the weights would grow without limit; the default C=1 prevents that.

Idea 4: More than two classes

For KKK classes the model has one weight vector per class and uses softmax (MLT week 12):

P(y=k∣x)=ezk∑jezj,zk=wkTx+bkP(y=k\mid\mathbf x)=\frac{e^{z_k}}{\sum_je^{z_j}},\qquad z_k=\mathbf w_k^T\mathbf x+b_kP(y=k∣x)=∑j​ezj​ezk​​,zk​=wkT​x+bk​

On all three iris species with the two petal features:

softmax_reg = LogisticRegression(C=30, max_iter=1000).fit(X[:, 2:], y)
softmax_reg.coef_.shape                         # (3, 2): one row per class
softmax_reg.predict_proba([[5.0, 2.0]])         # [[0.    0.029 0.971]]
softmax_reg.predict([[5.0, 2.0]])               # [2]    (virginica)

The three probabilities add to 1, and the prediction is the class with the largest one. (Older scikit-learn versions used multi_class="multinomial" for this; recent ones do it automatically with lbfgs.) coef_ has shape (n_classes, n_features) here but (1, n_features) in the binary case.

Idea 5: The incremental version

from sklearn.linear_model import SGDClassifier
SGDClassifier(loss="log_loss")          # logistic regression trained by SGD; has partial_fit

The default loss of SGDClassifier is 'hinge', which gives a linear SVM, not logistic regression. To get logistic regression you must set loss="log_loss". With the SGD version you also get partial_fit for data that arrives in chunks (week 3).

Question. A trained model has coef_ = [[1.5, -2.0]] and intercept_ = [0.5]. For x=(2,1)\mathbf x=(2,1)x=(2,1) find decision_function, predict_proba and predict.

Solution.

Solved example: 2. Shapes

Question. A 4-class problem has 6 features. What is the shape of coef_, intercept_, and of predict_proba for 10 test examples?

Solution. coef_: (4,6)(4,6)(4,6). intercept_: (4,)(4,)(4,). predict_proba(X_test): (10,4)(10,4)(10,4), and each row sums to 1.

Solved example: 3. Effect of C

Question. You raise C from 0.01 to 100. What happens to the training accuracy, the size of the weights and the risk of overfitting?

Solution. Weaker regularisation: the weights grow, the training accuracy usually rises (the boundary fits the training data more tightly), and the overfitting risk goes up.

Watch out - real exam trap
  • predict_proba returns one column per class, in the order of classes_.
  • C is the inverse of regularisation strength.
  • SGDClassifier's default is hinge (SVM), not logistic.
  • score is accuracy, not likelihood.
  • Binary coef_ has shape (1, n_features).
  • Scale the features and raise max_iter if there is a convergence warning.
