Core Topics & Concepts

1. Principal Component Analysis (PCA)

  • Key Idea: Dimensionality reduction by projecting data onto orthogonal axes (principal components) that maximize variance.

  • Steps:

    1. Center the data (subtract mean).
    2. Compute covariance matrix Σ=1nXTX\Sigma = \frac{1}{n} X^T XΣ=n1​XTX.
    3. Eigen-decomposition: Σ=UΛUT\Sigma = U \Lambda U^TΣ=UΛUT, where UUU contains eigenvectors (principal components) and Λ\LambdaΛ contains eigenvalues (variances).
    4. Project data onto top kkk eigenvectors: Xnew=XUkX_{\text{new}} = X U_kXnew​=XUk​.

  • Variance along PC1: For a dataset {α1u,α2u,… }\{ \alpha_1 \mathbf{u}, \alpha_2 \mathbf{u}, \dots \}{α1​u,α2​u,…}, the variance along the first PC is the largest eigenvalue of Σ\SigmaΣ.

    • Equation: If all points lie on a line (e.g., xi=aiu\mathbf{x}_i = a_i \mathbf{u}xi​=ai​u), the variance is Var(ai)⋅∥u∥2\text{Var}(a_i) \cdot \|\mathbf{u}\|^2Var(ai​)⋅∥u∥2.
    • Example (Q2): For {−2u,−u,u,2u}\{-2\mathbf{u}, -\mathbf{u}, \mathbf{u}, 2\mathbf{u}\}{−2u,−u,u,2u}, variance along PC1 is 2.52.52.5.
  • Reconstruction Error: If data lies in a kkk-dimensional subspace, retaining top kkk PCs gives zero reconstruction error (Q3).

2. Maximum A Posteriori (MAP) Estimation

  • Key Idea: Bayesian estimate of parameters by maximizing the posterior distribution.

    • Posterior: f(θ∣X)∝P(X∣θ)⋅P(θ)f(\theta | \mathbf{X}) \propto P(\mathbf{X} | \theta) \cdot P(\theta)f(θ∣X)∝P(X∣θ)⋅P(θ).

3. Logistic Regression & Class Imbalance

  • Key Idea: Binary classification using sigmoid function σ(wTx)\sigma(\mathbf{w}^T \mathbf{x})σ(wTx).

  • Threshold Adjustment:

    • Low threshold: Prioritizes recall (reduces false negatives, e.g., spam detection in Q5).
    • High threshold: Prioritizes precision (reduces false positives).
  • Trade-off: Acceptable to have false positives (regular emails marked as spam) to minimize false negatives (missed phishing emails).

4. k-Means Clustering

  • Key Properties (Q6):

    • Sensitive to outliers: Outliers can distort centroids.
    • Initialization matters: Different initializations can lead to different results (local optima).
    • Convergence: Always converges (but may not find global optimum).
    • Iterations: Initialization affects the number of iterations.
  • Correct Statements: B (sensitive to outliers), D (initialization affects iterations).

5. Training vs. Validation Loss Curves

  • Key Idea: Monitor overfitting/underfitting via loss curves (Q7).

    • Training Loss (Curve A): Decreases monotonically.
    • Validation Loss (Curve B): May increase if overfitting.

  • Interpretation:

    • If validation loss > training loss → overfitting.
    • If both losses plateau at high values → underfitting.

11. Model Complexity & Bias-Variance Trade-off

  • Key Concepts (Q15, Q18):

    • Underfitting: High bias, low variance (simplistic model).
    • Overfitting: Low bias, high variance (complex model).
    • Bagging (e.g., Random Forest): Train estimators in parallel on bootstrapped data.
    • Boosting (e.g., AdaBoost): Train sequentially, reweighting misclassified points.
  • AdaBoost (Q17): Decrease weights for correctly classified observations in next round.

12. Support Vector Machines (SVM)

  • Soft-Margin SVM: Allows misclassification via slack variables ξi\xi_iξi​.

    • Slack Variable ξi\xi_iξi​: Distance from correct margin boundary (Q19–Q22).

      • ξi=0\xi_i = 0ξi​=0 if point is on correct side of margin.
      • ξi>0\xi_i > 0ξi​>0 if point violates margin or is misclassified.
    • Support Vectors: Points with ξi>0\xi_i > 0ξi​>0 or on the margin.

  • Key Properties (Q16):

    • Removing non-support vectors does not change the model.
    • Kernel trick: Map data to higher dimensions for linear separation.
