A. Clustering Algorithms

1. K-Means & K-Means++

  • Lloyd’s Algorithm (K-Means):

    • Convergence: Always converges (monotonically decreases objective function).
    • Sensitivity: Sensitive to outliers (uses Euclidean distance).
    • Optimality: May not find the global optimum (depends on initialization).
    • Objective: Minimize within-cluster sum of squares (WCSS).

B. Dimensionality Reduction (PCA)

1. Principal Component Analysis (PCA)

  • Goal: Find orthogonal axes (principal components) that maximize variance.

  • Steps:

    1. Center the data (subtract mean).
    2. Compute covariance matrix Σ=1nXTX\Sigma = \frac{1}{n} X^T XΣ=n1​XTX.
    3. Eigenvalue decomposition: Σ=UΛUT\Sigma = U \Lambda U^TΣ=UΛUT.
    4. Project data onto top-kkk eigenvectors.

  • Key Equations:

    • Covariance Matrix:
Σ=1n∑i=1n(xi−xˉ)(xi−xˉ)T\Sigma = \frac{1}{n} \sum_{i=1}^n (x_i - \bar{x})(x_i - \bar{x})^TΣ=n1​i=1∑n​(xi​−xˉ)(xi​−xˉ)T
  • Reconstruction Error (Residue):
Error=∑i=k+1dλi\text{Error} = \sum_{i=k+1}^d \lambda_iError=i=k+1∑d​λi​

(where λi\lambda_iλi​ are eigenvalues in descending order).

  • Variance Captured by Top-kkk PCs:
Variance=∑i=1kλi∑i=1dλi\text{Variance} = \frac{\sum_{i=1}^k \lambda_i}{\sum_{i=1}^d \lambda_i}Variance=∑i=1d​λi​∑i=1k​λi​​

  • Properties:

    • If data lies in a kkk-dimensional subspace, the first kkk PCs capture all variance.
    • Eigenvalues of XTXX^T XXTX = Squared singular values of XXX.

2. Example Scenarios

  • Case 1: Data in R50\mathbb{R}^{50}R50 but lies in a 6D subspace → First 6 PCs capture 100% variance.
  • Case 2: d≫nd \gg nd≫n (e.g., d=1000d = 1000d=1000, n=100n = 100n=100) → Only n−1n-1n−1 eigenvalues are non-zero.
  • Case 3: Linearly dependent features → Rank of covariance matrix < ddd.

D. Kernel Methods

1. Valid Kernel Functions

A function K(x,y)K(x, y)K(x,y) is a valid kernel if it satisfies Mercer’s condition (symmetric and positive semi-definite).

  • Examples:

    1. Gaussian (RBF) Kernel:

  1. Polynomial Kernel:

4. Exam Tips

  1. PCA:

    • If data lies in a kkk-dimensional subspace, first kkk PCs capture all variance.
    • Reconstruction error = sum of discarded eigenvalues.

  2. K-Means:

    • Converges always but may not find the global optimum.
    • K-Means++ improves initialization by spreading centers.

  3. Bayesian:

    • Posterior mean for Beta-Binomial is (a+x)/(a+b+n)(a + x)/(a + b + n)(a+x)/(a+b+n).

  4. Kernels:

    • Check for symmetry and positive semi-definiteness.

  5. EM for GMM:

    • Responsibilities (γik\gamma_{ik}γik​) are soft assignments.
    • M-step updates are weighted averages.
