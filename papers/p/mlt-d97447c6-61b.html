1. Core Topics & Key Concepts

A. Dimensionality Reduction (PCA)

  • Key Idea: Reduce dimensionality while preserving variance.

  • Eigenvalues of Covariance Matrix:

    • Represent variance along principal components (PCs).
    • Total Variance = Sum of all eigenvalues.
    • Variance Captured by Top-k PCs = (Sum of top-k eigenvalues) / (Total variance) × 100%.
  • Equation:
Variance %=∑i=1kλi∑i=1dλi×100%\text{Variance \%} = \frac{\sum_{i=1}^k \lambda_i}{\sum_{i=1}^d \lambda_i} \times 100\%Variance %=∑i=1d​λi​∑i=1k​λi​​×100%

(Example: For eigenvalues [15, 5, 5, 0, 0], top-2 PCs capture (15+5)/25 = 80% variance.)

B. Regularization (Ridge Regression)

  • Key Idea: Penalize large weights to prevent overfitting.
  • Loss Function:
L(β)=SSE+λ∥β∥22(SSE=∑(yi−y^i)2)L(\beta) = \text{SSE} + \lambda \|\beta\|_2^2 \quad (\text{SSE} = \sum (y_i - \hat{y}_i)^2)L(β)=SSE+λ∥β∥22​(SSE=∑(yi​−y^​i​)2)

  • Plot Interpretation:

    • Training Loss: Decreases with model complexity (lower λ).
    • Test Loss: U-shaped curve; optimal λ balances bias-variance tradeoff.
    • Best f(λ): Typically log(λ) or 1/λ to visualize tradeoff clearly.

4. Exam Tips

  1. PCA: Always normalize data first. Variance calculation is eigenvalue-based.
  2. Ridge Regression: Optimal λ is where test loss is minimized (not training loss).

  3. Ensemble Methods:

    • Bagging = parallel, Boosting = sequential.
    • Deep trees → Bagging; Stumps → Boosting.

  4. SVM:

    • Hard margin: No misclassification allowed.
    • Soft margin: ξi\xi_iξi​ permits misclassification.
    • αi\alpha_iαi​ determines SV status.
  5. Loss Functions: Memorize graphs (hinge = red, logistic = yellow, squared = green).

  6. Neural Networks:

    • Binary output → sigmoid + cross-entropy.
    • Hidden layers → ReLU (avoid sigmoid/tanh for deep networks).
