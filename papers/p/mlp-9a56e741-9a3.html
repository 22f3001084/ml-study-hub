Here’s a structured summary of the core topics, concepts, principles, and equations essential for the Diploma-Level Machine Learning Practice (Computer-Based Exam). The summary is organized by topic clusters for clarity, followed by Mermaid knowledge graphs to visualize relationships.

1. Core Topics & Concepts

A. Data Handling with Pandas

  1. DataFrame Operations:

    • Indexing: df.loc[] (label-based), df.iloc[] (position-based).
    • Slicing: df.loc[23:24, 'Maths':'History'] ≡ df.iloc[2:4, 1:3] (Q2).
    • Handling missing data: df.dropna() reduces rows (Q6).
    • Data types: df.Hindi.apply(type).nunique() counts unique types (e.g., int, float, str) (Q4).

  1. Chunked Data Loading:

    • For large files: pd.read_csv("filename.csv", chunksize=1024, low_memory=False) (Q12).

B. Model Training & Evaluation

  1. Train-Test Split:

    • train_test_split(X, y, test_size=30) for exact sample counts (Q25).
    • Default splits: test_size=0.2 (20% test data).

  1. Cross-Validation:

    • K-Fold CV: KFold(n_splits=3) splits data into 3 folds (Q9).

      • Output: Indices of train/test sets (e.g., [3,4,5,6,7,8] vs [0,1,2]).
    • ShuffleSplit: Randomized splits (Q26).
    • Learning Curves: sklearn.model_selection.learning_curve plots training/test errors vs. sample size (Q10).

  1. Metrics:

    • Regression: neg_mean_squared_error, r2 (Q26).
    • Classification: accuracy, precision, recall, f1 (Q22).
    • Clustering: Inertia (sum of squared distances to centroids) (Q24, Q38).

C. Algorithms & Hyperparameters

  1. Decision Trees:

    • Hyperparameters:

      • max_depth: Controls tree depth (higher → overfitting) (Q20).
      • min_samples_split: Minimum samples to split a node (Q36).
      • min_samples_leaf: Minimum samples in a leaf (Q36).
    • Prone to: High variance (overfitting) (Q15).

  1. SVM (Support Vector Machines):

    • Hard Margin SVM: Correctly classifies all points if data is linearly separable (Q13).
    • Kernel Trick: Not covered in questions, but implied for non-linear data.

  1. Naive Bayes:

    • Assumes feature independence (Q11).
    • No hyperparameter tuning required (Q32).
    • Incremental learning: partial_fit (Q11).

  1. k-Nearest Neighbors (k-NN):

    • RadiusNeighborsClassifier: Uses all neighbors within a radius (not fixed k) (Q33).
    • Sensitive to scale (normalization recommended).

  1. Ensemble Methods:

    • Bagging: BaggingClassifier with DecisionTreeClassifier (Q23).
    • Boosting: AdaBoost’s learning_rate shrinks weak learner contributions (Q19).
    • Voting Classifier: voting='soft' averages probabilities (Q22).

  1. Neural Networks (MLP):

    • MLPClassifier/MLPRegressor: Defines hidden layers via hidden_layer_sizes=(5,3) (2 layers with 5 and 3 neurons) (Q35).
    • Hyperparameters: max_iter, learning_rate, alpha (L2 regularization).

  1. Stochastic Gradient Descent (SGD):

    • Loss Functions:

      • loss='log_loss' → Logistic regression (Q18).
      • loss='hinge' → Linear SVM (Q17).
      • loss='perceptron' → Perceptron (Q30).
    • Penalties: penalty='l1' (sparse weights) vs. penalty='l2' (Q17).
    • Warm Start: warm_start=True enables incremental training (Q18).

  1. Clustering (K-Means):

    • Inertia: Sum of squared distances to centroids (Q24).

      • Inertia = 0 when n_clusters = n_samples (Q38).
    • Elbow Method: Plot inertia vs. n_clusters to find optimal k.

  1. Imbalanced Data:

    • Techniques: Upsample minority, downsample majority, or synthetic samples (SMOTE) (Q31).

D. Preprocessing & Feature Engineering

  1. Text Data:

    • CountVectorizer: Converts text to word-count matrices (Q14).

      • Output: Vocabulary dictionary (e.g., {'this': 4, 'is': 2}).

  1. Polynomial Features:

    • PolynomialFeatures(degree=2) adds interaction terms (Q16).
    • Hyperparameter tuning: param_grid = {'poly__degree': [2, 3, ...]}.

  1. Scaling:

    • MinMaxScaler or StandardScaler for SGD/neural networks (Q18).

  1. Handling Categorical Data:

    • Inconsistent Entries: E.g., 'Chennai', 'CHENNAI', 'MADRAS' → Requires preprocessing (Q8).

E. Model Selection & Hyperparameter Tuning

  1. Grid Search:

    • GridSearchCV: Exhaustively tests hyperparameter combinations (Q21).

      • Example: param_grid = {'max_depth': [1,3,5], 'min_samples_split': [1,4,7]} → 15 combinations.

  1. Partial Fit:

    • For streaming/large data: model.partial_fit(X, y) (Q12, Q34).

F. Specialized Topics

  1. OpenML:

    • Load datasets: fetch_openml() (Q7).

  1. Model-Specific Notes:

    • Perceptron/SGD: SGDClassifier(loss='perceptron') is a stochastic perceptron (Q30).
    • Logistic Regression: SGDClassifier(loss='log_loss') (Q30).
    • GaussianNB: Assumes normal distribution for features (Q11).

4. Exam Tips

  1. Pandas:

    • Master loc vs. iloc (Q2).
    • Know how dropna() affects rows/columns (Q6).

  1. Model Evaluation:

    • For regression, use neg_mean_squared_error or r2 (Q26).
    • For classification, accuracy or f1 (Q22).

  1. Algorithms:

    • Decision Trees: High variance (Q15), tune max_depth (Q20).
    • SVM: Hard margin for separable data (Q13).
    • Naive Bayes: Independent features (Q11).

  1. Hyperparameter Tuning:

    • GridSearchCV tests all combinations (Q21).
    • Use param_grid with double underscores for pipelines (e.g., poly__degree) (Q16).

  1. SGD:

    • loss='log_loss' → Logistic regression (Q18).
    • penalty='l1' → Sparse weights (Q17).

  1. Clustering:

    • Inertia = 0 when n_clusters = n_samples (Q38).
    • Elbow method for optimal k (Q24).

  1. Text Data:

    • CountVectorizer outputs a vocabulary dictionary (Q14).

  1. Imbalanced Data:

    • Upsample minority or downsample majority (Q31).

  1. Neural Networks:

    • hidden_layer_sizes=(5,3) → 2 layers (Q35).

  1. Code Snippets:

    • Always check for random_state in splits/models for reproducibility.
    • warm_start=True enables incremental training (Q18).
