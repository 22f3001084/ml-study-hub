1. Core Topics & Key Concepts

A. Dimensionality Reduction (PCA)

  • Purpose: Reduce feature space while preserving variance.

  • Steps:

    1. Center the data (subtract mean).
    2. Compute covariance matrix Σ=1nXTX\Sigma = \frac{1}{n} X^T XΣ=n1​XTX.

    3. Eigen-decomposition: Σ=VΛVT\Sigma = V \Lambda V^TΣ=VΛVT, where:

      • Λ\LambdaΛ: Diagonal matrix of eigenvalues λ1≥λ2≥...≥λd\lambda_1 \geq \lambda_2 \geq ... \geq \lambda_dλ1​≥λ2​≥...≥λd​.
      • VVV: Matrix of eigenvectors (principal components).
    4. Project data: XPCA=XVkX_{\text{PCA}} = X V_kXPCA​=XVk​ (top-kkk eigenvectors).

  • Total Variance: Sum of eigenvalues.

    • Equation: Variance=∑i=1dλi\text{Variance} = \sum_{i=1}^d \lambda_iVariance=∑i=1d​λi​.
  • Explained Variance Ratio: λi∑λj\frac{\lambda_i}{\sum \lambda_j}∑λj​λi​​.

Key Equation:

Variance=λ1+λ2+...+λd\text{Variance} = \lambda_1 + \lambda_2 + ... + \lambda_dVariance=λ1​+λ2​+...+λd​

B. Bayesian Estimation

  • Prior: Beta distribution Beta(α,β)\text{Beta}(\alpha, \beta)Beta(α,β).
  • Likelihood: Binomial distribution (for binary outcomes).

  • Posterior: Updated Beta distribution.

    • Posterior Parameters:
α′=α+successes,β′=β+failures\alpha' = \alpha + \text{successes}, \quad \beta' = \beta + \text{failures}α′=α+successes,β′=β+failures
  • Posterior Mean:
Mean=α′α′+β′\text{Mean} = \frac{\alpha'}{\alpha' + \beta'}Mean=α′+β′α′​

  • Assumption: Features are conditionally independent given the class.
  • Posterior Probability:
P(y∣x1,...,xn)∝P(y)∏i=1nP(xi∣y)P(y | x_1, ..., x_n) \propto P(y) \prod_{i=1}^n P(x_i | y)P(y∣x1​,...,xn​)∝P(y)i=1∏n​P(xi​∣y)

D. Gram Matrix & Kernel Methods

  • Gram Matrix: K=XTXK = X^T XK=XTX (symmetric and positive semi-definite).

  • Properties:

    • Symmetry: K=KTK = K^TK=KT.
    • Positive Semi-Definite: vTKv≥0v^T K v \geq 0vTKv≥0 for any vvv.

Key Check: For a matrix KKK to be a Gram matrix:

  1. K=KTK = K^TK=KT.
  2. All eigenvalues ≥0\geq 0≥0.

E. Clustering (Lloyd’s Algorithm / K-Means)

  • Objective: Minimize within-cluster sum of squares (WCSS).

  • Steps:

    1. Initialize centroids.
    2. Assign points to nearest centroid.
    3. Update centroids as mean of assigned points.
    4. Repeat until convergence.
  • Decision Boundary: Voronoi diagram (points assigned to nearest centroid).

Key Insight: Points closer to existing cluster centroids (e.g., [0,0]T[0, 0]^T[0,0]T) are likely in the same cluster.

H. Random Forest

  • Bagging: Bootstrap aggregating (reduce variance).

  • Feature Subsampling: At each split, randomly select ppp features from ddd total.

    • Effect of ppp:

      • Small ppp: Decorrelates trees (reduces variance) but may underfit.
      • Large ppp: Trees become similar (increases variance).
  • Out-of-Bag (OOB) Error: Estimate generalization error without a separate validation set.

Key Trade-offs: | ppp (Features) | Correlation | Bias | Variance | |------------------------|----------------|----------|--------------| | Small | Low | High | Low | | Large | High | Low | High |

M. K-Nearest Neighbors (K-NN)

  • Prediction: Majority vote (classification) or average (regression) of kkk nearest neighbors.
  • Distance Metric: Typically Euclidean or Manhattan.

  • Sensitivity:

    • Outliers: High kkk reduces impact.
    • Scale: Features should be normalized.

Key Insight:

  • Lazy learner (no training phase).
  • Computationally expensive at test time.

4. Exam Tips

  1. PCA: Always check eigenvalues for variance and eigenvectors for principal components.
  2. Bayesian: Remember to add successes/failures to α/β\alpha/\betaα/β.
  3. Naive Bayes: Multiply conditional probabilities (assume independence).
  4. SVM: αi=0\alpha_i = 0αi​=0 implies correct classification outside margin.
  5. Random Forest: Lower ppp reduces correlation but may underfit.
  6. Perceptron: Only update weights if misclassified.
  7. Decision Trees: Calculate entropy and information gain for splits.
  8. K-NN: Normalize features and choose kkk carefully (odd for binary classification).
  9. Loss Functions: 0-1 loss counts misclassifications; squared loss penalizes large errors.
  10. Neural Networks: Forward propagation is layer-by-layer activation.
