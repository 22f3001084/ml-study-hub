B. Linear Algebra & Matrix Decompositions

1. Singular Value Decomposition (SVD)

  • For a matrix A∈Rm×nA \in \mathbb{R}^{m \times n}A∈Rm×n:
A=UΣVTA = U \Sigma V^TA=UΣVT

where:

  • UUU: Left singular vectors (eigenvectors of AATAA^TAAT).
  • Σ\SigmaΣ: Diagonal matrix of singular values (square roots of eigenvalues of ATAA^T AATA).

  • VVV: Right singular vectors (eigenvectors of ATAA^T AATA).

    • Key Properties:
  • Singular values σi=λi(ATA)\sigma_i = \sqrt{\lambda_i(A^T A)}σi​=λi​(ATA)​.
  • Rank of AAA = Number of non-zero singular values.
  • SVD is not unique for square matrices (depends on sign flips in UUU and VVV).

2. Principal Component Analysis (PCA)

  • Steps:

    1. Compute the covariance matrix Σ\SigmaΣ of the data.
    2. Find eigenvectors viv_ivi​ and eigenvalues λi\lambda_iλi​ of Σ\SigmaΣ.
    3. Project data onto the top kkk eigenvectors (principal components) with the largest eigenvalues.

  • Properties:

    • Principal components are orthogonal.
    • They capture maximum variance in the data.
    • The components are uncorrelated.

3. Karush-Kuhn-Tucker (KKT) Conditions

  • For an optimization problem:
min⁡f(x)subject togi(x)≤0,hj(x)=0\min f(x) \quad \text{subject to} \quad g_i(x) \leq 0, h_j(x) = 0minf(x)subject togi​(x)≤0,hj​(x)=0

The KKT conditions are:

  1. Stationarity: ∇f(x)+∑λi∇gi(x)+∑μj∇hj(x)=0\nabla f(x) + \sum \lambda_i \nabla g_i(x) + \sum \mu_j \nabla h_j(x) = 0∇f(x)+∑λi​∇gi​(x)+∑μj​∇hj​(x)=0.
  2. Primal Feasibility: gi(x)≤0g_i(x) \leq 0gi​(x)≤0, hj(x)=0h_j(x) = 0hj​(x)=0.
  3. Dual Feasibility: λi≥0\lambda_i \geq 0λi​≥0.

  4. Complementary Slackness: λigi(x)=0\lambda_i g_i(x) = 0λi​gi​(x)=0.

    • Example: For the problem:
min⁡x2+y2+z2+w2+1s.t.x+y+z+w=1,w≤δ\min x^2 + y^2 + z^2 + w^2 + 1 \quad \text{s.t.} \quad x + y + z + w = 1, w \leq \deltaminx2+y2+z2+w2+1s.t.x+y+z+w=1,w≤δ

The Lagrangian is:

L=x2+y2+z2+w2+1+α(1−x−y−z−w)+β(w−δ)L = x^2 + y^2 + z^2 + w^2 + 1 + \alpha(1 - x - y - z - w) + \beta(w - \delta)L=x2+y2+z2+w2+1+α(1−x−y−z−w)+β(w−δ)

KKT conditions include:

  • ∇L=0\nabla L = 0∇L=0 (stationarity).
  • β(w−δ)=0\beta (w - \delta) = 0β(w−δ)=0 (complementary slackness).
