Here’s a structured summary of core topics, concepts, principles, and equations for the "Diploma Level: Machine Learning Foundations" exam, along with Mermaid knowledge graphs to visualize relationships.

1. Core Topics & Concepts

A. Machine Learning Fundamentals

  1. Supervised Learning

    • Classification (Binary/Multi-class):

      • Used for discrete outputs (e.g., loan approval: "Yes/No").
      • Algorithms: Logistic Regression, Decision Trees, SVM, k-NN.

    • Regression:

      • Used for continuous outputs (e.g., predicting house prices).
      • Algorithms: Linear Regression, Polynomial Regression.

    • Loss Functions:

      • Squared Loss (MSE) for regression:
L(y,y^)=(y−y^)2L(y, \hat{y}) = (y - \hat{y})^2L(y,y^​)=(y−y^​)2
  • Log Loss (Cross-Entropy) for classification:
L(y,y^)=−[ylog⁡(y^)+(1−y)log⁡(1−y^)]L(y, \hat{y}) = -[y \log(\hat{y}) + (1-y) \log(1-\hat{y})]L(y,y^​)=−[ylog(y^​)+(1−y)log(1−y^​)]

  1. Unsupervised Learning

    • Clustering (e.g., k-Means, Hierarchical Clustering).
    • Dimensionality Reduction (e.g., PCA, t-SNE).

  1. Model Evaluation

    • Overfitting/Underfitting:

      • High training accuracy but low test accuracy → Overfitting.
      • Low accuracy on both → Underfitting.

    • Bias-Variance Tradeoff:

      • High bias → Underfitting.
      • High variance → Overfitting.

B. Linear Algebra (Critical for ML)

  1. Matrix Properties

    • Row Space: Spanned by rows of matrix AAA.
    • Basis: Linearly independent vectors spanning a space.
    • Rank: Max number of linearly independent rows/columns.
    • Orthogonal Matrix: ATA=IA^T A = IATA=I (columns are orthonormal).
    • Invertible Matrix: det⁡(A)≠0\det(A) \neq 0det(A)=0, AA−1=IAA^{-1} = IAA−1=I.
    • Symmetric Matrix: A=ATA = A^TA=AT.

  1. Eigenvalues & Eigenvectors

    • For matrix AAA, Av=λvAv = \lambda vAv=λv.
    • Real Symmetric Matrices: Always have real eigenvalues.

    • Diagonalizable Matrix:

      • A=PDP−1A = PDP^{-1}A=PDP−1 (if nnn linearly independent eigenvectors exist).
      • Not all diagonalizable matrices are invertible (e.g., singular matrices).

  1. Special Matrices

    • Positive Definite: All eigenvalues > 0.
    • Singular Matrix: det⁡(A)=0\det(A) = 0det(A)=0 (non-invertible).

4. Exam Tips

  1. Classification vs. Regression:

    • Classification → Discrete output (e.g., loan approval).
    • Regression → Continuous output (e.g., house price).

  1. Matrix Properties:

    • Basis must be linearly independent and span the space.
    • Orthogonal matrices have ATA=IA^T A = IATA=I.
    • Symmetric matrices have real eigenvalues.

  1. Diagonalizable Matrices:

    • Not all diagonalizable matrices are invertible (e.g., singular matrices with repeated eigenvalues).

  1. Loss Functions:

    • Squared Loss → Regression.
    • Log Loss → Classification.

  1. Eigenvalues:

    • Real symmetric matrices always have real eigenvalues.
