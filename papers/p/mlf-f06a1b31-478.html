4. Key Principles

  1. Problem-Type Mapping:

    • Loan approval (binary outcome) → Classification.
    • Predicting a continuous value (e.g., house price) → Regression.
    • Grouping similar data points → Clustering.
    • Reducing feature dimensions → Dimensionality Reduction.

  1. Matrix Properties:

    • A matrix is invertible if det⁡(A)≠0\det(A) \neq 0det(A)=0.
    • Diagonalizable ≠ Invertible (e.g., zero matrix is diagonalizable but not invertible).
    • Real symmetric matrices have real eigenvalues.

  1. Geometric Interpretations:

    • Orthogonal vectors: Perpendicular in Rn\mathbb{R}^nRn.
    • Projection: Shadow of one vector onto another.
    • Rotation matrices: Orthogonal and preserve angles/norms.
