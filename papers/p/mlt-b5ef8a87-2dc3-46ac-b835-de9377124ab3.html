B. Non-Linear Models

  • Polynomial Regression

    • Underfitting/Overfitting:

      • Degree 2/3: Underfits (Q17).
      • Degree 6: Smooth fit.
      • Degree 98: Overfits.
    • Bias-Variance Tradeoff.

  • Neural Networks

    • Activation Functions:

      • ReLU: f(z)=max⁡(0,z)f(z) = \max(0, z)f(z)=max(0,z) (Q6).
      • Sigmoid: f(z)=11+e−zf(z) = \frac{1}{1 + e^{-z}}f(z)=1+e−z1​.
      • Tanh: f(z)=ez−e−zez+e−zf(z) = \frac{e^z - e^{-z}}{e^z + e^{-z}}f(z)=ez+e−zez−e−z​.
      • Softmax: f(z)i=ezi∑jezjf(z)_i = \frac{e^{z_i}}{\sum_j e^{z_j}}f(z)i​=∑j​ezj​ezi​​.

    • Architecture:

      • Parameters: Weights+Biases=∑l=1L(nl⋅nl−1+nl)\text{Weights} + \text{Biases} = \sum_{l=1}^L (n_l \cdot n_{l-1} + n_l)Weights+Biases=∑l=1L​(nl​⋅nl−1​+nl​) (Q22).

        • Rows: Outgoing connections from neuron iii in layer l−1l-1l−1.
        • Columns: Incoming connections to neuron jjj in layer lll (Q26).
    • Invariance: Rotating images (e.g., upside-down) doesn’t degrade performance if trained on rotated data (Q13).

  • Support Vector Machines (SVM)

    • Hinge Loss: L(w)=max⁡(0,1−yi(wTxi+b))L(w) = \max(0, 1 - y_i (w^T x_i + b))L(w)=max(0,1−yi​(wTxi​+b)) (Q30).

    • Decision boundary: wTx+b=0w^T x + b = 0wTx+b=0.
    • Probability: For a random point in [0,1]2[0,1]^2[0,1]2, probability of class +1+1+1 is the area where wTx+b>0w^T x + b > 0wTx+b>0 (Q29).

  • Decision Trees & Ensembles

    • Decision Trees:

      • Splits: Gini/Entropy (Q5).
      • Regression trees: Predict mean of leaf nodes (Q32, Q33).

    • Random Forest:

      • Feature subsampling: Decreasing ppp (features per split) reduces correlation between trees (Q8).
      • Performance: Increasing ppp improves individual tree performance.

    • AdaBoost:

      • Stumps: Weak learners (e.g., split on X2X_2X2​) (Q34, Q35).
      • Sample weights: Updated based on misclassification (higher weight for misclassified samples).
