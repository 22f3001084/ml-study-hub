Core Topics & Key Concepts

1. Clustering (K-Means & Lloyd’s Algorithm)

  • Lloyd’s Algorithm (K-Means):

    • Convergence: Always converges (monotonically decreases objective function), but may converge to local optima (depends on initialization).
    • Sensitivity: Sensitive to outliers (uses Euclidean distance).
    • Optimality: Does not guarantee global optimum (only local).
    • Initialization: Affects final clusters (e.g., k-means++ improves initialization).

    • Steps:

      1. Initialize centroids randomly.
      2. Assign points to nearest centroid.
      3. Recompute centroids as mean of assigned points.
      4. Repeat until convergence (no change in assignments).
    • Tie-Breaking: Affects final clusters if points are equidistant to centroids.

  • Probability of Centroid Selection:

    • If using random initialization, probability of selecting a point as the second centroid is proportional to its squared distance from the first centroid (used in k-means++).

2. Principal Component Analysis (PCA)

  • Key Ideas:

    • Linear dimensionality reduction via orthogonal transformation.
    • Projects data onto directions (principal components) of maximum variance.
    • Components are eigenvectors of the covariance matrix, ordered by eigenvalues (variance explained).

  • Covariance Matrix:

    • For a dataset X∈Rn×dX \in \mathbb{R}^{n \times d}X∈Rn×d (centered), covariance matrix Σ=1n−1XTX\Sigma = \frac{1}{n-1} X^T XΣ=n−11​XTX.
    • Eigenvalues: Number of non-zero eigenvalues = rank of Σ\SigmaΣ (≤ min(n, d)).
    • Total Variance: Sum of all eigenvalues = trace of Σ\SigmaΣ.

  • Reconstruction:

    • Using top kkk components, residual error = sum of discarded eigenvalues.
    • Zero residue: Only if k=rank(Σ)k = \text{rank}(\Sigma)k=rank(Σ).

  • Variance Explained:

    • Variance along iii-th PC = λi\lambda_iλi​ (eigenvalue).
    • Proportion of variance: λi∑jλj\frac{\lambda_i}{\sum_j \lambda_j}∑j​λj​λi​​.

  • Example (from Q3, Q9–Q11):

    • If covariance matrix has eigenvalues [4.5,0.5,0,… ][4.5, 0.5, 0, \dots][4.5,0.5,0,…]:

      • Variance along PC1 = 4.5, PC2 = 0.5.
      • Total variance = 5.0 (sum of all eigenvalues).

3. Bayesian Inference (Beta Distribution)

  • Beta Distribution:

    • Prior for binary outcomes (e.g., coin flips): Beta(α,β)\text{Beta}(\alpha, \beta)Beta(α,β).
    • Posterior Mean: For Beta(α,β)\text{Beta}(\alpha, \beta)Beta(α,β), mean = αα+β\frac{\alpha}{\alpha + \beta}α+βα​.
    • Update Rule: After observing sss successes and fff failures, posterior is Beta(α+s,β+f)\text{Beta}(\alpha + s, \beta + f)Beta(α+s,β+f).

  • Example (from Q5):

    • Prior Beta(1,1)\text{Beta}(1, 1)Beta(1,1) (uniform), observe 1 success in 25 trials:

4. Kernel Methods

  • Valid Kernel Functions (from Q6):

    • Must satisfy Mercer’s condition (positive semi-definite Gram matrix).

    • Examples:

      • Linear kernel: K(x,y)=xTyK(x, y) = x^T yK(x,y)=xTy.
      • Polynomial kernel: K(x,y)=(xTy+c)dK(x, y) = (x^T y + c)^dK(x,y)=(xTy+c)d.
      • Gaussian (RBF) kernel: K(x,y)=exp⁡(−γ∥x−y∥2)K(x, y) = \exp(-\gamma \|x - y\|^2)K(x,y)=exp(−γ∥x−y∥2).
      • Sigmoid kernel: K(x,y)=tanh⁡(αxTy+c)K(x, y) = \tanh(\alpha x^T y + c)K(x,y)=tanh(αxTy+c).

5. K-Means Practical Examples

  • Convergence Iterations (from Q14–Q15):

    • With initial centroids at (−2,3)(-2, 3)(−2,3) and (2,−1)(2, -1)(2,−1), K-means converges in 1 iteration for the given dataset (points are clearly separable).
    • Adding (0,0)(0, 0)(0,0) may require 1 iteration if assignments don’t change.
