Core Topics & Key Concepts

1. Clustering (K-Means)

  • Goal: Partition data into k clusters by minimizing Within-Cluster Sum of Squares (WCSS).

  • Key Idea:

    • For perfect negative correlation (r = -1), data lies on a straight line.
    • Optimal cluster centers for k=3 will also lie on the same line (minimizes WCSS).
  • Equation:
WCSS=∑i=1k∑x∈Ci∥x−μi∥2\text{WCSS} = \sum_{i=1}^{k} \sum_{\mathbf{x} \in C_i} \|\mathbf{x} - \mu_i\|^2WCSS=i=1∑k​x∈Ci​∑​∥x−μi​∥2

where μi\mu_iμi​ = centroid of cluster CiC_iCi​.

2. Bias-Variance Tradeoff

  • Bias: Error due to overly simplistic assumptions (underfitting).

    • High bias: Linear models (e.g., y^=w0+w1x\hat{y} = w_0 + w_1 xy^​=w0​+w1​x).

  • Variance: Error due to excessive complexity (overfitting).

    • High variance: Polynomial/nonlinear models (e.g., y^=w1x2+w2x+w3\hat{y} = w_1 x^2 + w_2 x + w_3y^​=w1​x2+w2​x+w3​).

  • Tradeoff:

    • Model 1 (Linear) → Higher bias, lower variance.
    • Model 2 (Quadratic) → Lower bias, higher variance.

  • Kernel Trick: Maps data to higher-dimensional space via ϕ(x)\phi(\mathbf{x})ϕ(x).

    • Kernel Function: k(xi,xj)=ϕ(xi)Tϕ(xj)k(\mathbf{x}_i, \mathbf{x}_j) = \phi(\mathbf{x}_i)^T \phi(\mathbf{x}_j)k(xi​,xj​)=ϕ(xi​)Tϕ(xj​).
