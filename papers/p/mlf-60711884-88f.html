2. Linear Algebra & Matrix Decompositions

Key Concepts:

  • Singular Value Decomposition (SVD):

    • For matrix A∈Rm×nA \in \mathbb{R}^{m \times n}A∈Rm×n:

      • A=UΣVTA = U \Sigma V^TA=UΣVT, where:

        • UUU: Left singular vectors (eigenvectors of AATAA^TAAT).
        • VVV: Right singular vectors (eigenvectors of ATAA^T AATA).
        • Σ\SigmaΣ: Diagonal matrix of singular values (square roots of eigenvalues of ATAA^T AATA or AATAA^TAAT).
      • Rank of AAA = Number of non-zero singular values.
      • SVD is not unique for square matrices (depends on sign flips in UUU and VVV).

  • Eigenvalues/Eigenvectors:

    • Used in PCA and SVD.
    • Av=λvAv = \lambda vAv=λv.

3. Principal Component Analysis (PCA)

Key Concepts:

  • Goal: Project data onto a lower-dimensional subspace capturing maximum variance.

  • Steps:

    1. Center the data (subtract mean).
    2. Compute covariance matrix Σ\SigmaΣ.
    3. Eigenvalue decomposition: Σ=VΛVT\Sigma = V \Lambda V^TΣ=VΛVT.
    4. Principal components = eigenvectors sorted by eigenvalues (descending).

  • Properties:

    • Principal components are orthogonal.
    • Uncorrelated (if data is centered).
    • First PC captures the most variance.

Key Equations:

  1. Covariance Matrix:
Σ=1nXTX(for centered data)\Sigma = \frac{1}{n} X^T X \quad \text{(for centered data)}Σ=n1​XTX(for centered data)
  1. Projection onto PCs:
Y=XWwhere W=[v1,v2,…,vk]Y = X W \quad \text{where } W = [v_1, v_2, \dots, v_k]Y=XWwhere W=[v1​,v2​,…,vk​]

Key Concepts:

  • Convex/Concave Functions:
