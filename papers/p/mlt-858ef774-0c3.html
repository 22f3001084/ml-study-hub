Core Topics & Key Concepts

1. Clustering (K-Means, Initialization, and Convergence)

  • K-Means Algorithm:

    • Initialization: Randomly select k centroids (or use methods like K-Means++).
    • Assignment Step: Assign each data point to the nearest centroid (Euclidean distance).
    • Update Step: Recompute centroids as the mean of assigned points.
    • Convergence: Iterate until centroids stabilize or max iterations reached.

  • Key Observations:

    • Impossible Scenarios: If all points are assigned to one cluster initially, K-Means cannot recover (e.g., Question 2: Both scenarios are impossible if clusters are separable but initialized poorly).
    • Probability of Centroid Selection: If centroids are chosen uniformly at random, the probability of selecting a specific point as the next centroid depends on the remaining points (e.g., Question 6: Probability = 0.5).

2. Dimensionality Reduction (PCA)

  • Standard PCA Steps:

    1. Center the Data: Subtract the mean from each feature.
    2. Compute Covariance Matrix: Σ=1nXTX\Sigma = \frac{1}{n} X^T XΣ=n1​XTX.
    3. Eigendecomposition: Solve Σ=VΛVT\Sigma = V \Lambda V^TΣ=VΛVT, where VVV contains eigenvectors (principal components) and Λ\LambdaΛ contains eigenvalues.
    4. Project Data: Transform data to the new subspace using top-k eigenvectors.

  • Key Properties:

    • Principal components are orthogonal (uncorrelated).
    • The first PC maximizes variance, the second PC maximizes residual variance, etc.
    • Variance along a Unit Vector uuu: Var(Xu)=uTΣu\text{Var}(X u) = u^T \Sigma uVar(Xu)=uTΣu (e.g., Question 8: Variance = 1 for a cube).
    • Covariance Matrix for a Cube: For a cube centered at the origin with edge length 2, the covariance matrix is diagonal with entries 43\frac{4}{3}34​ (since variance per dimension = (2)212×22=43\frac{(2)^2}{12} \times 2^2 = \frac{4}{3}12(2)2​×22=34​). Sum of all entries = 3 (Question 7).
  • Reconstruction Error: For a data point xxx, the reconstruction using the first k PCs is x^=VkVkTx\hat{x} = V_k V_k^T xx^=Vk​VkT​x, and the error is ∥x−x^∥2\|x - \hat{x}\|^2∥x−x^∥2.

  • Kernel Trick: Map data to a higher-dimensional space using a kernel function K(x,y)=ϕ(x)Tϕ(y)K(x, y) = \phi(x)^T \phi(y)K(x,y)=ϕ(x)Tϕ(y), where ϕ\phiϕ is the feature map.

  • Polynomial Kernel:

    • Degree-d polynomial kernel in DDD-dimensional space: K(x,y)=(xTy+c)dK(x, y) = (x^T y + c)^dK(x,y)=(xTy+c)d.

5. Linear Algebra for ML

  • Covariance Matrix: For centered data XXX, Σ=1nXTX\Sigma = \frac{1}{n} X^T XΣ=n1​XTX.

  • Relationship Between XXTXX^TXXT and XTXX^T XXTX:

Exam Tips

  1. K-Means: Focus on initialization, assignment, and update steps. Understand why certain cluster assignments are impossible (e.g., all points in one cluster initially).
  2. PCA: Know how to compute the covariance matrix, eigenvalues, and projections. Remember that PCs are orthogonal.
  3. Kernels: Memorize the polynomial and Gaussian kernel formulas. Understand how the number of features grows with degree.
  4. EM Algorithm: Be comfortable with the E-step (posterior responsibilities) and M-step (parameter updates). Know how to compute log-likelihood.
  5. Linear Algebra: Review eigendecomposition, covariance matrices, and the relationship between XXTXX^TXXT and XTXX^T XXTX.
  6. Geometry: For a cube, know how to compute variance and covariance. Understand projections onto unit vectors.
