Exam Tips

  1. Perceptron: Know convergence conditions (Q3) and weight updates (Q27).
  2. k-NN: Higher kkk reduces overfitting (Q4).
  3. Decision Trees: Memorize Gini/Entropy curves (Q5).
  4. Activation Functions: Match outputs to possible functions (Q6).
  5. Multi-Label: Identify problems with multiple outputs (Q7).
  6. Random Forest: Feature subsampling reduces correlation (Q8).
  7. Loss Functions: Compute MSE/Ridge/Hinge manually (Q9, Q19, Q30).
  8. Confusion Matrix: Precision = TP / (TP + FP) (Q10).
  9. Gradients: Derive gradients for custom loss functions (Q11).
  10. Silhouette Score: Negative scores indicate poor clustering (Q12).
  11. Neural Networks: Understand weight matrices and parameter counts (Q22, Q26).
  12. Probabilistic Models: Count parameters for Naive Bayes (Q21).
  13. AdaBoost: Compute stump performance and sample weights (Q34, Q35).
  14. Polynomial Regression: Degree impacts underfitting/overfitting (Q17).
  15. NumPy: Practice array operations (Q15, Q18).
