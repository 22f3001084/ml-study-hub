Core Topics & Key Concepts

1. Principal Component Analysis (PCA)

  • Purpose: Dimensionality reduction while preserving variance.

  • Steps:

    1. Center the data (subtract mean).
    2. Compute covariance matrix: Σ=1nXTX\Sigma = \frac{1}{n} X^T XΣ=n1​XTX.
    3. Eigen-decomposition: Σ=VΛVT\Sigma = V \Lambda V^TΣ=VΛVT, where VVV = eigenvectors (principal components), Λ\LambdaΛ = eigenvalues.
    4. Project data onto top-kkk eigenvectors.

  • Key Equations:

    • Covariance matrix: Σ=1n∑i=1n(xi−μ)(xi−μ)T\Sigma = \frac{1}{n} \sum_{i=1}^n (x_i - \mu)(x_i - \mu)^TΣ=n1​∑i=1n​(xi​−μ)(xi​−μ)T.
    • Reconstruction error: Zero if k=dk = dk=d (original dimensions).
    • First PC: Eigenvector corresponding to the largest eigenvalue.
  • Example: For dataset D={(−1,1),(0,0),(1,1)}\mathcal{D} = \{(-1,1), (0,0), (1,1)\}D={(−1,1),(0,0),(1,1)}, the first PC is (11)\begin{pmatrix} 1 \\ 1 \end{pmatrix}(11​).

2. Linear Regression

  • Model: y=wTx+ϵy = w^T x + \epsilony=wTx+ϵ.
  • Loss Function (Squared Error): L(w)=∑i=1n(wTxi−yi)2L(w) = \sum_{i=1}^n (w^T x_i - y_i)^2L(w)=∑i=1n​(wTxi​−yi​)2.
  • Optimal Weights (Closed-Form): w∗=(XXT)−1Xyw^* = (X X^T)^{-1} X yw∗=(XXT)−1Xy (if XXX is full-rank).

  • Key Properties:

    • Minimum loss at w∗w^*w∗ is 0 if data is linearly separable.
    • For underdetermined systems, infinite solutions exist.

3. K-Means Clustering

  • Algorithm: Lloyd’s algorithm (iterative assignment + centroid update).

  • Properties:

    • Local minima: Depends on initialization (use K-means++ to mitigate).
    • Complexity: O(n⋅k⋅d⋅I)O(n \cdot k \cdot d \cdot I)O(n⋅k⋅d⋅I), where III = iterations.
    • Choosing kkk: Elbow method or silhouette score.

  • Trade-offs:

    • K-means++ is slower but avoids poor initializations.
    • Larger kkk increases computational cost.

4. Decision Trees

  • Splitting Criteria:

    • Gini impurity or entropy for classification.
    • Variance reduction for regression.
  • Pure Leaves: A leaf is pure if all samples belong to one class.
  • Example: For binary classification with threshold ppp in x<px < px<p, the number of possible integer ppp values depends on the sorted unique values of xxx.

5. Naive Bayes Classifier

  • Assumption: Features are conditionally independent given the class.

  • Parameters to Learn:

    • Class priors: P(y=c)P(y = c)P(y=c) for each class ccc.
    • Likelihoods: P(fj=v∣y=c)P(f_j = v \mid y = c)P(fj​=v∣y=c) for each feature fjf_jfj​, value vvv, and class ccc.
  • Example: For 4 classes and 3 binary features, total parameters = 3×2×4+3=273 \times 2 \times 4 + 3 = 273×2×4+3=27 (but simplified to 15 if features are binary and symmetries are exploited).

6. Perceptron Algorithm

  • Update Rule: w←w+η⋅yixiw \leftarrow w + \eta \cdot y_i x_iw←w+η⋅yi​xi​ if yi(wTxi)≤0y_i (w^T x_i) \leq 0yi​(wTxi​)≤0.
  • Convergence: Guaranteed if data is linearly separable and learning rate η\etaη is small.
  • Counterexample: Non-separable data (e.g., XOR) leads to no convergence.

7. Logistic Regression

  • Model: P(y=1∣x)=σ(wTx)P(y=1 \mid x) = \sigma(w^T x)P(y=1∣x)=σ(wTx), where σ\sigmaσ = sigmoid.
  • Decision Rule: Predict y^=1\hat{y} = 1y^​=1 if P(y=1∣x)>0.5P(y=1 \mid x) > 0.5P(y=1∣x)>0.5 (or another threshold).
  • Example: For w=[3/25/12]w = \begin{bmatrix} 3/2 \\ 5/12 \end{bmatrix}w=[3/25/12​] and x=[02]x = \begin{bmatrix} 0 \\ 2 \end{bmatrix}x=[02​], compute σ(wTx)\sigma(w^T x)σ(wTx). If σ(wTx)<0.75\sigma(w^T x) < 0.75σ(wTx)<0.75, predict 000.

8. Support Vector Machines (SVM)

  • Hard-Margin SVM:

    • Optimization: min⁡12∥w∥2\min \frac{1}{2} \|w\|^2min21​∥w∥2 s.t. yi(wTxi+b)≥1y_i (w^T x_i + b) \geq 1yi​(wTxi​+b)≥1.
    • Decision Boundary: wTx+b=0w^T x + b = 0wTx+b=0.
    • Supporting Hyperplanes: wTx+b=±1w^T x + b = \pm 1wTx+b=±1.
    • Margin Width: 2∥w∥\frac{2}{\|w\|}∥w∥2​.

  • Soft-Margin SVM:

    • Allows misclassifications via slack variables ξi\xi_iξi​.
    • Optimization: min⁡12∥w∥2+C∑ξi\min \frac{1}{2} \|w\|^2 + C \sum \xi_imin21​∥w∥2+C∑ξi​.

    • Effect of CCC:

      • Small CCC: Wider margin, more misclassifications.
      • Large CCC: Narrower margin, fewer misclassifications.
  • Kernel Trick: For non-linear boundaries, use ϕ(x)\phi(x)ϕ(x) (e.g., RBF kernel).

9. Model Evaluation & Bias-Variance Tradeoff

  • Underfitting:

    • High bias, low variance.
    • Poor performance on training and test data.

  • Overfitting:

    • Low bias, high variance.
    • Good training performance but poor generalization.

  • Diagnostics:

    • Compare training vs. test error (e.g., Model 1 in Q18 overfits; Model 4 underfits).

10. Ensemble Methods (Bagging & Random Forest)

  • Bagging:

    • Train multiple models on bootstrapped samples.
    • Average predictions (regression) or vote (classification).
    • Reduces variance.

  • Random Forest:

    • Extension of bagging with feature randomness.
    • Parallelizable (trees are independent).
    • Weak learners (shallow trees) are preferred to avoid overfitting.

11. Neural Networks

  • Architecture:

    • Input layer, hidden layers (with non-linear activations), output layer.

  • Key Properties:

    • Universal approximator with sufficient hidden units.
    • Non-linear activations (e.g., ReLU, sigmoid) are essential for non-linear decision boundaries.
    • Bias terms are optional but typically included.

12. Regularization

  • L1/L2 Regularization:

    • Add λ∥w∥1\lambda \|w\|_1λ∥w∥1​ (Lasso) or λ∥w∥22\lambda \|w\|_2^2λ∥w∥22​ (Ridge) to loss.

    • Effect of λ\lambdaλ:

      • λ→0\lambda \to 0λ→0: Approaches unregularized solution.
      • λ→∞\lambda \to \inftyλ→∞: Weights w→0w \to 0w→0.

Exam Tips

  1. PCA: Always center the data first. The first PC is the eigenvector with the largest eigenvalue.
  2. SVM: The margin width is 2∥w∥\frac{2}{\|w\|}∥w∥2​. Supporting hyperplanes are wTx+b=±1w^T x + b = \pm 1wTx+b=±1.
  3. Logistic Regression: Predict class based on P(y=1∣x)P(y=1 \mid x)P(y=1∣x) vs. threshold (default 0.5).
  4. Decision Trees: Count unique splits for pure leaves.
  5. Naive Bayes: Parameters = (classes) × (features) × (feature values) + (class priors).
  6. Perceptron: Only converges if data is linearly separable.
  7. Regularization: λ=0\lambda = 0λ=0 removes regularization; λ→∞\lambda \to \inftyλ→∞ forces weights to zero.
