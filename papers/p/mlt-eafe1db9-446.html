Core Topics & Concepts

1. Principal Component Analysis (PCA)

  • Key Idea: Dimensionality reduction by projecting data onto directions (principal components) that maximize variance.

  • Eigenvalues of Covariance Matrix:

    • Represent variance along principal components.
    • Total variance = sum of eigenvalues.
    • Variance captured by top k PCs = (sum of top k eigenvalues) / (total variance).
  • Equation:
Variance captured=∑i=1kλi∑i=1dλi\text{Variance captured} = \frac{\sum_{i=1}^k \lambda_i}{\sum_{i=1}^d \lambda_i}Variance captured=∑i=1d​λi​∑i=1k​λi​​

(For Q2: 15+515+5+5+0+0=0.8\frac{15 + 5}{15 + 5 + 5 + 0 + 0} = 0.815+5+5+0+015+5​=0.8 → 80%)

2. Regularization & Ridge Regression

  • Key Idea: Penalize large weights to prevent overfitting.
  • Loss Function:
L(w)=SSE+λ∥w∥22L(\mathbf{w}) = \text{SSE} + \lambda \|\mathbf{w}\|_2^2L(w)=SSE+λ∥w∥22​

where SSE=∑(yi−y^i)2\text{SSE} = \sum (y_i - \hat{y}_i)^2SSE=∑(yi​−y^​i​)2.

  • Plot Interpretation (Q3):

    • X-axis: f(λ)=log⁡(λ)f(\lambda) = \log(\lambda)f(λ)=log(λ) (common choice to visualize a wide range of λ\lambdaλ values).
    • Y-axis: Regularized loss (SSE + penalty).
    • Curves: Training vs. test loss (U-shaped, with test loss minimizing at optimal λ\lambdaλ).

4. Support Vector Machines (SVM)

Hard-Margin SVM

  • Decision Boundary: wTx+b=0\mathbf{w}^T \mathbf{x} + b = 0wTx+b=0.
  • Supporting Hyperplanes: wTx+b=±1\mathbf{w}^T \mathbf{x} + b = \pm 1wTx+b=±1.
  • Margin: 2∥w∥\frac{2}{\|\mathbf{w}\|}∥w∥2​.
  • Prediction: sign(wTx+b)\text{sign}(\mathbf{w}^T \mathbf{x} + b)sign(wTx+b). (For Q5: Points beyond +1+1+1 → class +1+1+1; beyond −1-1−1 → class −1-1−1.)
