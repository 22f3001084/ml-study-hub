1. Core Topics & Key Concepts

A. Clustering Algorithms

1. K-Means & K-Means++

  • Lloyd’s Algorithm (Standard K-Means)

    • Convergence: Always converges (monotonically decreases objective function).
    • Sensitivity: Sensitive to outliers (uses Euclidean distance).
    • Optimality: May converge to local optima (not guaranteed global optimum).
    • Initialization Dependency: Performance depends on initial centroids.

  • K-Means++ Initialization

    • Goal: Spread out initial centroids to improve convergence.

    • Selection Probability:

      • First centroid: Randomly chosen.
      • Subsequent centroids: Chosen with probability proportional to D(x)2D(x)^2D(x)2, where D(x)D(x)D(x) is the distance to the nearest existing centroid.
    • Score Function:
S(x)=min⁡j=1,…,l−1∥x−μj0∥2S(x) = \min_{j=1,\dots,l-1} \|x - \mu_j^0\|^2S(x)=j=1,…,l−1min​∥x−μj0​∥2
  • Convergence: Faster convergence than random initialization.

  • Likelihood Function for GMM:

B. Dimensionality Reduction (PCA)

1. Principal Component Analysis (PCA)

  • Goal: Find orthogonal directions (principal components) that maximize variance.

  • Steps:

    1. Center the Data: Subtract the mean.
    2. Compute Covariance Matrix: Σ=1nXTX\Sigma = \frac{1}{n} X^T XΣ=n1​XTX.

    3. Eigen Decomposition: Solve Σ=VΛVT\Sigma = V \Lambda V^TΣ=VΛVT, where:

      • VVV: Matrix of eigenvectors (principal components).
      • Λ\LambdaΛ: Diagonal matrix of eigenvalues (variances).
    4. Project Data: XPCA=XVkX_{\text{PCA}} = X V_kXPCA​=XVk​ (top kkk components).

  • Key Properties:

    • Eigenvalues: Number of non-zero eigenvalues = intrinsic dimensionality.
    • Reconstruction Error: Zero if k=k =k= intrinsic dimension.
    • Variance Explained: Proportion of variance by top kkk components:
Variance Explained=∑i=1kλi∑i=1dλi\text{Variance Explained} = \frac{\sum_{i=1}^k \lambda_i}{\sum_{i=1}^d \lambda_i}Variance Explained=∑i=1d​λi​∑i=1k​λi​​

  • Example:

    • If data lies in a 6D subspace of R50\mathbb{R}^{50}R50, PCA will yield 6 non-zero eigenvalues.
    • If 50 eigenvalues are non-zero, data is full-rank.

2. Covariance Matrix & Eigenvalues

  • Covariance Matrix (Σ\SigmaΣ):
Σ=1n∑i=1n(xi−μ)(xi−μ)T\Sigma = \frac{1}{n} \sum_{i=1}^n (x_i - \mu)(x_i - \mu)^TΣ=n1​i=1∑n​(xi​−μ)(xi​−μ)T
  • Eigenvalues: Represent variance along principal components.
  • Trace: Total variance = sum of eigenvalues.

1. Beta-Binomial Model (Bayesian Inference for Proportions)

  • Prior: θ∼Beta(a,b)\theta \sim \text{Beta}(a, b)θ∼Beta(a,b).
  • Likelihood: X∼Binomial(n,θ)X \sim \text{Binomial}(n, \theta)X∼Binomial(n,θ).
  • Posterior: θ∣X∼Beta(a+x,b+n−x)\theta | X \sim \text{Beta}(a + x, b + n - x)θ∣X∼Beta(a+x,b+n−x).
  • Posterior Mean (Estimate for θ\thetaθ):
E[θ∣X]=a+xa+b+n\mathbb{E}[\theta | X] = \frac{a + x}{a + b + n}E[θ∣X]=a+b+na+x​

4. Exam Tips

  1. PCA:

    • If data lies in a k-dimensional subspace, PCA will have k non-zero eigenvalues.
    • Reconstruction error is zero if k=k =k= intrinsic dimension.

  2. K-Means++:

    • The second centroid is chosen with probability proportional to D(x)2D(x)^2D(x)2.
    • Tie-breaking can affect final clusters.

  3. GMM:

    • The likelihood function involves a product of sums (not sum of products).
    • Responsibilities (γik\gamma_{ik}γik​) are soft assignments.

  4. Bayesian Estimation:

    • Beta-Binomial is used for proportion estimation.
    • Posterior mean is a weighted average of prior and data.

  5. Kernels:

    • RBF, Polynomial, Laplacian are valid.
    • Absolute difference (∣x−y∣|x-y|∣x−y∣) is not a valid kernel.
