Summary of Core Topics, Concepts, Principles, and Equations

1. Kernel Functions and Transformation Mappings

  • Kernel Functions: Functions that compute the dot product of the transformed input data in a higher-dimensional space.
  • Transformation Mapping (ϕ\phiϕ): Maps input data to a higher-dimensional space.
  • Example: For a given kernel k([x1,x2]T,[y1,y2]T)=1+x1y1+x2y2+x12y12x2y2+x1y1x22y22k([x_1, x_2]^T, [y_1, y_2]^T) = 1 + x_1 y_1 + x_2 y_2 + x_1^2 y_1^2 x_2 y_2 + x_1 y_1 x_2^2 y_2^2k([x1​,x2​]T,[y1​,y2​]T)=1+x1​y1​+x2​y2​+x12​y12​x2​y2​+x1​y1​x22​y22​, the appropriate transformation mapping is:

2. Principal Component Analysis (PCA)

  • Standard PCA: Applied on a centered dataset to find the directions (principal components) of maximum variance.
  • Variance: The variance of the dataset along the first principal component is maximum.
  • Eigenvalues and Eigenvectors: The first principal component is the unit norm eigenvector corresponding to the largest eigenvalue of the covariance matrix.
  • Low-Dimensional Subspace: If all points lie in a four-dimensional low subspace, the covariance matrix has only four non-zero eigenvalues.

3. Kernel PCA

  • Kernel PCA: Extension of PCA using kernel functions to handle non-linear data.
  • Valid Kernel Functions: For every transformation mapping ϕ:Rd→RD\phi : \mathbb{R}^d \rightarrow \mathbb{R}^Dϕ:Rd→RD, there exists a valid kernel function.
  • Combination of Kernels: For two valid kernels k1,k2:Rd×Rd→Rk_1, k_2 : \mathbb{R}^d \times \mathbb{R}^d \rightarrow \mathbb{R}k1​,k2​:Rd×Rd→R, ak1+bk2ak_1 + bk_2ak1​+bk2​ is a valid kernel function where aaa and bbb are positive real numbers.

4. Lloyd's Algorithm (K-Means Clustering)

  • Lloyd's Algorithm: Iterative algorithm to partition data into kkk clusters.
  • Initialization: Initial cluster centers are chosen, and the algorithm iteratively updates the centers to minimize within-cluster variance.
  • Example: For a dataset {−3,−1,0,1,4,299,300,301}\{-3, -1, 0, 1, 4, 299, 300, 301\}{−3,−1,0,1,4,299,300,301} with initial centers −10-10−10 and 310310310, the final cluster centers aaa and bbb can be found, and their product ababab can be computed.

5. Gaussian Mixture Models (GMM)

  • GMM: Probabilistic model that assumes all the data points are generated from a mixture of a finite number of Gaussian distributions.
  • Probability Calculation: The probability that a point xxx comes from a specific component can be calculated using the Gaussian density function.
  • Example: For a GMM with two components, the probability that the point x=1.2x = 1.2x=1.2 comes from the first component can be calculated using the given table of Gaussian densities.

6. Beta Distribution and Bernoulli Distribution

  • Beta Distribution: Used as a prior and posterior distribution for the parameter ppp in a Bernoulli distribution.
  • Example: For a dataset with 60 points, if the prior and posterior distributions for ppp are Beta(10,5)\text{Beta}(10,5)Beta(10,5) and Beta(30,45)\text{Beta}(30,45)Beta(30,45) respectively, the number of data points with the value 0 can be determined.
