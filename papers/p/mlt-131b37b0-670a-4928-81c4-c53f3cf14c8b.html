Core Topics & Concepts

1. Principal Component Analysis (PCA)

  • Purpose: Dimensionality reduction while preserving variance.

  • Steps:

    1. Compute the covariance matrix Σ\SigmaΣ of the data.
    2. Compute eigenvalues λ1≥λ2≥⋯≥λd\lambda_1 \geq \lambda_2 \geq \dots \geq \lambda_dλ1​≥λ2​≥⋯≥λd​ and eigenvectors v1,v2,…,vdv_1, v_2, \dots, v_dv1​,v2​,…,vd​.
    3. Project data onto the top kkk eigenvectors (principal components).

  • Reconstruction Error:

    • If you retain the first kkk components, the reconstruction error for a point xxx is the sum of the squared projections onto the discarded components:
Error=∑i=k+1d(viTx)2\text{Error} = \sum_{i=k+1}^d (v_i^T x)^2Error=i=k+1∑d​(viT​x)2
  • For the given problem (Q2), since the last two eigenvalues are 0, the reconstruction error for any point in the span of the first 3 eigenvectors is 0.

2. Bayesian Estimation (Beta-Binomial Model)

  • Prior: Beta distribution Beta(α,β)\text{Beta}(\alpha, \beta)Beta(α,β).
  • Likelihood: Binomial distribution Binomial(n,p)\text{Binomial}(n, p)Binomial(n,p).

  • Posterior:

    • Update parameters: α′=α+x\alpha' = \alpha + xα′=α+x, β′=β+n−x\beta' = \beta + n - xβ′=β+n−x.
    • Posterior mean:
E[p∣data]=α′α′+β′\mathbb{E}[p | \text{data}] = \frac{\alpha'}{\alpha' + \beta'}E[p∣data]=α′+β′α′​

  • Example (Q3):

    • Prior: Beta(3,4)\text{Beta}(3, 4)Beta(3,4).
    • Data: n=50n = 50n=50, x=12x = 12x=12.
    • Posterior: Beta(15,42)\text{Beta}(15, 42)Beta(15,42).

4. Gram Matrix & Positive Semidefiniteness

  • Gram Matrix: K=XTXK = X^T XK=XTX for some data matrix XXX.

  • Properties:

    1. Symmetric: K=KTK = K^TK=KT.
    2. Positive Semidefinite: vTKv≥0v^T K v \geq 0vTKv≥0 for all vvv.

  • Example (Q5):
