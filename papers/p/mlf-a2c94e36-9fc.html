1. Core Topics & Concepts

A. Machine Learning Foundations

  1. Supervised Learning:

    • Classification (e.g., loan approval: B in Q2).

      • Binary/multi-class classification.
      • Algorithms: Logistic Regression, Decision Trees, SVM.

    • Regression (e.g., polynomial regression: Q3, Q8, Q9).

      • Linear/non-linear regression (e.g., quadratic model: y=θ0+θ1x+θ2x2y = \theta_0 + \theta_1 x + \theta_2 x^2y=θ0​+θ1​x+θ2​x2).

      • Loss Functions:

        • Squared loss (MSE): L=1n∑i=1n(yi−y^i)2L = \frac{1}{n}\sum_{i=1}^n (y_i - \hat{y}_i)^2L=n1​∑i=1n​(yi​−y^​i​)2 (Q5, Q8).
        • Reconstruction loss (autoencoders): Mean squared distance between input and reconstructed input (Q5).

    • Model Evaluation:

      • Overfitting/underfitting.
      • Zero loss implies perfect fit (only possible if data is linearly separable; Q9).

  1. Unsupervised Learning:

    • Clustering (e.g., K-means, hierarchical).
    • Dimensionality Reduction (e.g., PCA, autoencoders; Q5).

  1. Key Algorithms:

    • Least Squares Method (for regression; Q3):

      • Solve θ=(XTX)−1XTy\theta = (X^T X)^{-1} X^T yθ=(XTX)−1XTy for linear regression.
      • For polynomial regression, transform XXX into a matrix of powers (e.g., [1,x,x2][1, x, x^2][1,x,x2] for quadratic).

    • Autoencoders (Q5):

      • Encoder fff, decoder ggg, reconstruction loss.

B. Linear Algebra

  1. Vectors:

    • Orthogonality: v1⋅v2=0v_1 \cdot v_2 = 0v1​⋅v2​=0 (Q4).

    • Projection: Projection of v1v_1v1​ onto v2v_2v2​: projv2v1=(v1⋅v2v2⋅v2)v2\text{proj}_{v_2} v_1 = \left( \frac{v_1 \cdot v_2}{v_2 \cdot v_2} \right) v_2projv2​​v1​=(v2​⋅v2​v1​⋅v2​​)v2​.

      • Zero projection implies orthogonality (Q4: options B, C, D).

  1. Matrices:

    • Eigenvalues/Eigenvectors (Q6, Q7, Q13–Q16):

      • Av=λvA v = \lambda vAv=λv.

      • Properties:

        • Sum of columns = zero vector ⇒ λ=0\lambda = 0λ=0 is an eigenvalue (Q7).
        • Real symmetric matrices have real eigenvalues (Q15).
        • Diagonalizable ≠ invertible (Q14).
        • Diagonalizable iff nnn linearly independent eigenvectors (not necessarily distinct eigenvalues; Q16).

    • Special Matrices:

      • Orthogonal Matrix: ATA=IA^T A = IATA=I (Q12, Q13).

        • Rotation matrix: A=[cos⁡θ−sin⁡θsin⁡θcos⁡θ]A = \begin{bmatrix} \cos \theta & -\sin \theta \\ \sin \theta & \cos \theta \end{bmatrix}A=[cosθsinθ​−sinθcosθ​] has no real eigenvalues for 0<θ<180∘0 < \theta < 180^\circ0<θ<180∘ (Q13).
      • Determinant: det⁡(A)\det(A)det(A) for scalar matrices (Q6: A=2IA = 2IA=2I ⇒ det⁡(A)=210=1024\det(A) = 2^{10} = 1024det(A)=210=1024).

    • Row Space/Basis (Q10, Q11):

      • Row space: Span of rows of AAA.
      • Basis: Linearly independent rows that span the row space.
      • Linear relations among rows (Q11: R2=2R1+R3R_2 = 2R_1 + R_3R2​=2R1​+R3​).

  1. Systems of Equations:

    • Collinearity check for linear models (Q9: slopes must be equal for all points).
