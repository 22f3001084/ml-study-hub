Core Topics & Key Concepts

1. Linear Regression & Regularization

  • Linear Regression:

    • Model: y=wTx+by = w^T x + by=wTx+b
    • Loss: Mean Squared Error (MSE) = 1n∑i=1n(yi−y^i)2\frac{1}{n} \sum_{i=1}^n (y_i - \hat{y}_i)^2n1​∑i=1n​(yi​−y^​i​)2

  • Ridge Regression (L2 Regularization):

    • Loss: MSE+λ∑j=1dwj2\text{MSE} + \lambda \sum_{j=1}^d w_j^2MSE+λ∑j=1d​wj2​
    • Penalizes large coefficients (shrinks weights but never to zero).

  • Lasso Regression (L1 Regularization):

    • Loss: MSE+λ∑j=1d∣wj∣\text{MSE} + \lambda \sum_{j=1}^d |w_j|MSE+λ∑j=1d​∣wj​∣
    • Can force coefficients to exactly zero (feature selection).

  • Key Insight:

    • w3w_3w3​ in Q4 has sparse weights (zeros) → Lasso.
    • w2w_2w2​ has large weights → Likely unregularized linear regression.
    • w1w_1w1​ has small weights → Ridge.

2. Decision Trees & Entropy

  • Entropy (measure of impurity): H(S)=−∑i=1cpilog⁡2piH(S) = -\sum_{i=1}^c p_i \log_2 p_iH(S)=−∑i=1c​pi​log2​pi​

    • H(S)H(S)H(S) max → Uniform class distribution.

  • Information Gain (IG): IG=H(parent)−∑i=1kNiNH(childi)IG = H(\text{parent}) - \sum_{i=1}^k \frac{N_i}{N} H(\text{child}_i)IG=H(parent)−∑i=1k​NNi​​H(childi​)

  • Stopping Criteria:

    • Min samples per node.

3. Clustering (Lloyd’s Algorithm / K-Means)

  • Algorithm Steps:

    1. Initialize centroids randomly.
    2. Assign points to nearest centroid (Euclidean distance).
    3. Recompute centroids as mean of assigned points.
    4. Repeat until convergence.

  • Key Idea:

    • After 1st iteration in Q5, centroids are means of C1,C2,C3C_1, C_2, C_3C1​,C2​,C3​.
    • In 2nd iteration, (3,3)(3,3)(3,3) will move to the nearest updated centroid.

4. Dimensionality Reduction (PCA & Kernel PCA)

  • Standard PCA:

    • Linear projection to maximize variance.
    • Eigenvalue decomposition of XTXX^T XXTX.

  • Kernel PCA:

    • Non-linear projection using kernel trick.
    • Kernel: K(xi,xj)=ϕ(xi)Tϕ(xj)K(x_i, x_j) = \phi(x_i)^T \phi(x_j)K(xi​,xj​)=ϕ(xi​)Tϕ(xj​).
    • Polynomial Kernel: K(xi,xj)=(xiTxj+c)dK(x_i, x_j) = (x_i^T x_j + c)^dK(xi​,xj​)=(xiT​xj​+c)d.
