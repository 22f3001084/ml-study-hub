1. Core Topics & Key Concepts

A. Clustering (K-Means, K-Means++, Lloyd’s Algorithm)

  • Lloyd’s Algorithm (K-Means):

    • Iterative algorithm to minimize within-cluster variance.
    • Convergence: Always converges (monotonically decreases objective function), but may converge to local optima.
    • Sensitivity: Sensitive to outliers (since it uses Euclidean distance).
    • Initialization: K-Means++ improves initialization by selecting centers based on distance-weighted probabilities.
    • Equation (Objective Function):

  • K-Means++ Initialization Score:

  • Convergence Behavior:

    • May converge to suboptimal solutions depending on initialization.
    • Not guaranteed to find the global optimum.

B. Principal Component Analysis (PCA)

  • Key Idea: Orthogonal transformation to convert correlated variables into linearly uncorrelated principal components (PCs).

  • Eigenvalues & Variance:

    • Eigenvalues of the covariance matrix represent variance along PCs.
    • If data lies in a k-dimensional subspace, only k eigenvalues are non-zero.
    • Total variance = Sum of all eigenvalues.
    • Proportion of variance explained by PC_i:
Variancei=λi∑j=1dλj\text{Variance}_i = \frac{\lambda_i}{\sum_{j=1}^{d} \lambda_j}Variancei​=∑j=1d​λj​λi​​

  • Reconstruction Error:

    • If k components capture all variance, reconstruction error = 0.
    • Residue (error) after k components:
Error=∑i=k+1dλi\text{Error} = \sum_{i=k+1}^{d} \lambda_iError=i=k+1∑d​λi​

  • Mean-Centered Data:

    • PCA is applied to centered data (subtract mean from each feature).

C. Bayesian Statistics (Beta Distribution, Posterior Mean)

  • Beta Distribution as Prior for Proportion (θ):

    • Prior: θ∼Beta(a,b)\theta \sim \text{Beta}(a, b)θ∼Beta(a,b)
    • Posterior (after observing k successes in n trials):
θ∣data∼Beta(a+k,b+n−k)\theta \mid \text{data} \sim \text{Beta}(a + k, b + n - k)θ∣data∼Beta(a+k,b+n−k)
  • Posterior Mean (Estimate for θ):
E[θ]=a+ka+b+nE[\theta] = \frac{a + k}{a + b + n}E[θ]=a+b+na+k​

  • Special Cases:

    • Uniform Prior (Beta(1,1)): Uninformative prior.
    • Jeffreys Prior (Beta(0.5,0.5)): Common for proportions.

4. Exam Tips

  1. K-Means:

    • Know when it converges (always) vs. finds global optimum (not guaranteed).
    • Understand K-Means++ initialization (probability ∝ distance²).

  1. PCA:

    • If data lies in a k-dimensional subspace, only k eigenvalues are non-zero.
    • Reconstruction error = sum of discarded eigenvalues.

  1. Bayesian Statistics:

    • Beta(1,1) = Uniform prior, Beta(0.5,0.5) = Jeffreys prior.
    • Posterior mean = (a+k)/(a+b+n)(a + k)/(a + b + n)(a+k)/(a+b+n).

  1. GMM & EM:

    • Likelihood involves sum over clusters (latent variables).
    • λ (responsibility) is the posterior probability of a point belonging to a cluster.

  1. Kernel Functions:

    • Gaussian, Polynomial, Laplacian are valid.
    • Absolute difference (|x-y|) is invalid.

  1. Covariance Matrix:

    • For centered data, covariance matrix is XTX/(n−1)X^T X / (n-1)XTX/(n−1).
    • Eigenvalues give variance along PCs.
