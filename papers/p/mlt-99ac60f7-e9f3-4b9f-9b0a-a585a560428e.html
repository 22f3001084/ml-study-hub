Core Topics & Key Concepts

1. Principal Component Analysis (PCA)

Key Concepts:

  • Goal: Dimensionality reduction by projecting data onto directions (principal components) of maximum variance.

  • Steps:

    1. Center the data: Subtract the mean from each feature.
    2. Compute covariance matrix Σ=1n−1XTX\Sigma = \frac{1}{n-1} X^T XΣ=n−11​XTX (for centered data).
    3. Eigen decomposition: Find eigenvalues λi\lambda_iλi​ and eigenvectors viv_ivi​ of Σ\SigmaΣ.
    4. Sort eigenvalues: Select top-kkk eigenvectors (principal components) corresponding to the largest eigenvalues.
    5. Project data: Xnew=X⋅VkX_{\text{new}} = X \cdot V_kXnew​=X⋅Vk​, where VkV_kVk​ contains the top-kkk eigenvectors.
  • Reconstruction Error: Zero if k=rank(X)k = \text{rank}(X)k=rank(X). For the given problem (Q3), k=3k = 3k=3 because all other points are linear combinations of 3 independent points.

Key Equations:

  1. Covariance Matrix:
Σ=1n−1∑i=1n(xi−μ)(xi−μ)T\Sigma = \frac{1}{n-1} \sum_{i=1}^n (x_i - \mu)(x_i - \mu)^TΣ=n−11​i=1∑n​(xi​−μ)(xi​−μ)T
  1. Eigenvalue Problem:
det⁡(Σ−λI)=0\det(\Sigma - \lambda I) = 0det(Σ−λI)=0
  1. Projection:
Xnew=X⋅VkX_{\text{new}} = X \cdot V_kXnew​=X⋅Vk​

Kernel PCA:

  • Kernel Trick: Compute kernel matrix K=ϕ(X)Tϕ(X)K = \phi(X)^T \phi(X)K=ϕ(X)Tϕ(X) (where ϕ\phiϕ is a non-linear mapping).
  • Eigenvectors of KKK: Used to find principal components in the feature space.

  • Comparison with Linear PCA:

    • Kernel PCA is more computationally expensive (Q4: Statements A and D are correct).
    • Eigenvectors of KKK are not the same as those of the covariance matrix CCC.

2. Clustering (Lloyd’s Algorithm / K-Means)

Key Concepts:

  • Goal: Partition data into kkk clusters by minimizing within-cluster variance.

  • Steps:

    1. Initialize cluster centers μ1,μ2,…,μk\mu_1, \mu_2, \dots, \mu_kμ1​,μ2​,…,μk​.
    2. Assign each point to the nearest center.
    3. Recompute centers as the mean of assigned points.
    4. Repeat until convergence.
  • Convergence: Guaranteed (finite iterations), but may reach local optima.

Key Equations:

  1. Assignment Step:

3. Gaussian Mixture Models (GMM) & EM Algorithm

Key Concepts:

  • Goal: Model data as a mixture of Gaussian distributions.

  • EM Algorithm:

    • E-Step: Compute responsibilities λki\lambda_k^iλki​ (posterior probabilities):

  • Decision Rule: Predict y^=1\hat{y} = 1y^​=1 if P(y=1∣x)>0.5P(y=1|x) > 0.5P(y=1∣x)>0.5 (or another threshold, e.g., 0.6 in Q12).

7. Decision Trees

Key Concepts:

  • Splitting Rule: Choose splits (e.g., x<px < px<p) to maximize information gain (or Gini purity).
  • Pure Leaves: All points in a leaf belong to the same class.

8. Perceptron Algorithm

Key Concepts:

  • Model: y^=sign(wTx)\hat{y} = \text{sign}(w^T x)y^​=sign(wTx).
  • Convergence: Guaranteed if data is linearly separable.

  • Example (Q11):

    • Data is not linearly separable (e.g., point (1,2)(1, 2)(1,2) and (−3,1)(-3, 1)(−3,1) have y=−1y = -1y=−1, but (4,1)(4, 1)(4,1) has y=1y = 1y=1, and no linear boundary can separate all points). Thus, does not converge.

9. Model Evaluation & Bias-Variance Tradeoff

Key Concepts:

  • Overfitting: Low training error, high test error (high variance, low bias).
  • Underfitting: High training and test error (high bias, low variance).

  • Example (Q17):

    • Model 1: Overfitting (low train error, high test error).
    • Model 4: Underfitting (high train and test error).

Ensemble Methods (Q16):

  • Bagging (Random Forest):

    • Reduces variance by averaging multiple models.
    • Parallelizable: Trees are independent.
    • Weak Learners: Typically high bias (e.g., shallow trees), but ensemble reduces variance.
  • Correct Statements: C, D, E.
