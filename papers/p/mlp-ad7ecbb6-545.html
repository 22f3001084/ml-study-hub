Here’s a structured summary of core topics, concepts, principles, and equations essential for the Diploma Level: Machine Learning Practice (Computer-Based Exam), along with Mermaid knowledge graphs to visualize relationships.

1. Core Topics & Concepts

A. Data Preprocessing

Key Concepts:

  1. One-Hot Encoding (OneHotEncoder)

    • Converts categorical features into binary (0/1) columns.

    • Example:

      from sklearn.preprocessing import OneHotEncoder
ohe = OneHotEncoder(sparse_output=False)
ohe.fit_transform([['apple'], ['banana'], ['apple']])
    • Output Shape: (n_samples, n_categories).

    • Note: If input has mixed types (e.g., `[['apple', 3], ['banana', 1]])**, all columns are treated as categorical by default (unless specified otherwise).

      • Correct Answer for Q2: D (6) (3 categories for fruit + 3 for numbers).

  1. Feature Scaling

    • MinMaxScaler: Scales features to [0, 1] range.

      • Formula:
Xscaled=X−XminXmax−XminX_{\text{scaled}} = \frac{X - X_{\text{min}}}{X_{\text{max}} - X_{\text{min}}}Xscaled​=Xmax​−Xmin​X−Xmin​​

  • Key Attribute: scaler.data_max_ (stores max values per feature).

    • StandardScaler: Standardizes features to mean=0, std=1.
  • Formula:
Xscaled=X−μσX_{\text{scaled}} = \frac{X - \mu}{\sigma}Xscaled​=σX−μ​

  1. Handling Missing Data

    • dropna() in Pandas:

      • thresh=N: Drops rows with fewer than N non-null values.
      • Example: df.dropna(thresh=15) keeps rows with ≥15 non-null values.

  1. Polynomial Features

    • PolynomialFeatures(degree=d): Generates polynomial/combination features up to degree d.

      • Example (degree=2): Input: [[a], [b]] → Output: [[1, a, a²], [1, b, b²]].
      • Correct Answer for Q16: A.

B. Model Evaluation Metrics

Key Concepts:

  1. Mean Absolute Error (MAE)

    • Formula:
MAE=1n∑i=1n∣yi−y^i∣\text{MAE} = \frac{1}{n} \sum_{i=1}^n |y_i - \hat{y}_i|MAE=n1​i=1∑n​∣yi​−y^​i​∣

  • Example (Q5):

    • y_true = [2, 0, 3, 5], y_pred = [2.5, 0.0, 2, 8] → MAE = 1.125.
    • Correct Answer: D.

  1. Accuracy, Precision, Recall, F1, ROC-AUC

    • Cross-Validation Metrics (Q14):

      • Valid for classification: roc_auc, accuracy, precision, recall, f1.
      • Invalid for regression: r2, mean_absolute_error, explained_variance.
      • Correct Answer: A (roc_auc).

  1. R² Score (score method in Linear Regression)

    • Key Insight (Q15):

      • If fit_intercept=True and data is linear, s1 = s2 (intercept doesn’t affect R² if data is centered).
      • Correct Answer: A.

C. Supervised Learning Algorithms

Key Concepts:

  1. Stochastic Gradient Descent (SGD)

    • Parameters (Q6):

      • learning_rate='constant': Fixes learning rate to eta0.
      • eta0: Initial learning rate.
    • Correct Answer: B.

  1. Decision Trees

    • Hyperparameters (Q18):

      • max_depth: Controls tree depth (higher → overfitting, lower → underfitting).
      • Effect of Decreasing max_depth: Accuracy drops (underfitting).
      • Correct Answer: B.

    • Splitting Rules (Q32):

      • Split occurs if:

        • min_samples_split ≤ samples in node.
        • min_samples_leaf ≤ samples in child nodes.
      • Correct Options: A, B, D.

  1. Random Forest

    • max_features (Q9):

      • Higher value → lower variance (trees become more similar).
      • Correct Answer: B.

  1. K-Nearest Neighbors (KNN)

    • Prediction (Q35):

      • Majority vote among n_neighbors.
      • Example: 3 neighbors with labels [0, 1, 1] → predicts 1.
      • Correct Answer: 0 (Note: The provided answer in Q35 seems incorrect; the correct prediction is 1.)

  1. Support Vector Machines (SVM)

    • Prediction vs. True Labels (Q34):

      • Accuracy = Correct Predictions / Total Predictions.
      • Example: 3/5 correct → accuracy = 0.6.
      • Correct Answer: 0.6.

D. Unsupervised Learning

Key Concepts:

  1. K-Means Clustering

    • Parameters (Q30):

      • n_clusters: Number of clusters (must be ≤ samples).
      • init: Initialization method (e.g., k-means++).
      • max_iter: Maximum iterations.

    • Outputs (Q19):

      • cluster_centers_: Coordinates of centroids.
      • inertia_: Sum of squared distances to centroids.
      • Correct Answer: D.

    • Error Handling (Q20):

      • ValueError if n_clusters > n_samples.
      • Correct Answer: C.

  1. Dimensionality Reduction (Q24)

    • Techniques:

      • PCA: Linear projection.
      • t-SNE: Non-linear, preserves local structure.
      • Lasso Regression: Feature selection via L1 regularization.
    • Correct Options: A, C, D.

E. Ensemble Methods

Key Concepts:

  1. Bagging (BaggingClassifier)

    • Parameters (Q7, Q8, Q21):

      • n_estimators: Number of base models.
      • max_samples: Fraction of samples per base model (e.g., 0.5 → 50%).
      • bootstrap: Whether to sample with replacement.

    • Correct Answers:

      • Q7: B (n_estimators = number of base learners).
      • Q8: A (max_samples = fraction of training data).
      • Q21: C (max_samples=0.5 → 50% of data per estimator).

  1. Boosting (AdaBoost, GradientBoosting)

    • Hyperparameter Tuning (Q22, Q29):

      • n_estimators: Number of boosting stages.
      • learning_rate: Shrinkage factor.
      • GridSearchCV: Exhaustively searches parameter combinations.

      • Correct Answers:

        • Q22: D (comprehensive grid for both AdaBoost and DecisionTree).
        • Q29: A, C, D (cross-validation, best params, explicit import needed).

F. Model Training & Hyperparameter Tuning

Key Concepts:

  1. Grid Search vs. Random Search (Q26)

    • RandomizedSearchCV:

      • n_iter: Number of parameter combinations to try.
      • param_distributions: Dictionary of hyperparameter distributions.
    • Correct Options: A, C, D.

  1. Partial Fit (Q25, Q28)

    • Use Cases:

      • Streaming data (cannot fit in memory).
      • Online learning.

    • Correct Answers:

      • Q25: A, C.
      • Q28: A, C, D (partial_fit allows incremental training; classes required for first call).

  1. Stratified K-Fold (Q27)

    • Preserves class distribution in splits.

    • Valid Training Sets (Q27): Must maintain class ratios.

      • Correct Options: B, D, F.

G. Neural Networks

Key Concepts:

  1. MLPClassifier/Regressor (Q11, Q31)

    • alpha: L2 regularization strength (higher → less overfitting).

    • hidden_layer_sizes:

      • Tuple specifies neurons per layer.
      • Example: (5, 3) → 2 hidden layers (5 neurons, then 3 neurons).

    • Correct Answers:

      • Q11: B (higher alpha → stronger regularization).
      • Q31: C, D.

H. Pandas Operations (Q36–Q38)

Key Concepts:

  1. Aggregations:

    • df['Sales'].sum() → Total sales.
    • df.groupby('Region')['Sales'].mean() → Average sales per region.

  2. Filtering:

    • df[df['Region'] == 'North']['Name'] → Names in North region.

  3. Sorting/Selecting:

    • df.nlargest(1, 'Sales') → Row with highest sales.
    • df.loc[df['Sales'].idxmax()] → Same as above.

3. Exam Tips

  1. Focus Areas:

    • Data Preprocessing: Encoding, scaling, missing data.
    • Model Evaluation: Metrics, cross-validation.
    • Algorithms: Decision trees, SVM, KNN, ensemble methods.
    • Hyperparameter Tuning: Grid search, random search.
    • Unsupervised Learning: K-means, PCA, t-SNE.

  1. Common Pitfalls:

    • Partial Fit: Requires classes for first call in classification.
