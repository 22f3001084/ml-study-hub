1. Linear Programming (Optimization)

  • Primal Problem Formulation:

    • Objective: Minimize/maximize a linear function (e.g., cost: 4x+3y4x + 3y4x+3y).
    • Constraints: Linear inequalities (e.g., 2x+y≤802x + y \leq 802x+y≤80, x+3y≤90x + 3y \leq 90x+3y≤90) + non-negativity (x,y≥0x, y \geq 0x,y≥0).

  • Feasible Region: Intersection of constraint half-planes.

8. Principal Component Analysis (PCA)

  • Goal: Reduce dimensionality while maximizing variance.

  • Steps:

    1. Center the data (subtract mean).
    2. Compute covariance matrix.
    3. Eigen decomposition: Project data onto eigenvectors with largest eigenvalues.

  • Key Points:

    • Maximizes variance of the projected data.
    • Minimizes reconstruction error (not maximizes).
    • Not about calculating means for significance.
