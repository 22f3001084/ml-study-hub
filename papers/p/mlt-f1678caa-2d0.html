Summary of Core Topics, Concepts, Principles, and Equations

1. Kernel Functions and Transformation Mapping

  • Kernel Functions: Functions that compute the dot product of the transformed input data in a higher-dimensional space.
  • Transformation Mapping (ϕ\phiϕ): Maps input data to a higher-dimensional space.
  • Example: Given a kernel function k([x1,x2]T,[y1,y2]T)k([x_1, x_2]^T, [y_1, y_2]^T)k([x1​,x2​]T,[y1​,y2​]T), find the appropriate ϕ\phiϕ that transforms the data.

2. K-means Clustering

  • Algorithm: Iterative algorithm to partition data into kkk clusters.
  • Euclidean Distance: Metric used to calculate the distance between data points and centroids.
  • Termination: Algorithm terminates when centroids do not change significantly between iterations.
  • Example: Given four points and initial centroids, determine the number of iterations and final centroids.

3. Principal Component Analysis (PCA)

  • Variance Maximization: PCA finds the directions of maximum variance in the data.
  • Eigenvectors and Eigenvalues: Principal components are the eigenvectors of the covariance matrix, corresponding to the largest eigenvalues.
  • Reconstruction: Data can be reconstructed using the principal components and their coefficients.
  • Example: Statements about variance, eigenvalues, and reconstruction in PCA.

4. Kernel PCA

  • Non-linear PCA: Extends PCA to non-linear data using kernel functions.
  • Valid Kernels: Conditions for valid kernel functions and their combinations.
  • Example: Statements about the number of principal components and valid kernel functions.

5. Bernoulli Distribution and Maximum Likelihood Estimation (MLE)

  • Bernoulli Distribution: Models binary data.
  • MLE: Method to estimate the parameters of a statistical model.
  • Example: Given MLE estimate for ppp, find the number of zeros in a dataset.

6. Beta Distribution and Bayesian Inference

  • Beta Distribution: Prior and posterior distributions for the parameter ppp in a Bernoulli model.
  • Bayesian Inference: Updating the prior distribution based on observed data.
  • Example: Given prior and posterior Beta distributions, find the number of zeros in a dataset.

7. Gaussian Mixture Models (GMM)

  • GMM: Probabilistic model that assumes data is generated from a mixture of Gaussian distributions.
  • Probability Calculation: Calculate the probability that a data point belongs to a specific component.
  • Example: Given GMM parameters, find the probability that a point comes from the first component.

8. Coordinate Transformation in PCA

  • Principal Components: Directions in the data that capture the most variance.
  • Projection: Transforming data points into the coordinate system formed by the principal components.
  • Example: Given principal components and a data point, find its representation in the new coordinate system.
