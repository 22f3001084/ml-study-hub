B. Linear Algebra & Optimization

  1. Singular Value Decomposition (SVD)

    • Properties:

      • Applicable to any matrix (not just square/symmetric).
      • Singular values are non-negative.
      • Singular values of AAA and ATA^TAT are identical.

  1. Principal Component Analysis (PCA)

    • Key Ideas:

      • Principal components = eigenvectors of the covariance matrix.
      • Maximizes variance along each component.
      • Basis is orthogonal.

  1. Convexity

    • Convex Sets:

      • Linear constraints (e.g., ∑aixi=b\sum a_i x_i = b∑ai​xi​=b) define convex sets.
      • Lines in R2\mathbb{R}^2R2 are convex; unions of convex sets are not necessarily convex.

    • Convex Functions:

      • exe^xex, ex2+2e^{x^2+2}ex2+2 are convex.
      • Composition f∘gf \circ gf∘g is not guaranteed convex.

    • Optimization:

      • Convex cost functions (e.g., f(x,y)=2x2+xy+y2f(x,y) = 2x^2 + xy + y^2f(x,y)=2x2+xy+y2) have global minima.

      • KKT Conditions for constrained optimization:

        • ∇L=0\nabla L = 0∇L=0 (stationarity).
        • β(w−δ)=0\beta (w - \delta) = 0β(w−δ)=0 (complementary slackness).
        • β≥0\beta \geq 0β≥0 (dual feasibility).

  1. Gradient Descent

    • Update Rule: xk+1=xk−η∇f(xk)x_{k+1} = x_k - \eta \nabla f(x_k)xk+1​=xk​−η∇f(xk​).
    • Example: For f(x,y)=x2+2y2−6x+8yf(x,y) = x^2 + 2y^2 - 6x + 8yf(x,y)=x2+2y2−6x+8y, ∇f=(2x−6,4y+8)\nabla f = (2x - 6, 4y + 8)∇f=(2x−6,4y+8). With η=0.2\eta = 0.2η=0.2, (x1,y1)=(1.8,−0.4)(x_1, y_1) = (1.8, -0.4)(x1​,y1​)=(1.8,−0.4).

C. Calculus & Constrained Optimization

  1. Lagrange Multipliers

    • Lagrangian: L=f(x)+∑λigi(x)L = f(x) + \sum \lambda_i g_i(x)L=f(x)+∑λi​gi​(x).

    • KKT Conditions:

      • ∇L=0\nabla L = 0∇L=0, λigi(x)=0\lambda_i g_i(x) = 0λi​gi​(x)=0, λi≥0\lambda_i \geq 0λi​≥0 (for inequalities).

  1. Maximization on Constraints

    • Example: Maximize f(x,y,z)=5x+7y+zf(x,y,z) = 5x + 7y + zf(x,y,z)=5x+7y+z on x2+y2=25x^2 + y^2 = 25x2+y2=25 and x+y−z=4x + y - z = 4x+y−z=4.

4. Exam Tips

  • Probability: Focus on CDF/PDF of exponential/Gaussian distributions and conditional probability.
  • Linear Algebra: SVD properties, PCA (eigenvectors vs. singular values), and convexity.
  • Optimization: KKT conditions, gradient descent updates, and Lagrange multipliers.
  • Calculus: Maximization/minimization on constraints (use substitution or Lagrange multipliers).
