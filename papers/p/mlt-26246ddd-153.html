Core Topics & Concepts

1. Clustering (K-Means)

  • Key Idea: Partition data into k clusters by minimizing within-cluster sum of squares (WCSS).

  • Perfect Negative Correlation (Q2):

    • If features have a correlation of -1, data lies on a straight line.
    • K-means cluster centers will also lie along the same line (minimizing WCSS).
  • Equation:
WCSS=∑i=1k∑x∈Ci∥x−μi∥2\text{WCSS} = \sum_{i=1}^{k} \sum_{\mathbf{x} \in C_i} \|\mathbf{x} - \mu_i\|^2WCSS=i=1∑k​x∈Ci​∑​∥x−μi​∥2

where μi\mu_iμi​ is the center of cluster CiC_iCi​.

2. Bias-Variance Tradeoff (Q3)

  • Bias: Error due to overly simplistic assumptions (underfitting).

    • High bias: Linear model (Model 1: y^=w0+w1x\hat{y} = w_0 + w_1 xy^​=w0​+w1​x).

  • Variance: Error due to excessive complexity (overfitting).

    • High variance: Polynomial model (Model 2: y^=w1x2+w2x+w3\hat{y} = w_1 x^2 + w_2 x + w_3y^​=w1​x2+w2​x+w3​).

  • Tradeoff:

    • Model 1 has higher bias, lower variance (simpler).
    • Model 2 has lower bias, higher variance (complex).

3. Logistic Regression (Q4)

  • Decision Boundary: For binary classification, the boundary is where σ(wTx+b)=0.5\sigma(\mathbf{w}^T \mathbf{x} + b) = 0.5σ(wTx+b)=0.5, i.e., wTx+b=0\mathbf{w}^T \mathbf{x} + b = 0wTx+b=0.

  • Angle θ\thetaθ of Weight Vector:

    • The weight vector w=[w1,w2]T\mathbf{w} = [w_1, w_2]^Tw=[w1​,w2​]T defines the boundary’s orientation.

    • Range for Class-1 Predictions:

      • For points x1=[1,3]T\mathbf{x}_1 = [1, \sqrt{3}]^Tx1​=[1,3​]T and x2=[−1,3]T\mathbf{x}_2 = [-1, \sqrt{3}]^Tx2​=[−1,3​]T to both be classified as 1, the angle θ\thetaθ must satisfy:
30∘≤θ≤150∘30^\circ \leq \theta \leq 150^\circ30∘≤θ≤150∘

6. Support Vector Machines (SVM) (Q7, Q8, Q10, Q15)

Hard-Margin SVM

  • Decision Boundary: wTx+b=0\mathbf{w}^T \mathbf{x} + b = 0wTx+b=0.
  • Support Vectors: Points lying on the margin boundaries wTx+b=±1\mathbf{w}^T \mathbf{x} + b = \pm 1wTx+b=±1.

  • Linearly Separable Data (Q8):

    • If data is separable, hard-margin SVM works (no slack variables ξi\xi_iξi​).
    • Perceptron vs. SVM: Both can separate data, but their decision boundaries may differ.

Soft-Margin SVM (Q7, Q10)

  • Optimization Problem:
min⁡w,b,ξ12∥w∥2+C∑i=1nξi\min_{\mathbf{w}, b, \xi} \frac{1}{2} \|\mathbf{w}\|^2 + C \sum_{i=1}^n \xi_iw,b,ξmin​21​∥w∥2+Ci=1∑n​ξi​

subject to:

yi(wTxi+b)≥1−ξi,ξi≥0y_i (\mathbf{w}^T \mathbf{x}_i + b) \geq 1 - \xi_i, \quad \xi_i \geq 0yi​(wTxi​+b)≥1−ξi​,ξi​≥0

  • Key Properties:

    • (B) If a point lies on the correct margin, its slack ξi=0\xi_i = 0ξi​=0 (no "bribe" paid).
    • (D) There are 2n constraints (one for each yi(wTxi+b)≥1−ξiy_i (\mathbf{w}^T \mathbf{x}_i + b) \geq 1 - \xi_iyi​(wTxi​+b)≥1−ξi​ and one for ξi≥0\xi_i \geq 0ξi​≥0).
    • (E) As C→∞C \to \inftyC→∞, soft-margin SVM approaches hard-margin SVM.

  • Support Vectors (Q7):

    • Points A, N are support vectors (lie on the margin).
    • Points F, A, C, I, N influence the optimal w\mathbf{w}w.
