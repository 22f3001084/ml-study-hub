Machine Learning Techniques Exam: Core Topics Summary

This exam focuses heavily on Unsupervised Learning techniques, particularly Clustering and Dimensionality Reduction, alongside foundational Mathematical Concepts from linear algebra, probability, and statistics.

1. Unsupervised Learning: Clustering

1.1 K-Means Clustering (Lloyd's Algorithm)

  • Concept: An iterative partitioning algorithm that aims to partition NNN data points into KKK clusters, where each data point belongs to the cluster with the nearest mean (centroid).

  • Principles:

    • Algorithm Steps:

      1. Initialization: Choose KKK initial cluster centroids.
      2. Assignment Step (E-step-like): Assign each data point to the cluster whose centroid is closest, typically using squared Euclidean distance.
      3. Update Step (M-step-like): Recalculate the centroids as the mean of all data points assigned to that cluster.
      4. Convergence: Repeat steps 2 and 3 until cluster assignments no longer change or centroids do not move significantly.

    • Properties:

      • Convergence: Always converges in a finite number of iterations to a local optimum of the objective function.
      • Sensitivity to Initialization: The final clustering result can vary significantly based on the initial placement of centroids.
      • Sensitivity to Outliers: Highly sensitive to outliers due to its reliance on means and squared Euclidean distance, which heavily penalizes large distances.
      • Optimality: Does not guarantee finding the global optimal clustering.

  • Equations:

    • Squared Euclidean Distance: For points x=(x1,…,xD)x = (x_1, \dots, x_D)x=(x1​,…,xD​) and y=(y1,…,yD)y = (y_1, \dots, y_D)y=(y1​,…,yD​):

1.2 K-Means++ Initialization

  • Concept: A smart initialization technique for K-Means that selects initial centroids to be far apart, improving the chance of finding a better local optimum.

  • Principles:

    • Randomly choose the first center from the data points.
    • For each subsequent center, choose a data point xxx with probability proportional to its squared distance D(x)2D(x)^2D(x)2 from the closest existing center.
    • This probabilistic selection biases towards choosing points that are far from already chosen centroids.

1.3 Gaussian Mixture Models (GMM) and Expectation-Maximization (EM) Algorithm

  • Concept: A probabilistic model that assumes data points are generated from a mixture of several Gaussian distributions with unknown parameters (means, covariances, and mixing weights). The EM algorithm is used to estimate these parameters.

    • GMM Likelihood: For a dataset X={x1,…,xN}X = \{x_1, \dots, x_N\}X={x1​,…,xN​} and KKK Gaussian components, the likelihood function for parameters θ={πk,μk,Σk}k=1K\theta = \{\pi_k, \mu_k, \Sigma_k\}_{k=1}^Kθ={πk​,μk​,Σk​}k=1K​ is:

2. Unsupervised Learning: Dimensionality Reduction

2.1 Principal Component Analysis (PCA)

  • Concept: A linear dimensionality reduction technique that transforms data to a new coordinate system such that the greatest variance by any projection of the data lies on the first coordinate (first principal component), the second greatest variance on the second coordinate, and so on.

  • Principles:

    • Covariance Matrix: PCA is based on the eigenvalue decomposition of the data's covariance matrix.
    • Principal Components: The principal components are the eigenvectors of the covariance matrix, ordered by their corresponding eigenvalues in descending order.
    • Variance Explained: Each eigenvalue represents the amount of variance captured along its corresponding principal component.
    • Intrinsic Dimensionality: If a dataset inherently lies in a kkk-dimensional linear subspace, then its covariance matrix will have kkk non-zero eigenvalues, and kkk principal components are sufficient to reconstruct the data with zero error.
    • Reconstruction Error: When reducing dimensionality, the reconstruction error relates to the variance not captured by the selected principal components. Zero residue implies all variance is captured.

  • Equations:

    • Mean Vector: For a dataset X∈RN×DX \in \mathbb{R}^{N \times D}X∈RN×D where NNN is the number of samples and DDD is the number of features, the mean of feature jjj is:

      xˉj=1N∑i=1NXij\bar{x}_j = \frac{1}{N} \sum_{i=1}^N X_{ij}xˉj​=N1​i=1∑N​Xij​
    • Mean-Centered Data Matrix: Xcentered=X−mean(X)X_{centered} = X - \text{mean}(X)Xcentered​=X−mean(X) (each row has mean subtracted).

    • Sample Covariance Matrix: For mean-centered data XcenteredX_{centered}Xcentered​:

      Σ=1N−1XcenteredTXcentered\Sigma = \frac{1}{N-1} X_{centered}^T X_{centered}Σ=N−11​XcenteredT​Xcentered​

      (Often 1/N1/N1/N is used in ML contexts for population covariance, or when treating XXX as a population.) For a 2D dataset with points (xi,yi)(x_i, y_i)(xi​,yi​):

      Σ=1N−1(∑(xi−xˉ)2∑(xi−xˉ)(yi−yˉ)∑(yi−yˉ)(xi−xˉ)∑(yi−yˉ)2)\Sigma = \frac{1}{N-1} \begin{pmatrix} \sum (x_i - \bar{x})^2 & \sum (x_i - \bar{x})(y_i - \bar{y}) \\ \sum (y_i - \bar{y})(x_i - \bar{x}) & \sum (y_i - \bar{y})^2 \end{pmatrix}Σ=N−11​(∑(xi​−xˉ)2∑(yi​−yˉ​)(xi​−xˉ)​∑(xi​−xˉ)(yi​−yˉ​)∑(yi​−yˉ​)2​)
    • Eigenvalue Decomposition: Σv=λv\Sigma v = \lambda vΣv=λv, where λ\lambdaλ is an eigenvalue and vvv is an eigenvector.

3. Kernel Functions

  • Concept: Functions that compute the inner product between two vectors in a high-dimensional feature space, without explicitly transforming the data into that space (the "kernel trick"). Used in algorithms like SVMs and Kernel PCA to handle non-linear relationships.

  • Principles:

    • A function K(x,y)K(x, y)K(x,y) is a valid kernel if it corresponds to an inner product in some high-dimensional feature space, i.e., K(x,y)=ϕ(x)Tϕ(y)K(x, y) = \phi(x)^T \phi(y)K(x,y)=ϕ(x)Tϕ(y) for some mapping ϕ\phiϕ.
    • Mercer's Theorem: Provides formal conditions for a function to be a valid kernel (the kernel matrix must be positive semi-definite).

  • Common Valid Kernels:

    • Radial Basis Function (RBF) / Gaussian Kernel:

      K(x,y)=exp⁡(−∣∣x−y∣∣22σ2)orK(x,y)=exp⁡(−γ∣∣x−y∣∣2)K(x, y) = \exp\left(-\frac{||x - y||^2}{2\sigma^2}\right) \quad \text{or} \quad K(x, y) = \exp(-\gamma ||x - y||^2)K(x,y)=exp(−2σ2∣∣x−y∣∣2​)orK(x,y)=exp(−γ∣∣x−y∣∣2)

      where σ>0\sigma > 0σ>0 (or γ>0\gamma > 0γ>0) is a bandwidth parameter.

4. Bayesian Inference (Beta-Binomial Model)

  • Concept: A framework for updating beliefs about parameters of a distribution using observed data. The Beta-Binomial model is a common example of a conjugate prior relationship.

  • Principles:

    • Bayes' Theorem: Relates the posterior probability of a parameter (θ\thetaθ) given data (DDD) to the likelihood of the data given the parameter and the prior probability of the parameter.

      P(θ∣D)=P(D∣θ)P(θ)P(D)P(\theta|D) = \frac{P(D|\theta) P(\theta)}{P(D)}P(θ∣D)=P(D)P(D∣θ)P(θ)​
    • Conjugate Prior: When the posterior distribution is in the same family as the prior distribution. For a Binomial likelihood, the Beta distribution is a conjugate prior.
    • Beta Distribution: A continuous probability distribution defined on the interval [0,1][0, 1][0,1], often used to model probabilities or proportions.
    • Binomial Distribution: A discrete probability distribution of the number of successes in a sequence of nnn independent yes/no experiments.

  • Equations:

    • Beta Prior Distribution: θ∼Beta(a,b)\theta \sim \text{Beta}(a, b)θ∼Beta(a,b)
    • Binomial Likelihood: Given kkk successes in nnn trials: P(k∣n,θ)∼Binomial(n,θ)P(k|n, \theta) \sim \text{Binomial}(n, \theta)P(k∣n,θ)∼Binomial(n,θ)

    • Beta Posterior Distribution: Given a Beta(a,b)\text{Beta}(a, b)Beta(a,b) prior and observing kkk successes in nnn trials, the posterior is:

      θ∣k,n∼Beta(a+k,b+n−k)\theta|k, n \sim \text{Beta}(a+k, b+n-k)θ∣k,n∼Beta(a+k,b+n−k)

      E[θ]=αα+βE[\theta] = \frac{\alpha}{\alpha + \beta}E[θ]=α+βα​
