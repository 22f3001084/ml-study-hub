The examination covers fundamental concepts in Machine Learning, Linear Algebra, Multivariable Calculus, and Optimization. A strong understanding of these mathematical and algorithmic foundations is crucial.

Summary of Core Topics, Concepts, Principles, and Equations

1. Machine Learning Fundamentals

  • Loss Functions: Quantify the error between predicted and actual values.

    • Mean Squared Error (MSE): Primarily used for regression problems, penalizes larger errors more heavily.

  • Classification vs. Regression: Distinguish between problems predicting discrete categories (classification) and continuous values (regression). MSE is not suitable for classification.

  • Autoencoders and Dimensionality Reduction:

    • Encoder: Maps input data to a lower-dimensional representation.
    • Decoder: Maps the lower-dimensional representation back to the original data space.

    • Reconstruction Error: Measures how well the decoder can reconstruct the original input from the encoded representation. Often uses squared Euclidean norm.

2. Linear Algebra

  • Vector Spaces and Subspaces:

    • Row Space, Column Space, Null Space (Kernel): Understand their definitions and properties.
    • Orthogonality: The row space of a matrix is orthogonal to its null space. The column space of a matrix is orthogonal to the null space of its transpose.

    • Rank-Nullity Theorem: For a matrix A∈Rm×nA \in \mathbb{R}^{m \times n}A∈Rm×n, the dimension of its column space (rank) plus the dimension of its null space (nullity) equals the number of columns nnn.

      rank(A)+nullity(A)=n\text{rank}(A) + \text{nullity}(A) = nrank(A)+nullity(A)=n
    • Rank: The dimension of the column space (or row space) of a matrix. The column rank is always equal to the row rank.

  • Eigenvalues and Eigenvectors:

    • Definition: For a matrix AAA, a non-zero vector vvv is an eigenvector if Av=λvAv = \lambda vAv=λv for some scalar λ\lambdaλ, called the eigenvalue.
    • Symmetric Matrices: Have real eigenvalues and an orthogonal basis of eigenvectors. They are always diagonalizable.
    • Diagonalization: A square matrix AAA is diagonalizable if and only if there exists a basis of eigenvectors for the entire space Rd\mathbb{R}^dRd. This means the algebraic multiplicity of each eigenvalue equals its geometric multiplicity.

  • Matrix Operations and Properties:

    • Matrix multiplication, transpose.
    • Determinant: A scalar value that can be computed from the elements of a square matrix.

    • Projection Matrices: Project vectors onto a subspace.

      • Projection matrix onto the line spanned by vector aaa:

        Pa=aaTaTaP_a = \frac{a a^T}{a^T a}Pa​=aTaaaT​

      • Projection matrix onto the orthogonal complement of the span of aaa:

        Pa⊥=I−PaP_{a^\perp} = I - P_aPa⊥​=I−Pa​

  • Systems of Linear Equations (Ax=bAx=bAx=b):

    • Consistency: A system is consistent if a solution xxx exists (i.e., bbb lies in the column space of AAA). This can be checked by comparing the rank of AAA with the rank of the augmented matrix [A∣b][A|b][A∣b].

    • Least Squares Approximation: If Ax=bAx=bAx=b is inconsistent, the least squares method finds x^\hat{x}x^ that minimizes ∥Ax−b∥2\|Ax-b\|^2∥Ax−b∥2. The solution x^\hat{x}x^ is found by solving the normal equations:

      ATAx^=ATbA^T A \hat{x} = A^T bATAx^=ATb
    • Projection Vector: The vector p=Ax^p = A\hat{x}p=Ax^ is the projection of bbb onto the column space of AAA.

  • Gradient Descent: An iterative optimization algorithm used to find the local minimum of a function. It moves in the direction opposite to the gradient.
