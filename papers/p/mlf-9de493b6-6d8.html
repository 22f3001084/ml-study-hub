B. Linear Algebra

  1. Singular Value Decomposition (SVD)

    • Definition: For any matrix A∈Rm×nA \in \mathbb{R}^{m \times n}A∈Rm×n, A=UΣVTA = U \Sigma V^TA=UΣVT, where:

      • UUU: Left singular vectors (orthogonal).
      • Σ\SigmaΣ: Diagonal matrix of singular values (σi≥0\sigma_i \geq 0σi​≥0).
      • VVV: Right singular vectors (orthogonal).

    • Properties:

      • Singular values are non-negative (always true).
      • AAA and ATA^TAT share the same singular values.
      • SVD exists for any matrix (not just square/symmetric).

  1. Principal Component Analysis (PCA)

    • Goal: Find orthogonal directions (principal components) that maximize variance.

    • Steps:

      1. Compute the covariance matrix Σ\SigmaΣ of the data.

      2. Perform eigendecomposition of Σ\SigmaΣ: Σ=VΛVT\Sigma = V \Lambda V^TΣ=VΛVT, where:

        • Columns of VVV: Principal components (eigenvectors).
        • Λ\LambdaΛ: Eigenvalues (variances along PCs).
      3. Project data onto top-kkk eigenvectors.

    • Key Points:

      • PCs are eigenvectors of the covariance matrix.
      • PCs form an orthogonal basis.
      • Maximizes variance sequentially.

  1. Convex Sets & Functions

    • Convex Set: A set SSS where for any x,y∈Sx, y \in Sx,y∈S and θ∈[0,1]\theta \in [0,1]θ∈[0,1], θx+(1−θ)y∈S\theta x + (1-\theta)y \in Sθx+(1−θ)y∈S.

      • Examples:

        • Hyperplanes (∑aixi=b\sum a_i x_i = b∑ai​xi​=b) are convex.
        • Lines in R2\mathbb{R}^2R2 are convex.
        • Non-examples: Unions of convex sets, arbitrary curves.

    • Convex Function: A function fff where for any x,yx, yx,y and θ∈[0,1]\theta \in [0,1]θ∈[0,1], f(θx+(1−θ)y)≤θf(x)+(1−θ)f(y)f(\theta x + (1-\theta)y) \leq \theta f(x) + (1-\theta)f(y)f(θx+(1−θ)y)≤θf(x)+(1−θ)f(y).

      • Examples:

        • exe^xex, ex2+2e^{x^2+2}ex2+2, x2x^2x2.
        • Non-examples: cos⁡(x)\cos(x)cos(x), compositions of convex functions (not always convex).

  1. Lagrange Multipliers & KKT Conditions

    • General Form: For min⁡f(x)\min f(x)minf(x) subject to g(x)=0g(x) = 0g(x)=0 and h(x)≤0h(x) \leq 0h(x)≤0, the Lagrangian is: L(x,α,β)=f(x)+αg(x)+βh(x)L(x, \alpha, \beta) = f(x) + \alpha g(x) + \beta h(x)L(x,α,β)=f(x)+αg(x)+βh(x).

    • KKT Conditions:

4. Exam Tips

  1. Probability: Focus on CDF/PDF properties, linear transformations of Gaussians, and expectation rules.
  2. Linear Algebra: SVD/PCA properties are high-yield (e.g., singular values, eigenvectors).
  3. Optimization: Know KKT conditions cold (stationarity, complementary slackness).
  4. Convexity: Test functions using the definition (e.g., exe^xex is convex; cos⁡(x)\cos(x)cos(x) is not).
  5. Calculus: Parameterization (e.g., cylinders) and gradient descent updates are key.
