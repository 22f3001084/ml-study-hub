Here’s a structured summary of core topics, concepts, principles, and equations essential for the Diploma-Level Machine Learning Techniques exam, based on the provided question paper. The exam focuses on clustering (K-means, Lloyd’s algorithm), PCA, Bayesian inference, kernel methods, and basic linear algebra.

1. Core Topics & Key Concepts

A. Clustering (K-means & Lloyd’s Algorithm)

  • Lloyd’s Algorithm (K-means):

    • Iterative algorithm to partition data into K clusters by minimizing within-cluster variance.

    • Steps:

      1. Initialize cluster centers (e.g., randomly or via K-means++).
      2. Assign points to the nearest center (Euclidean distance).
      3. Recompute centers as the mean of assigned points.
      4. Repeat until convergence (centers stabilize).

    • Convergence:

      • Guaranteed to converge (monotonically decreases objective function), but may reach local optima (sensitive to initialization).
      • Not guaranteed to find the global optimum.

    • Sensitivity to Outliers:

      • Outliers can distort cluster centers (since centers are means).
    • Time Complexity: O(n·K·I·d), where n = samples, K = clusters, I = iterations, d = dimensions.

  • Initialization Strategies:

    • Random initialization may lead to poor convergence.
    • K-means++: Probabilistically selects initial centers to spread them out (reduces variance in results).

  • Tie-Breaking in K-means:

    • If a point is equidistant to multiple centers, the tie-breaking rule (e.g., assign to the first center) can affect final clusters.

B. Principal Component Analysis (PCA)

  • Goal: Reduce dimensionality while preserving variance.

  • Steps:

    1. Standardize data (mean=0, variance=1).
    2. Compute covariance matrix Σ = XᵀX (if X is centered).

    3. Eigenvalue decomposition: Σ = VΛVᵀ, where:

      • Λ: Diagonal matrix of eigenvalues (sorted descending).
      • V: Matrix of eigenvectors (principal components, PCs).
    4. Project data onto top k PCs: X_proj = X·V_k (where V_k = first k columns of V).

  • Key Properties:

    • Eigenvalues: Represent variance along PCs.
    • Reconstruction: X_recon = X_proj·V_kᵀ (zero residue only if all PCs are used).
    • Total Variance: Sum of all eigenvalues = total variance of the dataset.
    • Number of Non-Zero Eigenvalues: Equals the rank of the covariance matrix (≤ min(n, d)).

  • Example:

    • If Σ has eigenvalues [4.5, 0.5, 0], the first PC captures 4.5 units of variance, and the second captures 0.5.

C. Bayesian Inference (Beta Distribution)

  • Beta Distribution: Conjugate prior for binomial likelihood.

    • PDF: Beta(α, β) ∝ x^(α-1)(1-x)^(β-1).
    • Posterior Mean: For Beta(α, β), the mean is α/(α+β).

    • Example:

      • Beta(1,1) = Uniform(0,1). Posterior mean = 1/(1+1) = 0.5 (but in Q5, the posterior mean is given as ~0.039, suggesting a non-standard update—likely involving observed data).
      • Beta(0.5,0.5): U-shaped distribution. Posterior mean depends on data.

  • Posterior Update:

    • If data has s successes and f failures, posterior is Beta(α+s, β+f).
    • Key Equation:

D. Kernel Methods

  • Kernel Trick: Map data to a higher-dimensional space where it becomes linearly separable.

  • Valid Kernels: Must satisfy Mercer’s condition (positive semi-definite kernel matrix).

    • Common kernels:

      1. Linear: K(x, y) = xᵀy.
      2. Polynomial: K(x, y) = (xᵀy + c)^d.
      3. RBF/Gaussian: K(x, y) = exp(-γ||x-y||²).
      4. Sigmoid: K(x, y) = tanh(κxᵀy + c).
    • Note: Q6 asks for valid kernels (correct answers: A, B, D—likely referring to standard kernels).

E. Covariance Matrix & Multivariate Data

  • Covariance Matrix (Σ):

    • For data X ∈ ℝ^(n×d), Σ = (X - μ)ᵀ(X - μ) / (n-1)* (sample covariance).
    • Diagonal entries = variances; off-diagonal = covariances.

  • Example (from Q9–Q13):

    • Given a dataset, compute Σ, then perform PCA to find eigenvalues/variances.

F. K-means Practical Examples

  • Convergence in 1 Iteration:

    • If initial centers are already the means of their Voronoi partitions, the algorithm converges immediately (Q4C).

  • Effect of New Data Points:

    • Adding (0,0) to the dataset in Q15 changes cluster assignments, but with the given initial centers, convergence happens in 1 iteration.

4. Exam Tips

  1. K-means:

    • Remember it always converges but may not find the global optimum.
    • Outliers distort centers (since centers are means).
    • Initialization matters (K-means++ is better than random).

  1. PCA:

    • Number of non-zero eigenvalues = rank of the covariance matrix.
    • Total variance = sum of all eigenvalues.
    • Reconstruction is lossless only if all PCs are used.

  1. Bayesian Inference:

    • For Beta(α, β), the mean is α/(α+β).
    • Posterior updates depend on observed data (successes/failures).

  1. Kernels:

    • Valid kernels must be positive semi-definite.
    • Common kernels: Linear, Polynomial, RBF, Sigmoid.

  1. Covariance Matrix:

    • Diagonal entries = variances; off-diagonal = covariances.
    • Always center the data before computing PCA.

  1. Practical Questions:

    • For K-means with given initial centers, manually compute assignments and updates to find final centers.
    • For PCA, compute eigenvalues of the covariance matrix to find variances.
