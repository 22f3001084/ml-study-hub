Core Topics & Key Concepts

1. Clustering (K-Means, K-Means++, Lloyd’s Algorithm)

  • K-Means Algorithm:

    • Iterative partitioning into K clusters by minimizing within-cluster variance.

    • Steps:

      1. Initialize centroids (randomly or via K-Means++).
      2. Assign points to nearest centroid (Euclidean distance).
      3. Recompute centroids as mean of assigned points.
      4. Repeat until convergence (centroids stabilize).
    • Convergence: Guaranteed (monotonically decreases objective function), but may converge to local optima.
    • Sensitivity to Outliers: Yes (outliers can skew centroids).

  • K-Means++ Initialization:

    • Improves convergence by spreading initial centroids.
    • Probability of selection: Proportional to squared distance from existing centroids.
    • Score function:
S(x)=min⁡j=1,…,l−1∥x−μj0∥2S(x) = \min_{j=1,\ldots,l-1} \|x - \mu_j^0\|^2S(x)=j=1,…,l−1min​∥x−μj0​∥2
  • Tie-breaking: Affects final clusters if distances are equal.

  • Lloyd’s Algorithm:

    • Synonym for standard K-Means.

    • Properties:

      • Converges for any initialization (but may not be globally optimal).
      • Sensitive to outliers.

2. Principal Component Analysis (PCA)

  • Goal: Dimensionality reduction while preserving variance.

  • Steps:

    1. Center the data (subtract mean).
    2. Compute covariance matrix Σ=1n−1XTX\Sigma = \frac{1}{n-1} X^T XΣ=n−11​XTX.

    3. Eigen decomposition: Σ=VΛVT\Sigma = V \Lambda V^TΣ=VΛVT, where:

      • VVV: Eigenvectors (principal components, PCs).
      • Λ\LambdaΛ: Eigenvalues (variances along PCs).
    4. Project data onto top-k PCs.

  • Key Properties:

    • PCs are orthogonal.
    • First PC captures maximum variance.
    • Reconstruction error: Zero if k=rank(X)k = \text{rank}(X)k=rank(X).
    • Variance explained by PC_i:
Proportion=λi∑j=1dλj\text{Proportion} = \frac{\lambda_i}{\sum_{j=1}^d \lambda_j}Proportion=∑j=1d​λj​λi​​
  • Linear Subspace: If data lies in a k-dimensional subspace, only k eigenvalues are non-zero.

  • Example:

    • For a dataset in R50\mathbb{R}^{50}R50 lying in a 6D subspace, PCA yields 6 non-zero eigenvalues.

4. Kernel Methods

  • Valid Kernels (must satisfy Mercer’s condition):

    1. Gaussian (RBF) Kernel:

Exam Tips

  1. K-Means: Know convergence properties, initialization (K-Means++), and sensitivity to outliers.
  2. PCA: Focus on eigenvalues/variance explained, reconstruction error, and linear subspaces.
  3. GMM/EM: Understand the likelihood function, responsibilities, and parameter updates.
  4. Kernels: Memorize valid kernels (RBF, polynomial, Laplacian) and invalid ones (e.g., ∣x−y∣|x-y|∣x−y∣).
  5. Bayesian Estimation: Practice calculating posterior means for Beta priors.
  6. Toy Datasets: Compute covariance matrices and PCA manually for small datasets (e.g., 2D points).
