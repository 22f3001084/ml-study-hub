Core Topics & Key Concepts

1. Linear Programming (Optimization)

  • Primal Problem Formulation:

    • Objective: Minimize/maximize a linear function (e.g., cost: 4x+3y4x + 3y4x+3y).
    • Constraints: Linear inequalities (e.g., 2x+y≤802x + y \leq 802x+y≤80, x+3y≤90x + 3y \leq 90x+3y≤90).
    • Non-negativity: x,y≥0x, y \geq 0x,y≥0.
  • Feasible Region: Intersection of constraints (convex set).
  • Optimal Solution: Vertex of the feasible region (use graphical method or simplex algorithm).
  • Key Equation:
Minimize cTxsubject to Ax≤b, x≥0\text{Minimize } c^T x \quad \text{subject to } Ax \leq b, \, x \geq 0Minimize cTxsubject to Ax≤b,x≥0

3. Optimization in Geometry

  • Maximizing Area with Constraints:

    • Example: Fence problem (rectangle against a wall).

    • Steps:

      1. Define variables (e.g., length LLL, width WWW).
