1. Machine Learning Foundations

Core Topics:

  • Supervised Learning:

    • Classification vs. Regression:

      • Classification: Maps input xxx to discrete output yyy (e.g., decision boundaries).
      • Regression: Maps input xxx to continuous output yyy (e.g., best-fit line).

      • Key Equation:

        • Regression: y=wTx+by = w^T x + by=wTx+b (linear regression).
        • Classification: y^=sign(wTx+b)\hat{y} = \text{sign}(w^T x + b)y^​=sign(wTx+b) (linear classifier).

    • Types of Classifiers:

      • Linear (e.g., SVM, logistic regression) vs. Non-linear (e.g., kernel SVM, decision trees).

    • Types of Regression:

      • Linear, polynomial, ridge/lasso (regularized).

  • Unsupervised Learning:

    • PCA (Principal Component Analysis):

      • Projection onto lines/planes to minimize reconstruction error.

      • Key Equation:

        • Covariance matrix: C=1n∑i=1n(xi−μ)(xi−μ)TC = \frac{1}{n} \sum_{i=1}^n (x_i - \mu)(x_i - \mu)^TC=n1​∑i=1n​(xi​−μ)(xi​−μ)T.

      • Example: For C=[4224]C = \begin{bmatrix} 4 & 2 \\ 2 & 4 \end{bmatrix}C=[42​24​], error = λ2=2\lambda_2 = 2λ2​=2.

  • Optimization:

    • Linear Programming:

      • Minimize/maximize a linear objective subject to constraints.

      • Example:

        • Minimize 50x1+80x250x_1 + 80x_250x1​+80x2​ s.t. x1+x2>12x_1 + x_2 > 12x1​+x2​>12, x1≤6x_1 \leq 6x1​≤6, x2≤10x_2 \leq 10x2​≤10.
