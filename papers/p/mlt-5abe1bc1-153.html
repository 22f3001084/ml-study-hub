Core Topics & Key Concepts

1. Clustering (K-Means, K-Means++, Lloyd’s Algorithm)

  • Lloyd’s Algorithm (K-Means):

    • Iterative algorithm to minimize within-cluster variance.
    • Convergence: Always converges (monotonically decreases objective function), but may reach local optima.
    • Sensitivity: Outliers can distort centroids.
    • Initialization: K-Means++ improves initialization by selecting centers probabilistically based on distances.

    • Equation:

      • Objective: Minimize ∑i=1nmin⁡μj∈C∥xi−μj∥2\sum_{i=1}^n \min_{\mu_j \in C} \|x_i - \mu_j\|^2∑i=1n​minμj​∈C​∥xi​−μj​∥2.
      • K-Means++ selection probability: P(x)=S(x)2∑x′S(x′)2P(x) = \frac{S(x)^2}{\sum_{x'} S(x')^2}P(x)=∑x′​S(x′)2S(x)2​, where S(x)=min⁡j∥x−μj∥2S(x) = \min_j \|x - \mu_j\|^2S(x)=minj​∥x−μj​∥2.

  • Key Observations:

    • Convergence depends on initialization (Option B in Q2).
    • Outliers can skew results (Option C in Q2).
    • K-Means++ reduces sensitivity to initialization.

2. Principal Component Analysis (PCA)

  • Purpose: Dimensionality reduction by projecting data onto orthogonal axes (principal components) that maximize variance.

  • Key Properties:

    • Eigenvalues of the covariance matrix Σ\SigmaΣ represent variance along principal components.
    • If data lies in a kkk-dimensional subspace, only kkk eigenvalues are non-zero.
    • Reconstruction error vanishes if all non-zero components are retained.

  • Equations:

    • Covariance matrix: Σ=1nXTX\Sigma = \frac{1}{n} X^T XΣ=n1​XTX (for centered data XXX).
    • Proportion of variance explained by iii-th PC: λi∑jλj\frac{\lambda_i}{\sum_j \lambda_j}∑j​λj​λi​​.
    • Reconstruction: X≈UkΣkVkTX \approx U_k \Sigma_k V_k^TX≈Uk​Σk​VkT​ (truncated SVD).

  • Key Observations:

    • For data in a 6D subspace of R50\mathbb{R}^{50}R50, only 6 eigenvalues are non-zero (Q3: Options B, D).
    • Total variance = sum of all eigenvalues (Q3: Option D).
    • Linear dependencies reduce the rank of Σ\SigmaΣ (Q7: k=3k = 3k=3).

3. Bayesian Statistics (Beta Distribution, Posterior Estimation)

  • Beta Distribution as Prior:

    • Used for modeling proportions (e.g., defect rate θ\thetaθ).
    • Prior: θ∼Beta(a,b)\theta \sim \text{Beta}(a, b)θ∼Beta(a,b).
    • Posterior: θ∣data∼Beta(a+successes,b+failures)\theta | \text{data} \sim \text{Beta}(a + \text{successes}, b + \text{failures})θ∣data∼Beta(a+successes,b+failures).
    • Posterior Mean: E[θ]=a+successesa+b+n\mathbb{E}[\theta] = \frac{a + \text{successes}}{a + b + n}E[θ]=a+b+na+successes​.

  • Key Observations:

    • For Beta(1,1)\text{Beta}(1,1)Beta(1,1) (uniform prior) and 3 defects in 100 samples: E[θ]=1+31+1+100=0.039\mathbb{E}[\theta] = \frac{1 + 3}{1 + 1 + 100} = 0.039E[θ]=1+1+1001+3​=0.039 (Q5: Option A).
    • For Beta(0.5,0.5)\text{Beta}(0.5, 0.5)Beta(0.5,0.5): E[θ]=0.5+30.5+0.5+100≈0.034\mathbb{E}[\theta] = \frac{0.5 + 3}{0.5 + 0.5 + 100} \approx 0.034E[θ]=0.5+0.5+1000.5+3​≈0.034 (Q5: Option D).

4. Kernel Methods

  • Valid Kernels (Mercer’s Condition):

    • Must be symmetric and positive semi-definite.

    • Examples:

      • Gaussian (RBF) kernel: K(x,y)=exp⁡(−∥x−y∥22σ2)K(x, y) = \exp\left(-\frac{\|x-y\|^2}{2\sigma^2}\right)K(x,y)=exp(−2σ2∥x−y∥2​) (Option A).
      • Polynomial kernel: K(x,y)=(x⋅y+c)dK(x, y) = (x \cdot y + c)^dK(x,y)=(x⋅y+c)d (Option B).
      • Laplacian kernel: K(x,y)=exp⁡(−∥x−y∥σ)K(x, y) = \exp\left(-\frac{\|x-y\|}{\sigma}\right)K(x,y)=exp(−σ∥x−y∥​) (Option D).
    • Invalid Kernel: K(x,y)=∣x−y∣K(x, y) = |x - y|K(x,y)=∣x−y∣ (not PSD) (Option C in Q6).

5. Gaussian Mixture Models (GMM) & EM Algorithm

  • Likelihood Function:

    • For GMM with KKK components: L(θ)=∏i=1n∑k=1KπkN(xi∣μk,Σk)L(\theta) = \prod_{i=1}^n \sum_{k=1}^K \pi_k \mathcal{N}(x_i | \mu_k, \Sigma_k)L(θ)=∏i=1n​∑k=1K​πk​N(xi​∣μk​,Σk​).
    • Log-Likelihood: Easier to maximize (avoids underflow).

  • EM Algorithm Steps:

    1. E-Step: Compute responsibilities γ(zik)\gamma(z_{ik})γ(zik​).
    2. M-Step: Update πk,μk,Σk\pi_k, \mu_k, \Sigma_kπk​,μk​,Σk​ using γ(zik)\gamma(z_{ik})γ(zik​).

  • Key Observations:

    • Likelihood involves a product of sums (Q12: Option B).
    • Responsibilities λik\lambda_{ik}λik​ are proportional to πkN(xi∣μk,Σk)\pi_k \mathcal{N}(x_i | \mu_k, \Sigma_k)πk​N(xi​∣μk​,Σk​) (Q13).

7. K-Means Practical Applications

  • Convergence in Iterations:

    • K-Means converges when cluster assignments stabilize.
    • Adding a point (e.g., (0,0)(0,0)(0,0)) may change cluster assignments, but convergence can still be fast (Q15: 1 iteration).

  • Final Cluster Centers:

    • Depends on initial centers and data distribution (Q14: Option A).

Exam Tips

  1. PCA: Focus on eigenvalues, variance explained, and reconstruction error.
  2. K-Means: Understand convergence, initialization (K-Means++), and sensitivity to outliers.
  3. Bayesian Statistics: Memorize the Beta distribution’s posterior mean formula.
  4. Kernels: Recognize valid kernels (Gaussian, polynomial, Laplacian) and invalid ones (e.g., ∣x−y∣|x-y|∣x−y∣).
  5. GMM/EM: Know the likelihood function and the E/M steps.
  6. Covariance Matrix: Practice calculating it from data points (Q9).
