B. Unsupervised Learning

  1. K-Means Clustering

    • Concept: Partitions data into KKK clusters by minimizing within-cluster variance.

    • Key Equation:

      • Objective: min⁡∑i=1n∥xi−μzi∥2\min \sum_{i=1}^n \|x_i - \mu_{z_i}\|^2min∑i=1n​∥xi​−μzi​​∥2.

  1. Principal Component Analysis (PCA)

    • Concept: Dimensionality reduction via eigen decomposition of covariance matrix.

    • Key Equation:

      • Covariance matrix: C=1nXTXC = \frac{1}{n} X^T XC=n1​XTX.

C. Probabilistic Models

  1. Naive Bayes

    • Concept: Assumes feature independence given the class. Uses MLE for parameter estimation.

    • Key Equation:

      • P(y∣x)∝P(y)∏iP(xi∣y)P(y|x) \propto P(y) \prod_i P(x_i|y)P(y∣x)∝P(y)∏i​P(xi​∣y).
    • Example: Question 17 (parameter counting), Question 18 (prediction with Laplace smoothing).

  1. Maximum A Posteriori (MAP) Estimation

    • Concept: Bayesian parameter estimation with a prior.

    • Key Equation:

      • λ^MAP=arg⁡max⁡λP(λ∣X)\hat{\lambda}_{MAP} = \arg \max_\lambda P(\lambda|X)λ^MAP​=argmaxλ​P(λ∣X).
    • Example: Question 14 (exponential distribution with uniform prior).

D. Ensemble Methods

  1. Random Forest

    • Concept: Aggregates predictions from multiple decision trees via averaging (regression) or voting (classification).
    • Example: Question 13 (probability averaging).

E. Decision Trees

  1. Decision Tree Algorithm

    • Concept: Recursively splits data based on feature thresholds. Prone to overfitting if unconstrained.

    • Key Points:

      • Handles numerical/categorical features.
      • Sensitive to data perturbations.
    • Example: Question 7 (properties of decision trees).

4. Exam-Specific Tips

  1. Perceptron/SVM:

    • For convergence (Question 2), cycle through data points and update weights manually.
    • For kernels (Question 3), match terms in k(x,y)k(x, y)k(x,y) to ϕ(x)Tϕ(y)\phi(x)^T \phi(y)ϕ(x)Tϕ(y).
    • Support vectors (Question 4) are points where yi(wTxi)=1y_i(w^T x_i) = 1yi​(wTxi​)=1.

  1. K-Means:

    • Greedy initialization (Question 5) does not guarantee optimality but can achieve FoptimalF_{optimal}Foptimal​ depending on data.

  1. Neural Networks:

    • Compute hidden layer outputs step-by-step (Question 6). ReLU: max⁡(0,z)\max(0, z)max(0,z); Sigmoid: 1/(1+e−z)1/(1 + e^{-z})1/(1+e−z).

  1. Decision Trees:

    • Overfitting (Question 7) is controlled by max depth/pruning. Trees handle mixed feature types.

  1. Probabilistic Models:

    • For Naive Bayes (Questions 17–18), count parameters as (d+1)×c(d + 1) \times c(d+1)×c (where ddd = features, ccc = classes).
    • MAP estimation (Question 14) for exponential distribution: Posterior∝Likelihood×Prior\text{Posterior} \propto \text{Likelihood} \times \text{Prior}Posterior∝Likelihood×Prior.

  1. Regression:

    • Ridge regression (Questions 15–16): As λ↓\lambda \downarrowλ↓, coefficients approach OLS solution.

  1. PCA:

    • Total variance (Question 11) is the sum of eigenvalues. Solve the system of equations for λi\lambda_iλi​.
