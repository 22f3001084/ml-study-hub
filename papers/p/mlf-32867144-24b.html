1. Core Topics & Concepts

A. Machine Learning Basics

  1. Supervised Learning

    • Classification (e.g., loan approval: Yes/No based on features like income, credit score).

      • Algorithms: Logistic Regression, Decision Trees, SVM, k-NN.

    • Regression (predicting continuous values, e.g., house prices).

      • Algorithms: Linear Regression, Polynomial Regression.

    • Loss Functions:

      • Squared Loss (MSE): L(y,y^)=(y−y^)2L(y, \hat{y}) = (y - \hat{y})^2L(y,y^​)=(y−y^​)2 (used in regression).
      • Log Loss (Cross-Entropy): Used in classification.

  1. Unsupervised Learning

    • Clustering (e.g., customer segmentation).

      • Algorithms: k-Means, Hierarchical Clustering.
    • Dimensionality Reduction (e.g., PCA, t-SNE).

  1. Model Evaluation

    • Overfitting/Underfitting.
    • Train-Test Split, Cross-Validation.

B. Linear Algebra (Critical for ML)

  1. Matrices & Vectors

    • Row Space: Span of the rows of a matrix AAA.

    • Basis: Linearly independent vectors that span a space.

      • Example: For A=[10201−100−1]A = \begin{bmatrix} 1 & 0 & 2 \\ 0 & 1 & -1 \\ 0 & 0 & -1 \end{bmatrix}A=​100​010​2−1−1​​, a basis for the row space is {(1,0,2), (0,1,-1), (0,0,-1)}.
    • Rank: Number of linearly independent rows/columns.

  1. Matrix Properties

    • Orthogonal Matrix: ATA=IA^T A = IATA=I (columns are orthonormal).
    • Invertible Matrix: det⁡(A)≠0\det(A) \neq 0det(A)=0, AA−1=IAA^{-1} = IAA−1=I.
    • Symmetric Matrix: A=ATA = A^TA=AT.

    • Eigenvalues/Eigenvectors:

      • Av=λvA \mathbf{v} = \lambda \mathbf{v}Av=λv.
      • Real Symmetric Matrices: Always have real eigenvalues.
      • Diagonalizable Matrix: A=PDP−1A = PDP^{-1}A=PDP−1 (requires nnn linearly independent eigenvectors, not necessarily distinct eigenvalues).

  1. Special Matrices

    • Positive Definite: All eigenvalues > 0.
    • Singular Matrix: det⁡(A)=0\det(A) = 0det(A)=0 (non-invertible).

C. Calculus & Optimization (For ML Models)

  1. Gradient Descent:

    • Update rule: θ=θ−α∇J(θ)\theta = \theta - \alpha \nabla J(\theta)θ=θ−α∇J(θ).
    • Used to minimize loss functions (e.g., MSE, Log Loss).

  1. Partial Derivatives:

    • Critical for computing gradients in multivariate functions.

D. Probability & Statistics (For ML)

  1. Probability Distributions:

    • Gaussian (Normal), Bernoulli, Binomial.

  2. Bayes’ Theorem:

    • P(A∣B)=P(B∣A)P(A)P(B)P(A|B) = \frac{P(B|A)P(A)}{P(B)}P(A∣B)=P(B)P(B∣A)P(A)​.

  3. Maximum Likelihood Estimation (MLE):

    • Finds parameters that maximize the likelihood of observed data.

4. Exam Tips

  1. Classification vs. Regression:

    • Use classification for discrete outputs (e.g., Yes/No).
    • Use regression for continuous outputs (e.g., house price).

  1. Linear Algebra:

    • A matrix is invertible iff det⁡(A)≠0\det(A) \neq 0det(A)=0.
    • A matrix is orthogonal iff ATA=IA^T A = IATA=I.
    • Real symmetric matrices always have real eigenvalues.
    • Diagonalizable ≠ n distinct eigenvalues (only needs nnn linearly independent eigenvectors).

  1. Basis & Row Space:

    • A basis must be linearly independent and span the space.
    • Example: For A=[10201−1000]A = \begin{bmatrix} 1 & 0 & 2 \\ 0 & 1 & -1 \\ 0 & 0 & 0 \end{bmatrix}A=​100​010​2−10​​, the row space basis is {(1,0,2), (0,1,-1)}.

  1. Eigenvalues:

    • If a matrix has complex eigenvalues, it’s not diagonalizable over the reals.
    • Symmetric matrices are always diagonalizable.

  1. Gradient Descent:

    • Smaller learning rate (α\alphaα) ⇒ slower convergence.
    • Too large α\alphaα ⇒ divergence.

  1. True/False Questions:

    • "Diagonalizable ⇒ Invertible"? False (e.g., zero matrix is diagonalizable but singular).
    • "Real symmetric ⇒ real eigenvalues"? True.
    • "n distinct eigenvalues ⇒ diagonalizable"? True, but the converse is false.
