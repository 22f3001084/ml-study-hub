1. Core Topics & Key Concepts

A. Linear Programming (Optimization)

  • Primal Problem Formulation:

    • Objective: Minimize/maximize a linear function (e.g., cost/profit).
    • Constraints: Linear inequalities (resource limits).
    • Non-negativity: Variables ≥ 0.

    • Example (Q2, Q3):

      Minimize: 2x + 3y
Subject to:
  2x + y ≤ 90 (labor hours),
  x + 3y ≤ 80 (machine hours),
  x, y ≥ 0.
    • Solution Method: Graphical (for 2D) or Simplex algorithm.
  • Dual Problem: Not directly tested here, but useful for sensitivity analysis.

B. Convex Sets & Functions

  • Convex Set (Q4):

    • A set where the line segment joining any two points lies entirely within the set.

    • Examples:

      • Semicircle (Q4B), Triangle (Q4C).
      • Non-examples: "V" shape (Q4D), disjoint circles (Q4A).

  • Convex Function (Q5):

    • A function where the line segment between any two points on the graph lies above the graph.

    • Tests:

      • Quadratic Forms: f(v)=vTAvf(v) = v^T A vf(v)=vTAv is convex if matrix AAA is positive semidefinite (e.g., Q5B, Q5D).
      • Hessian Matrix: For f(x,y)=x2+y2+3f(x, y) = x^2 + y^2 + 3f(x,y)=x2+y2+3, the Hessian is [2002]\begin{bmatrix} 2 & 0 \\ 0 & 2 \end{bmatrix}[20​02​] (positive definite → convex).
      • Product of Convex Functions: Not necessarily convex (e.g., Q5A is not convex).

C. Probability & Statistics

  • Chebyshev’s Inequality (Q7):

    • Bounds the probability of a random variable deviating from its mean.

    • Formula:

      P(|X - μ| ≥ kσ) ≤ 1/k²

    • Example: For μ=70μ = 70μ=70, σ=8σ = 8σ=8, k=2k = 2k=2:

      P(|X - 70| ≥ 16) ≤ 1/4 = 0.25.

E. Optimization in Geometry

  • Maximizing Area with Constraints (Q6):

    • Problem: Fence 3 sides of a rectangle with 120m (river on 4th side).

    • Solution:

      • Let sides be xxx (parallel to river) and yyy (perpendicular).
      • Constraint: x+2y=120x + 2y = 120x+2y=120.
      • Area: A=xy=y(120−2y)A = xy = y(120 - 2y)A=xy=y(120−2y).

      • Maximize by setting derivative dA/dy=0dA/dy = 0dA/dy=0:

        120 - 4y = 0 → y = 30, x = 60.
      • Max Area: 60×30=180060 \times 30 = 180060×30=1800 m².

F. Machine Learning Basics

  • Linear Regression Loss (Q8):

    • Loss Function: Mean Squared Error (MSE):

      L = \frac{1}{n} \sum_{i=1}^n (f(\mathbf{x}^i) - y^i)².
    • Example: For f(x)=x1+2x2+x3f(\mathbf{x}) = x_1 + 2x_2 + x_3f(x)=x1​+2x2​+x3​, compute predictions and compare to yyy.

  • Principal Component Analysis (PCA) (Q12):

    • Goal: Project data onto lower-dimensional subspace to maximize variance (or minimize reconstruction error).

    • Steps:

      1. Center the data.
      2. Compute covariance matrix.
      3. Eigen decomposition to find principal components.

    • Key Points:

      • Reduces dimensionality (Q12C).
      • Maximizes variance of projection (Q12A).
      • Does not maximize reconstruction error (Q12D is false).

  • Least Squares Minimization (Q11):
