A. Clustering Algorithms

1. K-Means & K-Means++

  • Lloyd’s Algorithm (K-Means):

    • Optimality: Does not guarantee global optimum (depends on initialization).

B. Dimensionality Reduction (PCA)

1. Principal Component Analysis (PCA)

  • Goal: Find orthogonal axes (principal components) that maximize variance.

  • Steps:

    1. Center the data (subtract mean).
    2. Compute covariance matrix S=1n−1XTXS = \frac{1}{n-1} X^T XS=n−11​XTX.

    3. Eigendecomposition: S=UΛUTS = U \Lambda U^TS=UΛUT, where:

      • UUU: Matrix of eigenvectors (principal components).
      • Λ\LambdaΛ: Diagonal matrix of eigenvalues (variances).
    4. Project data onto top-kkk eigenvectors.
  • Variance Explained:
Proportion of variance=λi∑j=1dλj\text{Proportion of variance} = \frac{\lambda_i}{\sum_{j=1}^{d} \lambda_j}Proportion of variance=∑j=1d​λj​λi​​

  • Reconstruction Error (Residue):

    • If data lies in a kkk-dimensional subspace, the first kkk PCs capture all variance.
    • Eigenvalues = 0 for dimensions beyond intrinsic dimensionality.

2. Key Properties

  • Covariance Matrix Rank:

    • If data lies in a kkk-dimensional subspace, covariance matrix has kkk non-zero eigenvalues.

  • Example:

    • If all points lie in a 6D subspace in R50\mathbb{R}^{50}R50, PCA yields:

      • 6 non-zero eigenvalues.
      • First 6 PCs capture 100% variance.

4. Exam Tips

  1. PCA:

    • If data lies in a kkk-dimensional subspace, first kkk PCs capture all variance.
    • Eigenvalues = 0 for redundant dimensions.

  2. K-Means:

    • Converges always but may not find the global optimum.
    • K-Means++ improves initialization by weighting distances.

  3. GMM:

    • Likelihood involves sum over components (mixture model).
    • EM alternates between E-step (expectation) and M-step (maximization).

  4. Bayesian Estimation:

    • Posterior mean is the estimate for θ\thetaθ.
    • Beta prior is conjugate for Binomial likelihood.

  5. Kernels:

    • RBF, Polynomial, Laplacian are valid.
    • Absolute difference is not a valid kernel.
