Here’s a structured summary of core topics, concepts, principles, and equations for the "Diploma Level: Machine Learning Foundations" exam, based on the provided question paper. The exam covers Machine Learning (ML) basics, Linear Algebra, and Mathematical Foundations. --- ---

1. Machine Learning Foundations

Core Topics & Concepts

  1. Supervised Learning

    • Classification (Q2):

      • Predicts discrete labels (e.g., loan approval: "Yes/No").
      • Algorithms: Logistic Regression, Decision Trees, SVM, k-NN.
      • Key Idea: Map input features (e.g., income, credit score) to a class.

    • Regression:

      • Predicts continuous values (e.g., house price).
      • Algorithms: Linear Regression, Polynomial Regression.

    • Loss Functions (Q8):

      • Squared Loss (MSE): L(y,y^)=(y−y^)2L(y, \hat{y}) = (y - \hat{y})^2L(y,y^​)=(y−y^​)2.
      • Used in regression to measure prediction error.

  1. Unsupervised Learning

    • Clustering (Q2 option C):

      • Groups similar data points (e.g., customer segmentation).
      • Algorithms: k-Means, Hierarchical Clustering.

    • Dimensionality Reduction (Q2 option D):

      • Reduces feature space (e.g., PCA, t-SNE).

  1. Model Evaluation

    • Bias-Variance Tradeoff:

      • Bias: Error due to overly simplistic assumptions.
      • Variance: Error due to excessive sensitivity to training data.

    • Overfitting/Underfitting (Q9):

      • Overfitting: Model performs well on training data but poorly on test data (e.g., high-degree polynomial).
      • Underfitting: Model is too simple to capture patterns.

2. Linear Algebra

Core Topics & Equations

  1. Matrix Basics

    • Row Space: Span of a matrix’s rows.

      • Basis (Q10): Linearly independent rows that span the row space.
      • Example: For matrix AAA, basis = {(1,0,2),(0,1,−1),(0,0,−1)}\{(1,0,2), (0,1,-1), (0,0,-1)\}{(1,0,2),(0,1,−1),(0,0,−1)}.
    • Rank: Number of linearly independent rows/columns.

    • Invertibility (Q12, Q14, Q16):

      • A square matrix AAA is invertible iff det⁡(A)≠0\det(A) \neq 0det(A)=0.
      • Not all diagonalizable matrices are invertible (Q14: False).

  1. Special Matrices

    • Orthogonal Matrix (Q12 option A):

      • ATA=IA^T A = IATA=I (columns are orthonormal).
      • Preserves vector lengths: ∥Ax∥=∥x∥\|Ax\| = \|x\|∥Ax∥=∥x∥.

    • Symmetric Matrix (Q12 option C, Q13, Q15):

      • A=ATA = A^TA=AT.
      • Eigenvalues: Always real (Q15: True).
      • Diagonalizable: Always diagonalizable (even without distinct eigenvalues; Q16: False).

  1. Eigenvalues & Diagonalization (Q13, Q15, Q16)

    • Eigenvalue Equation: Av=λvA v = \lambda vAv=λv.

    • Diagonalizable Matrix:

      • A=PDP−1A = P D P^{-1}A=PDP−1, where DDD is diagonal.
      • Condition: Must have nnn linearly independent eigenvectors (not necessarily distinct eigenvalues; Q16: False).

    • Real Eigenvalues:

      • Guaranteed for symmetric matrices (Q15: True).
      • Not guaranteed for non-symmetric real matrices (Q13: Option A).

  1. Vector Spaces

    • Basis (Q10): Minimal spanning set for a subspace.
    • Linear Independence: No vector in the set can be written as a combination of others.
