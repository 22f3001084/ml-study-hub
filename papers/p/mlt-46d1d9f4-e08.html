Core Topics & Key Concepts

1. Perceptron Algorithm

  • Concept: Linear classifier for binary classification. Updates weights iteratively if misclassification occurs.

  • Key Equations:

    • Update rule: w←w+η⋅yixiw \leftarrow w + \eta \cdot y_i x_iw←w+η⋅yi​xi​ (if yi(wTxi)≤0y_i(w^T x_i) \leq 0yi​(wTxi​)≤0)
    • Decision boundary: wTx=0w^T x = 0wTx=0
  • Convergence: Guaranteed if data is linearly separable (Novikoff’s theorem).
  • Mistake Bound: Depends on margin and radius of data.

2. Kernel Methods & Feature Transformations

  • Concept: Non-linear mapping of input features to higher-dimensional space using kernel functions.

  • Key Equations:

    • Kernel trick: K(xi,xj)=ϕ(xi)Tϕ(xj)K(x_i, x_j) = \phi(x_i)^T \phi(x_j)K(xi​,xj​)=ϕ(xi​)Tϕ(xj​)

    • Transformation ϕ\phiϕ: Must satisfy k(x,y)=ϕ(x)Tϕ(y)k(x, y) = \phi(x)^T \phi(y)k(x,y)=ϕ(x)Tϕ(y).
  • Common Kernels: Linear, polynomial, RBF.

3. Support Vector Machines (SVM)

  • Hard-Margin SVM:

    • Objective: Maximize margin 2∣∣w∣∣\frac{2}{||w||}∣∣w∣∣2​.
    • Constraints: yi(wTxi+b)≥1y_i(w^T x_i + b) \geq 1yi​(wTxi​+b)≥1.
    • Support Vectors: Points lying on the margin.

  • Soft-Margin SVM:

    • Objective: min⁡12∣∣w∣∣2+C∑ϵi\min \frac{1}{2} ||w||^2 + C \sum \epsilon_imin21​∣∣w∣∣2+C∑ϵi​.
    • Constraints: yi(wTxi+b)≥1−ϵiy_i(w^T x_i + b) \geq 1 - \epsilon_iyi​(wTxi​+b)≥1−ϵi​, ϵi≥0\epsilon_i \geq 0ϵi​≥0.

    • Role of CCC:

      • C→0C \to 0C→0: Ignores misclassifications (no support vectors).
      • C→∞C \to \inftyC→∞: Hard-margin behavior (all points are support vectors if separable).

4. K-Means Clustering

  • Concept: Partitions data into KKK clusters by minimizing within-cluster variance.
  • Objective Function: F=∑i=1n∣∣xi−μzi∣∣2F = \sum_{i=1}^n ||x_i - \mu_{z_i}||^2F=∑i=1n​∣∣xi​−μzi​​∣∣2

  • Initialization:

    • Random: Pick KKK points randomly.
    • Greedy (K-Means++): First center random, next centers maximize distance.
  • Convergence: Guaranteed to local optimum (not necessarily global).

5. Neural Networks

  • Architecture:

    • Input layer → Hidden layers (ReLU, sigmoid, etc.) → Output layer.

  • Forward Propagation:

    • Hidden layer: h=ReLU(W(1)x)h = \text{ReLU}(W^{(1)} x)h=ReLU(W(1)x)
    • Output: y^=σ(W(out)h)\hat{y} = \sigma(W^{(out)} h)y^​=σ(W(out)h) (sigmoid for binary classification).
  • Prediction: Output is probability P(y=1)P(y=1)P(y=1).

6. Decision Trees

  • Concept: Recursive partitioning of feature space.

  • Key Properties:

    • Overfitting: Mitigated by limiting depth, pruning, or ensemble methods.
    • Feature Importance: Sensitive to small data perturbations.
    • Handling Data: Works for numerical and categorical features.

  • Model: P(y=1)=11+e−(wTx)P(y=1) = \frac{1}{1 + e^{-(w^T x)}}P(y=1)=1+e−(wTx)1​.

8. Random Forest

  • Concept: Ensemble of decision trees. Predicts by averaging probabilities.

  • Example (Q13):

  • MAP Estimation: λ^MAP=arg⁡max⁡λf(λ∣X)\hat{\lambda}_{\text{MAP}} = \arg \max_\lambda f(\lambda | X)λ^MAP​=argmaxλ​f(λ∣X).

10. Linear Regression & Ridge Regression

  • Ordinary Least Squares (OLS): w^ML=(XTX)−1XTY\hat{w}_{ML} = (X^T X)^{-1} X^T Yw^ML​=(XTX)−1XTY.

  • Ridge Regression: w^Ridge=(XTX+λI)−1XTY\hat{w}_{\text{Ridge}} = (X^T X + \lambda I)^{-1} X^T Yw^Ridge​=(XTX+λI)−1XTY.

    • Effect of λ\lambdaλ:

      • High λ\lambdaλ: Shrinks coefficients toward zero.
      • Low λ\lambdaλ: Coefficients approach OLS solution.

11. Naive Bayes

  • Concept: Assumes feature independence given class.

  • Parameters:

    • For binary features and classes: P(fi∣y)P(f_i | y)P(fi​∣y) for each feature-class pair.
    • Laplace Smoothing: Adds pseudo-counts to avoid zero probabilities.

  • Example (Q17-18):

    • 3 binary features → 2 (class priors) + 3 × 2 (feature probabilities) = 8 parameters.
    • With smoothing: 7 parameters (since one probability is determined by others).
