1. Core Topics & Concepts

A. Principal Component Analysis (PCA)

  • Key Idea: Dimensionality reduction by projecting data onto orthogonal axes (principal components) that maximize variance.

  • Eigenvalues of Covariance Matrix:

    • Represent variance along principal components.
    • Total variance = Sum of all eigenvalues.
    • Variance captured by top-k PCs = (Sum of top-k eigenvalues) / (Total variance).
  • Equation:
Variance captured (%)=∑i=1kλi∑i=1dλi×100\text{Variance captured (\%)} = \frac{\sum_{i=1}^k \lambda_i}{\sum_{i=1}^d \lambda_i} \times 100Variance captured (%)=∑i=1d​λi​∑i=1k​λi​​×100

(Where λi\lambda_iλi​ are eigenvalues, ddd is dimensionality.)

B. Regularization (Ridge Regression)

  • Key Idea: Penalize large weights to prevent overfitting.
  • Loss Function:
L(w)=SSE+λ∥w∥22L(\mathbf{w}) = \text{SSE} + \lambda \|\mathbf{w}\|_2^2L(w)=SSE+λ∥w∥22​

(SSE = Sum of Squared Errors, λ\lambdaλ = regularization strength.)

  • Plot Interpretation:

    • Training loss decreases with model complexity (lower λ\lambdaλ).
    • Test loss has a U-shape; optimal λ\lambdaλ minimizes it.
    • Best f(λ)f(\lambda)f(λ): λ\sqrt{\lambda}λ​ (balances scale for visualization).
