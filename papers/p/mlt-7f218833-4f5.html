1. Kernel Methods & Feature Transformations

  • Kernel Trick: Maps data to higher dimensions implicitly (e.g., polynomial kernels).
  • Kernel Function: k(x,y)=ϕ(x)Tϕ(y)k(\mathbf{x}, \mathbf{y}) = \phi(\mathbf{x})^T \phi(\mathbf{y})k(x,y)=ϕ(x)Tϕ(y) Example (Q2): k([x1,x2],[y1,y2])=1+x1y1+x12y12+x22y22k([x_1, x_2], [y_1, y_2]) = 1 + x_1 y_1 + x_1^2 y_1^2 + x_2^2 y_2^2k([x1​,x2​],[y1​,y2​])=1+x1​y1​+x12​y12​+x22​y22​ Corresponding Feature Map (Q2): ϕ([x1,x2])=[1,x1,x12,x22]\phi([x_1, x_2]) = [1, x_1, x_1^2, x_2^2]ϕ([x1​,x2​])=[1,x1​,x12​,x22​]

2. Bayesian Estimation

  • Prior/Posterior Distributions:

    • Prior: p(θ)p(\theta)p(θ) (e.g., Beta distribution for Bernoulli data).
    • Posterior: p(θ∣data)∝p(data∣θ)⋅p(θ)p(\theta | \text{data}) \propto p(\text{data} | \theta) \cdot p(\theta)p(θ∣data)∝p(data∣θ)⋅p(θ).
  • Bernoulli Likelihood: p(data∣p)=p# successes(1−p)# failuresp(\text{data} | p) = p^{\text{\# successes}} (1-p)^{\text{\# failures}}p(data∣p)=p# successes(1−p)# failures.
  • Beta-Bernoulli Conjugacy: Posterior is Beta with updated parameters: αpost=αprior+# successes\alpha_{\text{post}} = \alpha_{\text{prior}} + \text{\# successes}αpost​=αprior​+# successes, βpost=βprior+# failures\beta_{\text{post}} = \beta_{\text{prior}} + \text{\# failures}βpost​=βprior​+# failures.
  • Key Insight (Q3): If posterior mode > prior mode, likely more successes (e.g., 5 successes in 6 trials).

3. Regularization (LASSO, Ridge)

  • LASSO (L1 Regularization): min⁡w∥y−Xw∥22+λ∥w∥1\min_{\mathbf{w}} \|\mathbf{y} - X\mathbf{w}\|_2^2 + \lambda \|\mathbf{w}\|_1minw​∥y−Xw∥22​+λ∥w∥1​.

    • Sparsity: Higher λ\lambdaλ → more weights set to 0 (Q4).

  • Ridge (L2 Regularization): min⁡w∥y−Xw∥22+λ∥w∥22\min_{\mathbf{w}} \|\mathbf{y} - X\mathbf{w}\|_2^2 + \lambda \|\mathbf{w}\|_2^2minw​∥y−Xw∥22​+λ∥w∥22​.

    • Smooths weights but doesn’t enforce sparsity.

4. Decision Trees & Information Gain

  • Information Gain (IG): IG=H(parent)−∑childrenNiNH(childi)IG = H(\text{parent}) - \sum_{\text{children}} \frac{N_i}{N} H(\text{child}_i)IG=H(parent)−∑children​NNi​​H(childi​), where HHH is entropy.
  • Entropy: H(S)=−∑ipilog⁡2piH(S) = -\sum_{i} p_i \log_2 p_iH(S)=−∑i​pi​log2​pi​.
  • Key Insight (Q5): If IG=0IG = 0IG=0, children’s entropy = parent’s entropy. If one child’s entropy = parent’s entropy, the other must also equal it (symmetry).

5. Perceptron & Linear Separability

7. Linear Regression & Loss Functions

  • Squared Loss: L(w)=∥y−Xw∥22L(\mathbf{w}) = \|\mathbf{y} - X\mathbf{w}\|_2^2L(w)=∥y−Xw∥22​.

  • Impact of Features/Regularization (Q10):

    • More features (ddd): Can reduce training loss (but risk overfitting).
    • More data (nnn): May not reduce training loss (focuses on generalization).
    • Regularization (L1/L2): Increases training loss (penalizes complexity).
    • Learning rate: Smaller rates may refine convergence but don’t directly reduce loss.

9. Training vs. Validation Curves (Q13)

  • Training Loss: Decreases monotonically with training (optimization).
  • Validation Loss: Decreases initially, then may increase (overfitting).

11. K-Means Clustering

  • Algorithm:

    1. Initialize centroids μ1,μ2,…,μK\mu_1, \mu_2, \dots, \mu_Kμ1​,μ2​,…,μK​.
    2. Assign points to nearest centroid (Euclidean distance).
    3. Recompute centroids as mean of assigned points.
    4. Repeat until convergence.
  • Key Insight (Q17): Final centroids may coincide with initial centroids if points are symmetrically distributed.

16. Ensemble Methods (Bagging, Random Forest)

  • Bagging (Q15):

    • Trains multiple models on bootstrapped samples.
    • Reduces variance (helps if base estimators are high-variance/low-bias).
    • If estimators are identical, bagging offers no benefit.

  • Random Forest:

    • Extends bagging by random feature subsets.
    • Parallelizable (independent trees).
