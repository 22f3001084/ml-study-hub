Core Topics & Key Concepts

1. Activation Functions

  • ReLU (Rectified Linear Unit):

    • Definition: ReLU(x)=max⁡(0,x)\text{ReLU}(x) = \max(0, x)ReLU(x)=max(0,x)
    • Outputs: 000 for x<0x < 0x<0, xxx for x≥0x \geq 0x≥0.
    • Example: For inputs [−2.7,3.9,−1.0,4.2,6.4,−7.3][-2.7, 3.9, -1.0, 4.2, 6.4, -7.3][−2.7,3.9,−1.0,4.2,6.4,−7.3], outputs are [0,3.9,0,4.2,6.4,0][0, 3.9, 0, 4.2, 6.4, 0][0,3.9,0,4.2,6.4,0] (Q2).

2. Gradient Descent & Optimization

  • Learning Rate (α\alphaα):

    • If loss increases, the learning rate is too high (divergence).
    • Fix: Reduce α\alphaα (Q3).

  • Stochastic vs. Batch Gradient Descent:

    • Batch: Uses entire dataset.
    • Stochastic: Uses one sample per iteration.

  • Constraints: yi(wTxi+b)≥1y_i (w^T x_i + b) \geq 1yi​(wTxi​+b)≥1.

4. Model Complexity & Bias-Variance Tradeoff

  • Bias:

    • High Bias (Underfitting): Model is too simple (e.g., low-degree polynomial).
    • Low Bias (Overfitting): Model is too complex (e.g., high-degree polynomial).

  • Example (Q6, Q15, Q16):

    • Model 1: y^=a0+a1x+a2x2\hat{y} = a_0 + a_1 x + a_2 x^2y^​=a0​+a1​x+a2​x2 (higher bias, lower variance).
    • Model 2: y^=a0+a1x+⋯+a10x10\hat{y} = a_0 + a_1 x + \dots + a_{10} x^{10}y^​=a0​+a1​x+⋯+a10​x10 (lower bias, higher variance).
    • Test Error: Depends on the true data distribution (Q16).

7. k-Nearest Neighbors (k-NN)

  • Leave-One-Out Cross-Validation (LOOCV):

    • Lower error for higher kkk (smoother decision boundaries).
    • Example (Q8): 3-NN has lower LOOCV error than 1-NN.

8. Clustering (Lloyd’s Algorithm / k-Means)

  • Steps:

    1. Initialize centroids.
    2. Assign points to nearest centroid.
    3. Recompute centroids.

  • Example (Q9):

    • Initial clusters: C1={5,6,−2,−3}C_1 = \{5, 6, -2, -3\}C1​={5,6,−2,−3}, C2={1,7,−4,−1}C_2 = \{1, 7, -4, -1\}C2​={1,7,−4,−1}.
    • After 1 iteration: C1={5,6,1}C_1 = \{5, 6, 1\}C1​={5,6,1}, C2={−2,−3,7,−4,−1}C_2 = \{-2, -3, 7, -4, -1\}C2​={−2,−3,7,−4,−1}.

9. Principal Component Analysis (PCA)

  • Covariance Matrix (CCC):

    • Diagonal entries = variances.
    • Off-diagonal entries = covariances.

  • Principal Components:

    • Eigenvectors of CCC, ordered by eigenvalues.

  • Example (Q17, Q18):

    • Given C=[12aba6cbc3]C = \begin{bmatrix} 12 & a & b \\ a & 6 & c \\ b & c & 3 \end{bmatrix}C=​12ab​a6c​bc3​​, first PC variance = 12.
    • If eigenvectors are standard basis, features are uncorrelated.

  • Example (Q19, Q20):

    • If a feature is always 0, P(xj=1∣y)=0P(x_j = 1 | y) = 0P(xj​=1∣y)=0.
    • Prediction for x=[1,1,1,0]x = [1, 1, 1, 0]x=[1,1,1,0] is indeterminate (zero probability).

11. AdaBoost

  • Weight Update:

    • Increase weights for misclassified points.
    • wi←wi⋅eαt⋅I(yi≠ht(xi))w_i \leftarrow w_i \cdot e^{\alpha_t \cdot \mathbb{I}(y_i \neq h_t(x_i))}wi​←wi​⋅eαt​⋅I(yi​=ht​(xi​)).

  • Error Calculation:

    • Training error = sum of weights of misclassified points.

  • Example (Q27-Q29):

    • Initial weights: 13\frac{1}{3}31​.

    • After 1 iteration:

      • x1x_1x1​: weight = 12\frac{1}{2}21​, true label = -1.

      • Training error ≈ 0.33.

  • Uniform Distribution:

    • X∼Uniform[0,a]X \sim \text{Uniform}[0, a]X∼Uniform[0,a].
    • MLE for aaa: a^=max⁡(xi)\hat{a} = \max(x_i)a^=max(xi​).

13. Ensemble Methods (Bagging)

  • Preferred Estimators:

    • High variance, low bias models (e.g., deep decision trees, k-NN with small kkk).

  • Example (Q11):

    • Decision stump with random features (reduces variance).
    • k-NN with small kkk (high variance, good for bagging).

Exam Tips

  1. SVM: Know the difference between hard-margin and soft-margin, and how kernels work.
  2. Perceptron: Understand the mistake bound and update rule.
  3. Decision Trees: Focus on splitting criteria and interpreting tree structures.
  4. PCA: Remember that principal components are eigenvectors of the covariance matrix.
  5. AdaBoost: Pay attention to weight updates and error calculations.
  6. Neural Networks: Count parameters carefully (include biases!).
  7. k-NN: Higher kkk smooths decision boundaries (lower LOOCV error).
