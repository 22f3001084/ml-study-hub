1. Core Topics & Concepts

A. Clustering (K-Means, K-Means++, Lloyd’s Algorithm)

  • Lloyd’s Algorithm (Standard K-Means):

    • Iterative optimization (assign points to nearest centroid → recompute centroids).
    • Convergence: Always converges (monotonically decreases objective function), but may converge to local optima.
    • Sensitivity: Outliers can distort centroids (sensitive to outliers).
    • Optimality: Not guaranteed to find the global optimum (depends on initialization).

  • K-Means++ Initialization:

    • Goal: Spread initial centroids to improve convergence.

    • Process:

      1. Randomly pick the first centroid.
      2. For each subsequent centroid, select points with probability proportional to their squared distance from the nearest existing centroid.
    • Score Function: S(x)=min⁡j∥x−μj∥2S(x) = \min_{j} \|x - \mu_j\|^2S(x)=minj​∥x−μj​∥2.

  • Convergence Criteria:

    • Stops when cluster assignments no longer change or centroids stabilize.

B. Principal Component Analysis (PCA)

  • Goal: Dimensionality reduction while preserving variance.

  • Key Ideas:

    • Eigenvalues/Eigenvectors: Principal components are eigenvectors of the covariance matrix, ordered by eigenvalues (variance explained).
    • Reconstruction Error: Residue vanishes if kkk (number of components) equals the intrinsic dimensionality.
    • Variance Explained: Proportion of variance by PC iii: λi∑jλj\frac{\lambda_i}{\sum_j \lambda_j}∑j​λj​λi​​.

  • Mathematical Formulation:

    • Covariance matrix: Σ=1nXTX\Sigma = \frac{1}{n} X^T XΣ=n1​XTX (for centered data).
    • Eigenvalue decomposition: Σ=VΛVT\Sigma = V \Lambda V^TΣ=VΛVT.
    • Projected data: XPCA=XVkX_{\text{PCA}} = X V_kXPCA​=XVk​ (where VkV_kVk​ contains top kkk eigenvectors).

  • Special Cases:

    • If data lies in a ddd-dimensional subspace of Rn\mathbb{R}^nRn, only ddd eigenvalues are non-zero.
    • Example: 50D data in a 6D subspace → first 6 PCs capture all variance.

C. Gaussian Mixture Models (GMM) & EM Algorithm

  • GMM: Probabilistic model assuming data is generated from a mixture of Gaussians.

    • Parameters: Means μk\mu_kμk​, covariances Σk\Sigma_kΣk​, mixing coefficients πk\pi_kπk​.
    • Likelihood Function:

D. Bayesian Statistics (Beta-Binomial Model)

  • Prior: Beta distribution Beta(a,b)\text{Beta}(a, b)Beta(a,b) for proportion θ\thetaθ.

    • Mean: E[θ]=aa+b\mathbb{E}[\theta] = \frac{a}{a + b}E[θ]=a+ba​.
  • Posterior: After observing kkk successes in nnn trials, posterior is Beta(a+k,b+n−k)\text{Beta}(a + k, b + n - k)Beta(a+k,b+n−k).
  • Posterior Mean:
E[θ∣data]=a+ka+b+n\mathbb{E}[\theta | \text{data}] = \frac{a + k}{a + b + n}E[θ∣data]=a+b+na+k​

E. Kernel Methods

  • Valid Kernels: Must satisfy Mercer’s condition (positive semi-definite Gram matrix).

    • Examples:

      1. Gaussian (RBF) Kernel:
K(x,y)=exp⁡(−∥x−y∥22σ2)K(x, y) = \exp\left(-\frac{\|x - y\|^2}{2\sigma^2}\right)K(x,y)=exp(−2σ2∥x−y∥2​)
  1. Polynomial Kernel:

  • Invalid Kernel Example: K(x,y)=∣x−y∣K(x, y) = |x - y|K(x,y)=∣x−y∣ (not PSD).

4. Exam Tips

  1. K-Means:

    • Know when Lloyd’s algorithm converges (always) vs. optimality (not guaranteed).
    • Understand K-Means++ initialization (probabilistic selection based on distances).

  1. PCA:

    • If data lies in a ddd-dimensional subspace, only ddd eigenvalues are non-zero.
    • Variance explained by PC iii = λi/∑λj\lambda_i / \sum \lambda_jλi​/∑λj​.

  1. GMM/EM:

    • Likelihood function involves a product of sums (not sum of products).
    • Responsibilities (γik\gamma_{ik}γik​) are posterior probabilities.

  1. Bayesian Statistics:

    • Posterior mean for Beta-Binomial is (a+k)/(a+b+n)(a + k)/(a + b + n)(a+k)/(a+b+n).

  1. Kernels:

    • RBF, polynomial, and Laplacian kernels are valid; ∣x−y∣|x - y|∣x−y∣ is not.
