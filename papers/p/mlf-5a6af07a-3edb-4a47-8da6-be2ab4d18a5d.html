2. Linear Algebra

Key Concepts

  • Orthogonal Matrices:

    • ATA=IA^T A = IATA=I
    • ABABAB is orthogonal if A,BA, BA,B are orthogonal.
    • A+BA + BA+B is not necessarily orthogonal.

  • Symmetric Matrices:

    • A=ATA = A^TA=AT
    • Eigenvalues are real.
    • ATAA^T AATA and AATAA^TAAT have the same eigenvalues and singular values (but not necessarily eigenvectors).

  • Unitary Matrices:

    • U†U=IU^\dagger U = IU†U=I (for complex matrices).
    • Not necessarily Hermitian (e.g., rotation matrices).

  • Rank & Eigenvalues:

    • ATAA^T AATA and AATAA^TAAT have the same rank.

  • Singular Value Decomposition (SVD):

    • A=UΣVTA = U \Sigma V^TA=UΣVT, where Σ\SigmaΣ contains singular values.
