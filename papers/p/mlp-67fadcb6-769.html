A. Model Training & Evaluation

Key Concepts:

  1. Cross-Validation (K-Fold)

    • Equation:

    • Example: 10-fold CV trains 10 models (Q2).

  1. Model Persistence (warm_start)

    • Retains weights between .fit() calls (e.g., Perceptron(warm_start=True)) (Q3).

  1. Confusion Matrix

    • Structure: | True\Pred | 0 | 1 | |-----------|---------|---------| | 0 | TN | FP | | 1 | FN | TP |

    • Metrics:

      • Precision: TPTP+FP\frac{TP}{TP + FP}TP+FPTP​
      • Recall: TPTP+FN\frac{TP}{TP + FN}TP+FNTP​
      • F1: 2×Precision×RecallPrecision+Recall2 \times \frac{Precision \times Recall}{Precision + Recall}2×Precision+RecallPrecision×Recall​
    • Use Case: Imbalanced data (e.g., rare disease detection) (Q15).

  1. Evaluation Metrics for Imbalanced Data

    • Avoid: Accuracy (misleading for rare classes).
    • Use: Precision, Recall, F1, ROC-AUC (Q15).

4. Exam Tips

  1. Cross-Validation: Always count models as n_splits (Q2).
  2. Imbalanced Data: Avoid accuracy; use precision/recall/F1 (Q15).
  3. Hyperparameter Tuning: Total models = product of options (Q24).
  4. Text/Image Data: Flattening → (height × width × channels,) (Q5).
  5. Time Series: ADF p<0.05p < 0.05p<0.05 → stationary (Q7).
  6. Collaborative Filtering: Cosine similarity for user-user predictions (Q25–27).
