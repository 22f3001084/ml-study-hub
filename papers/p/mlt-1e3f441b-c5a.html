3. Expectation-Maximization (EM) Algorithm

  • Core Concepts:

    • EM algorithm is used for finding maximum likelihood estimates in models with latent variables.
    • E-step: Estimate the latent variables.
    • M-step: Maximize the likelihood over the model parameters.

  • Key Principles:

    • EM algorithm converges to a local optimum.
    • Poor initialization can affect the convergence and the quality of clusters.

4. Gradient Descent and Stochastic Gradient Descent

  • Core Concepts:

    • Gradient descent is an optimization algorithm used to minimize some function by iteratively moving in the direction of steepest descent.
    • Stochastic gradient descent (SGD) is a variant of gradient descent that uses a subset of the data to compute the gradient.

  • Key Principles:

    • Gradient descent converges to a global minimum for convex functions.
    • SGD can be faster but may require more iterations to converge.
