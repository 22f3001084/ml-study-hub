1. Core Topics & Concepts

A. Machine Learning Fundamentals

  1. Supervised Learning

    • Classification (e.g., loan approval based on features like income, credit score).

      • Algorithms: Logistic Regression, Decision Trees, SVM.
      • Loss functions: Cross-entropy, Hinge loss.

    • Regression (e.g., polynomial regression for quadratic models).

      • Algorithms: Linear Regression, Polynomial Regression, Ridge/Lasso.

      • Loss functions: Mean Squared Error (MSE).

        • Equation:
MSE=1n∑i=1n(yi−y^i)2\text{MSE} = \frac{1}{n} \sum_{i=1}^n (y_i - \hat{y}_i)^2MSE=n1​i=1∑n​(yi​−y^​i​)2

  • Least Squares Method for parameter estimation (θ₀, θ₁, θ₂ in y=θ0+θ1x+θ2x2y = θ₀ + θ₁x + θ₂x²y=θ0​+θ1​x+θ2​x2).

    • Closed-form solution (Normal Equation):
θ=(XTX)−1XTy\theta = (X^T X)^{-1} X^T yθ=(XTX)−1XTy

  • Model Evaluation:

    • Squared loss, reconstruction loss (e.g., autoencoders).
    • Overfitting/underfitting.

  1. Unsupervised Learning

    • Clustering (e.g., K-Means, Hierarchical Clustering).

    • Dimensionality Reduction (e.g., PCA, Autoencoders).

      • Autoencoder loss (reconstruction loss):

    • Classification vs. Regression vs. Clustering vs. Dimensionality Reduction.

B. Linear Algebra

  1. Vectors

    • Orthogonality: Two vectors v1v_1v1​ and v2v_2v2​ are orthogonal if v1Tv2=0v_1^T v_2 = 0v1T​v2​=0.
    • Linear Independence: Vectors are linearly independent if no vector can be written as a linear combination of others.
    • Projection: Projection of v1v_1v1​ onto v2v_2v2​:
projv2v1=(v1⋅v2v2⋅v2)v2\text{proj}_{v_2} v_1 = \left( \frac{v_1 \cdot v_2}{v_2 \cdot v_2} \right) v_2projv2​​v1​=(v2​⋅v2​v1​⋅v2​​)v2​
  • Parallel/Collinear Vectors: Vectors are parallel if one is a scalar multiple of the other.

  1. Matrices

    • Eigenvalues/Eigenvectors:

      • Av=λvA v = \lambda vAv=λv, where λ\lambdaλ = eigenvalue, vvv = eigenvector.

      • Properties:

        • Sum of columns = zero vector ⇒ λ=0\lambda = 0λ=0 is an eigenvalue.
        • Real symmetric matrices have real eigenvalues.
        • Orthogonal matrices: ATA=IA^T A = IATA=I (eigenvalues have magnitude 1).

      • Diagonalizability:

        • A matrix is diagonalizable if it has nnn linearly independent eigenvectors (not necessarily distinct eigenvalues).

    • Determinant:

      • det⁡(A)\det(A)det(A) for a matrix where all non-zero vectors are eigenvectors with eigenvalue λ\lambdaλ: det⁡(A)=λn\det(A) = \lambda^ndet(A)=λn.

    • Row Space/Basis:

      • Row space of AAA: Span of its rows.
      • Basis: Linearly independent rows that span the row space.

    • Linear Relations:

      • Example: R2=2R1+R3R_2 = 2R_1 + R_3R2​=2R1​+R3​ (from matrix rows).

  1. Special Matrices

    • Orthogonal Matrices: ATA=IA^T A = IATA=I.

      • Example: Rotation matrix:

    • Symmetric Matrices: A=ATA = A^TA=AT.

4. Exam-Specific Tips

  1. Polynomial Regression:

    • For y=θ0+θ1x+θ2x2y = \theta_0 + \theta_1 x + \theta_2 x^2y=θ0​+θ1​x+θ2​x2, construct the design matrix XXX with columns [1,x,x2][1, x, x^2][1,x,x2] and solve θ=(XTX)−1XTy\theta = (X^T X)^{-1} X^T yθ=(XTX)−1XTy.

  1. Eigenvalues/Eigenvectors:

    • If all non-zero vectors are eigenvectors with eigenvalue λ\lambdaλ, the matrix is A=λIA = \lambda IA=λI, so det⁡(A)=λn\det(A) = \lambda^ndet(A)=λn.

  1. Linear Approximation:

    • For f(x1,x2)=ex1+x2f(x_1, x_2) = e^{x_1} + x_2f(x1​,x2​)=ex1​+x2​, compute gradients at (0,0)(0,0)(0,0):
∇f=[ex1,1]⇒∇f(0,0)=[1,1]\nabla f = [e^{x_1}, 1] \Rightarrow \nabla f(0,0) = [1, 1]∇f=[ex1​,1]⇒∇f(0,0)=[1,1]

So, L(0,0)[f](x)=f(0,0)+∇f⋅x=1+x1+x2L_{(0,0)}[f](x) = f(0,0) + \nabla f \cdot x = 1 + x_1 + x_2L(0,0)​[f](x)=f(0,0)+∇f⋅x=1+x1​+x2​.

  1. Reconstruction Loss:

    • Encode each data point, decode it, and compute the mean squared distance from the original.

  1. Orthogonal Matrices:

    • Rotation matrices are orthogonal and have eigenvalues eiθe^{i\theta}eiθ, which are complex unless θ=0\theta = 0θ=0 or π\piπ.

  1. Basis for Row Space:

    • Perform row reduction (Gaussian elimination) to find linearly independent rows.
