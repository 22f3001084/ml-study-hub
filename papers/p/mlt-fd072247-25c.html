Core Topics & Key Concepts

1. Principal Component Analysis (PCA)

  • Purpose: Dimensionality reduction while preserving variance.

  • Steps:

    1. Standardize data (mean=0, variance=1).
    2. Compute covariance matrix: Σ=1nXTX\Sigma = \frac{1}{n} X^T XΣ=n1​XTX.
    3. Eigen-decomposition: Σ=UΛUT\Sigma = U \Lambda U^TΣ=UΛUT, where Λ\LambdaΛ contains eigenvalues λ1≥λ2≥...≥λd\lambda_1 \geq \lambda_2 \geq ... \geq \lambda_dλ1​≥λ2​≥...≥λd​.
    4. Project data onto top kkk eigenvectors (principal components).

  • Variance along PC1: For a dataset {α1u,α2u,...,αnu}\{ \alpha_1 \mathbf{u}, \alpha_2 \mathbf{u}, ..., \alpha_n \mathbf{u} \}{α1​u,α2​u,...,αn​u}, the variance along the first PC is the largest eigenvalue of Σ\SigmaΣ.

    • If data is scaled multiples of u\mathbf{u}u, variance = Var(α)⋅∥u∥2\text{Var}(\alpha) \cdot \|\mathbf{u}\|^2Var(α)⋅∥u∥2.
    • Equation:
Variance along PC1=λ1=1n∑i=1n(αi−αˉ)2⋅∥u∥2\text{Variance along PC1} = \lambda_1 = \frac{1}{n} \sum_{i=1}^n (\alpha_i - \bar{\alpha})^2 \cdot \|\mathbf{u}\|^2Variance along PC1=λ1​=n1​i=1∑n​(αi​−αˉ)2⋅∥u∥2
  • Reconstruction Error: If you retain kkk PCs, the error is the sum of discarded eigenvalues:
Error=∑i=k+1dλi\text{Error} = \sum_{i=k+1}^d \lambda_iError=i=k+1∑d​λi​
  • If data lies in a kkk-dimensional subspace, error = 0.

2. Maximum A Posteriori (MAP) Estimation

  • Prior + Likelihood → Posterior:
f(θ∣X)∝P(X∣θ)⋅P(θ)f(\theta | X) \propto P(X | \theta) \cdot P(\theta)f(θ∣X)∝P(X∣θ)⋅P(θ)
  • Uniform Prior: For θ∼Uniform[0,b]\theta \sim \text{Uniform}[0, b]θ∼Uniform[0,b], the posterior is:
f(θ∣X)∝I[0,b](θ)⋅∏i=1nI[0,θ](xi)f(\theta | X) \propto \mathbb{I}_{[0, b]}(\theta) \cdot \prod_{i=1}^n \mathbb{I}_{[0, \theta]}(x_i)f(θ∣X)∝I[0,b]​(θ)⋅i=1∏n​I[0,θ]​(xi​)
  • MAP Estimate: Mode of the posterior. For Uniform[0,60] prior and data X={x1,...,xn}X = \{x_1, ..., x_n\}X={x1​,...,xn​}, MAP is max⁡(xi)\max(x_i)max(xi​) if max⁡(xi)≤60\max(x_i) \leq 60max(xi​)≤60, else 60.

3. Logistic Regression & Class Imbalance

  • Decision Boundary: σ(wTx)≥t\sigma(\mathbf{w}^T \mathbf{x}) \geq tσ(wTx)≥t, where ttt is the threshold.

    • Low Threshold (t → 0): High recall (few false negatives), high false positives.
    • High Threshold (t → 1): High precision (few false positives), high false negatives.
  • Trade-off: For spam detection (prioritize recall), set low threshold (answer = 1).

4. k-Means Clustering

  • Sensitive to:

    • Initialization (different centroids → different results).
    • Outliers (pulls centroids away).
  • Convergence: Guaranteed to converge (but may be local minima).

  • Key Points:

    • Initialization affects iterations to converge (Option D).
    • Outliers can distort clusters (Option B).

5. Training vs. Validation Loss Curves

  • Training Loss: Decreases monotonically (model fits training data).

  • Validation Loss:

    • Decreases initially, then may increase (overfitting).
    • Curve A: Training loss (lower, smoother).
    • Curve B: Validation loss (higher, may rise later).

11. Bias-Variance Tradeoff & Model Complexity

  • Underfitting: High bias, low variance (Option A is incorrect).
  • Overfitting: High variance, low bias (e.g., deep decision trees).

  • Bagging (e.g., Random Forest):

    • Trains estimators in parallel on bootstrapped samples.
    • Reduces variance.

  • AdaBoost:

    • Sequentially trains weak learners, upweights misclassified points.
    • Reduces bias.

12. Support Vector Machines (SVM)

  • Support Vectors: Points on the margin (wTxi=±1\mathbf{w}^T \mathbf{x}_i = \pm 1wTxi​=±1).

  • Slack Variables (ξi\xi_iξi​): Measure violation of margin.

    • ξi=0\xi_i = 0ξi​=0 if point is correctly classified and outside/on the margin.
    • ξi=∣wTxi−yi∣−1\xi_i = |\mathbf{w}^T \mathbf{x}_i - y_i| - 1ξi​=∣wTxi​−yi​∣−1 if misclassified or inside margin.
  • Soft-Margin SVM: Minimizes ∥w∥2+C∑ξi\|\mathbf{w}\|^2 + C \sum \xi_i∥w∥2+C∑ξi​.

  • Key Observations:

    • Removing non-support vectors does not change the model (Option B).

    • ξi\xi_iξi​ for points:

      • On the correct side of the margin: ξi=0\xi_i = 0ξi​=0.
      • Inside margin or misclassified: ξi>0\xi_i > 0ξi​>0.

14. Model Complexity & Test Error

  • False Statement: "Increasing complexity always increases test error."

    • Truth: Test error may decrease initially (better fit), then increase (overfitting).
