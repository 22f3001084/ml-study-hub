1. Core Topics & Key Concepts

A. Clustering (K-Means & K-Means++)

  • Lloyd’s Algorithm (K-Means):

    • Convergence: Always converges (monotonically decreases objective function).
    • Sensitivity: Sensitive to outliers (uses Euclidean distance).
    • Optimality: May converge to local optima (not guaranteed global optimum).
    • Initialization: Performance depends on initial centroids.

  • K-Means++ Initialization:

    • Goal: Spread out initial centroids to improve convergence.
    • Score Function: S(x)=min⁡j∥x−μj∥2S(x) = \min_{j} \|x - \mu_j\|^2S(x)=minj​∥x−μj​∥2 (probability ∝ S(x)S(x)S(x)).
    • Convergence: Faster than random initialization.

  • Key Equations:

    • Centroid Update: μk=1∣Ck∣∑x∈Ckx\mu_k = \frac{1}{|C_k|} \sum_{x \in C_k} xμk​=∣Ck​∣1​∑x∈Ck​​x

B. Principal Component Analysis (PCA)

  • Goal: Dimensionality reduction via orthogonal transformation.

  • Key Ideas:

    • Projects data onto directions (principal components) of maximum variance.
    • Eigenvalues of covariance matrix Σ\SigmaΣ represent variance along PCs.
    • Reconstruction Error: Zero if k=rank(X)k = \text{rank}(X)k=rank(X).

  • Key Equations:

    • Covariance Matrix: Σ=1nXTX\Sigma = \frac{1}{n} X^T XΣ=n1​XTX (for centered data).
    • Variance Explained: Proportion=λi∑jλj\text{Proportion} = \frac{\lambda_i}{\sum_j \lambda_j}Proportion=∑j​λj​λi​​
    • Reconstruction: X≈UkΣkVkTX \approx U_k \Sigma_k V_k^TX≈Uk​Σk​VkT​ (top-kkk SVD).

  • Properties:

    • If data lies in a ddd-dimensional subspace, only ddd eigenvalues are non-zero.
    • Total Variance: Sum of all eigenvalues = sum of diagonal entries of Σ\SigmaΣ.

C. Bayesian Statistics (Beta-Binomial Model)

  • Prior: θ∼Beta(a,b)\theta \sim \text{Beta}(a, b)θ∼Beta(a,b) (conjugate prior for Binomial).
  • Posterior: θ∣data∼Beta(a+successes,b+failures)\theta | \text{data} \sim \text{Beta}(a + \text{successes}, b + \text{failures})θ∣data∼Beta(a+successes,b+failures).
  • Posterior Mean (Estimate for θ\thetaθ):
E[θ]=a+successesa+b+nE[\theta] = \frac{a + \text{successes}}{a + b + n}E[θ]=a+b+na+successes​

4. Exam Tips

  1. PCA:

    • If data lies in a ddd-dimensional subspace, only ddd eigenvalues are non-zero.
    • Variance explained = λi∑λj\frac{\lambda_i}{\sum \lambda_j}∑λj​λi​​.
    • Reconstruction error = 0 if k≥rank(X)k \geq \text{rank}(X)k≥rank(X).

  1. K-Means:

    • Converges always (but may be suboptimal).
    • K-Means++ improves initialization by weighting points by S(x)S(x)S(x).

  1. Bayesian:

    • Beta prior + Binomial data → Beta posterior.
    • Posterior mean = a+successesa+b+n\frac{a + \text{successes}}{a + b + n}a+b+na+successes​.

  1. Kernels:

    • RBF, Polynomial, Laplacian are valid.
    • ∣x−y∣|x-y|∣x−y∣ is not a valid kernel.

  1. EM Algorithm:

    • E-Step: Compute λik\lambda_{ik}λik​ (responsibilities).
    • M-Step: Update πk,μk,Σk\pi_k, \mu_k, \Sigma_kπk​,μk​,Σk​.

  1. Linear Algebra:

    • Rank = number of linearly independent columns/rows.
    • If c4=2c1−c2c_4 = 2c_1 - c_2c4​=2c1​−c2​, the rank reduces by 1.
