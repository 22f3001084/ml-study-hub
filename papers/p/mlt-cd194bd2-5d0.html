Core Topics & Concepts

1. Principal Component Analysis (PCA)

  • Goal: Dimensionality reduction by projecting data onto orthogonal axes (principal components) that maximize variance.

  • Steps:

    1. Center the data (subtract mean).
    2. Compute covariance matrix Σ=1nXTX\Sigma = \frac{1}{n} X^T XΣ=n1​XTX.
    3. Eigenvalue decomposition: Σ=UΛUT\Sigma = U \Lambda U^TΣ=UΛUT, where UUU contains eigenvectors (principal components) and Λ\LambdaΛ contains eigenvalues.
    4. Sort eigenvalues in descending order and select top-kkk eigenvectors.
    5. Project data: Xnew=XUkX_{\text{new}} = X U_kXnew​=XUk​.

  • Variance along PC1:

    • For a dataset {x1,…,xn}\{x_1, \dots, x_n\}{x1​,…,xn​}, variance along the first PC is the largest eigenvalue λ1\lambda_1λ1​ of the covariance matrix.
    • Equation:
Variance=λ1=1n∑i=1n(u1Txi)2\text{Variance} = \lambda_1 = \frac{1}{n} \sum_{i=1}^n (u_1^T x_i)^2Variance=λ1​=n1​i=1∑n​(u1T​xi​)2
  • Example (Q2): For dataset {−2u,−u,u,2u}\{-2u, -u, u, 2u\}{−2u,−u,u,2u}, variance along PC1 is 2.52.52.5.

  • Reconstruction Error:

    • If you retain only the top-kkk PCs, the reconstruction error is the sum of the discarded eigenvalues.
    • Equation:
Error=∑i=k+1dλi\text{Error} = \sum_{i=k+1}^d \lambda_iError=i=k+1∑d​λi​
  • Example (Q3): For a dataset lying in a 2D subspace of R4\mathbb{R}^4R4, retaining 2 PCs gives zero error.

  • Prior and Posterior:

    • Prior: p(θ)p(\theta)p(θ) (e.g., Uniform[0,60]\text{Uniform}[0, 60]Uniform[0,60] for θ\thetaθ).
    • Likelihood: p(X∣θ)p(X|\theta)p(X∣θ).

3. Logistic Regression & Class Imbalance

  • Decision Threshold:

    • Lower threshold →\rightarrow→ higher recall (fewer false negatives, more false positives).
    • Higher threshold →\rightarrow→ higher precision (fewer false positives, more false negatives).
  • Example (Q5): For spam detection, prioritize recall (detect all phishing emails) by setting a low threshold (answer: 1).

  • Leave-One-Out Cross-Validation (LOOCV):

5. K-Means Clustering

  • Algorithm Steps:

    1. Specify kkk (number of clusters).
    2. Initialize centroids randomly.
    3. Assign points to nearest centroid.
    4. Recompute centroids as mean of assigned points.
    5. Repeat until convergence.
  • Correct Sequence (Q7): 3 (random init) → 1 (assign) → 4 (recompute) → 2 (reassign).

10. AdaBoost

  • Weight Update:

  • Underfitting: High bias, low variance.
  • Overfitting: Low bias, high variance.
  • Example (Q13): Increasing complexity does not always increase test error (answer: B).
