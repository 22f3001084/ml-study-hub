Summary of Core Topics, Concepts, Principles, and Equations

Linear Algebra

  1. Matrices and Their Properties

    • Hermitian Matrix: A matrix equal to its conjugate transpose, B=BHB = B^HB=BH.
    • Unitary Matrix: A matrix whose conjugate transpose is its inverse, A−1=AHA^{-1} = A^HA−1=AH.
    • Diagonalization: Expressing a matrix in the form A=QΛQTA = Q \Lambda Q^TA=QΛQT, where Λ\LambdaΛ is a diagonal matrix.
    • Singular Value Decomposition (SVD): Expressing a matrix as A=Q1ΣQ2TA = Q_1 \Sigma Q_2^TA=Q1​ΣQ2T​.

  1. Eigenvalues and Eigenvectors

    • Eigenvalues: Scalars λ\lambdaλ such that Av=λvAv = \lambda vAv=λv for a non-zero vector vvv.
    • Eigenvectors: Non-zero vectors vvv that satisfy Av=λvAv = \lambda vAv=λv.
    • Properties: For unitary matrices, eigenvalues have magnitude 1, ∣α∣=1|\alpha| = 1∣α∣=1.

  1. Quadratic Forms and Covariance Matrices

    • Quadratic Form: Q(x,y,z)=xTMxQ(x, y, z) = x^T M xQ(x,y,z)=xTMx.
    • Covariance Matrix: Used in Principal Component Analysis (PCA) to project data onto lower-dimensional spaces.

  1. Matrix Types and Properties

    • Square Matrix: A matrix with the same number of rows and columns.
    • Diagonal Matrix: A matrix with non-zero elements only on the main diagonal.
    • Upper/Lower Triangular Matrix: Matrices with zero elements below or above the main diagonal.
    • Singular Matrix: A matrix with a determinant of zero, which is not invertible.
    • Positive Semi-Definite Matrix: A matrix whose eigenvalues are non-negative.

Optimization

  1. Gradient Descent

    • Algorithm: Iterative method to minimize a function f(x,y)f(x, y)f(x,y).
    • Learning Rate: Step size in the gradient descent algorithm, often denoted as 1t2\frac{1}{t^2}t21​.

  1. Projection and Distance

    • Projection: Finding the closest point on a line to a given point.
    • Distance: Minimizing the distance between a point and a line.

Principal Component Analysis (PCA)

  1. Covariance Matrix: Used to understand the variance and covariance of data.
  2. Eigenvalues and Eigenvectors: Used to determine the principal components.
  3. Projection: Projecting data onto the principal components to reduce dimensionality.
