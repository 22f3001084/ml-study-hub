Summary of Core Topics, Concepts, Principles, and Equations

1. Kernel Functions and Kernel PCA

  • Kernel Function: A function that computes the dot product of the transformed input data in a higher-dimensional space.

    • Example: k([x1,x2]T,[y1,y2]T)=1+x1y1+x2y2+x12y12x2y2+x1y1x22y22k([x_1, x_2]^T, [y_1, y_2]^T) = 1 + x_1 y_1 + x_2 y_2 + x_1^2 y_1^2 x_2 y_2 + x_1 y_1 x_2^2 y_2^2k([x1​,x2​]T,[y1​,y2​]T)=1+x1​y1​+x2​y2​+x12​y12​x2​y2​+x1​y1​x22​y22​
  • Transformation Mapping (ϕ\phiϕ): Maps input data to a higher-dimensional space.

  • Kernel PCA: Principal Component Analysis (PCA) applied in a higher-dimensional space using kernel functions.

    • Properties:

      • The number of principal components cannot exceed the dimensionality of the dataset.
      • Linear combinations of valid kernels with positive coefficients are also valid kernels.
      • Kernel functions must produce non-negative outputs.

2. K-means Clustering

  • Algorithm: Iterative algorithm to partition data into kkk clusters.

    • Steps:

      1. Initialize centroids.
      2. Assign each data point to the nearest centroid.
      3. Recompute centroids based on the current assignment.
      4. Repeat until convergence.
    • Termination: When centroids no longer change or a maximum number of iterations is reached.
    • Distance Metric: Euclidean distance is commonly used.

3. Principal Component Analysis (PCA)

  • Purpose: Reduces the dimensionality of a dataset while preserving as much variability as possible.

    • Steps:

      1. Center the data.
      2. Compute the covariance matrix.
      3. Compute the eigenvalues and eigenvectors of the covariance matrix.
      4. Select the top kkk eigenvectors (principal components) corresponding to the largest eigenvalues.

    • Properties:

      • The first principal component captures the maximum variance.
      • The first principal component is the eigenvector corresponding to the largest eigenvalue of the covariance matrix.
      • If data lies in a lower-dimensional subspace, the covariance matrix will have fewer non-zero eigenvalues.

4. Gaussian Mixture Models (GMM)

  • Purpose: Models data as a mixture of Gaussian distributions.

    • Components:

      • πi\pi_iπi​: Mixing coefficients.
      • μi\mu_iμi​: Mean of the iii-th Gaussian component.
      • σi2\sigma_i^2σi2​: Variance of the iii-th Gaussian component.
    • Probability Calculation: The probability that a point xxx comes from a component is given by the posterior probability.

5. Bernoulli Distribution and Maximum Likelihood Estimation (MLE)

  • Bernoulli Distribution: Models binary data.

    • Parameter: ppp, the probability of success (e.g., P(x=1)P(x = 1)P(x=1)).

    • MLE: Estimates the parameter ppp based on observed data.

      • For a dataset with nnn observations, if the MLE estimate for ppp is p^\hat{p}p^​, then the number of zeros is n(1−p^)n(1 - \hat{p})n(1−p^​).

6. Beta Distribution

  • Purpose: Used as a prior distribution for the parameter ppp in a Bernoulli distribution.

    • Parameters: α\alphaα and β\betaβ.
    • Posterior Distribution: Updated based on observed data.
