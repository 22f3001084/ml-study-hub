1. Core Topics & Key Concepts

A. Supervised Learning

  1. Linear Regression & Regularization

    • Ordinary Least Squares (OLS):

      • Minimizes ∑(yi−y^i)2\sum (y_i - \hat{y}_i)^2∑(yi​−y^​i​)2.
      • Closed-form solution: w=(XTX)−1XTyw = (X^T X)^{-1} X^T yw=(XTX)−1XTy.

    • Ridge Regression (L2 Regularization):

      • Loss: MSE+λ∑wj2\text{MSE} + \lambda \sum w_j^2MSE+λ∑wj2​.
      • Penalizes large coefficients (reduces overfitting).
      • Solution: w=(XTX+λI)−1XTyw = (X^T X + \lambda I)^{-1} X^T yw=(XTX+λI)−1XTy.

    • Lasso Regression (L1 Regularization):

      • Loss: MSE+λ∑∣wj∣\text{MSE} + \lambda \sum |w_j|MSE+λ∑∣wj​∣.
      • Forces sparse solutions (feature selection).
    • Key Equation:

Lasso: w=arg⁡min⁡w∥y−Xw∥22+λ∥w∥1\text{Lasso: } w = \arg\min_w \|y - Xw\|_2^2 + \lambda \|w\|_1Lasso: w=argwmin​∥y−Xw∥22​+λ∥w∥1​

  1. Logistic Regression

    • Sigmoid function: σ(z)=11+e−z\sigma(z) = \frac{1}{1 + e^{-z}}σ(z)=1+e−z1​.
    • Decision boundary: y^=1\hat{y} = 1y^​=1 if σ(wTx)>0.5\sigma(w^T x) > 0.5σ(wTx)>0.5.
    • Key Equation:
P(y=1∣x)=σ(wTx)P(y=1|x) = \sigma(w^T x)P(y=1∣x)=σ(wTx)

  1. Support Vector Machines (SVM)

    • Hard-Margin SVM:

      • Maximizes margin 2∥w∥\frac{2}{\|w\|}∥w∥2​.
      • Constraints: yi(wTxi+b)≥1y_i(w^T x_i + b) \geq 1yi​(wTxi​+b)≥1.

    • Soft-Margin SVM:

      • Allows misclassification with slack variables ξi\xi_iξi​.
      • Primal problem:

  • Dual Problem:

    • Solve for α\alphaα (Lagrange multipliers).
    • Kernel trick: K(xi,xj)=ϕ(xi)Tϕ(xj)K(x_i, x_j) = \phi(x_i)^T \phi(x_j)K(xi​,xj​)=ϕ(xi​)Tϕ(xj​).

  • Key Properties:

    • If αi=0\alpha_i = 0αi​=0: Correctly classified (non-support vector).
    • If 0<αi<C0 < \alpha_i < C0<αi​<C: Lies on margin (support vector).
    • If αi=C\alpha_i = Cαi​=C: Misclassified or inside margin.

  1. Decision Trees

    • Impurity Measures:

      • Entropy: H(S)=−∑pilog⁡2piH(S) = -\sum p_i \log_2 p_iH(S)=−∑pi​log2​pi​.
      • Gini Index: G(S)=1−∑pi2G(S) = 1 - \sum p_i^2G(S)=1−∑pi2​.

    • Splitting Criteria:

      • Information Gain (IG): IG=H(parent)−∑∣Sv∣∣S∣H(Sv)\text{IG} = H(\text{parent}) - \sum \frac{|S_v|}{|S|} H(S_v)IG=H(parent)−∑∣S∣∣Sv​∣​H(Sv​).

    • Stopping Conditions:

      • Node is pure (all samples same class, entropy = 0).
      • Max depth reached.

  1. Ensemble Methods

    • AdaBoost:

      • Combines weak learners (slightly better than random guessing).
      • Updates weights: Increase for misclassified samples.

  1. Perceptron Algorithm

    • Updates weights when misclassified: w←w+η(yi−y^i)xiw \leftarrow w + \eta (y_i - \hat{y}_i) x_iw←w+η(yi​−y^​i​)xi​.
    • Converges if data is linearly separable.

B. Unsupervised Learning

  1. Clustering (Lloyd’s Algorithm / K-Means)

    • Steps:

      1. Initialize centroids randomly.
      2. Assign points to nearest centroid.
      3. Recompute centroids as mean of assigned points.
    • Key Equation:
Ck=1∣Ck∣∑x∈CkxC_k = \frac{1}{|C_k|} \sum_{x \in C_k} xCk​=∣Ck​∣1​x∈Ck​∑​x

  1. Kernel PCA

    • Projects data into higher-dimensional space using kernel K(x,x′)K(x, x')K(x,x′).
    • Polynomial Kernel: K(x,x′)=(xTx′+c)dK(x, x') = (x^T x' + c)^dK(x,x′)=(xTx′+c)d.
    • Key Idea: Use kernel trick to avoid explicit transformation.

C. Probabilistic Models

  1. Naïve Bayes

    • Assumes feature independence given class: P(y∣x1,…,xn)∝P(y)∏P(xi∣y)P(y|x_1, \dots, x_n) \propto P(y) \prod P(x_i|y)P(y∣x1​,…,xn​)∝P(y)∏P(xi​∣y).
    • Prediction: y^=arg⁡max⁡yP(y)∏P(xi∣y)\hat{y} = \arg\max_y P(y) \prod P(x_i|y)y^​=argmaxy​P(y)∏P(xi​∣y).

  1. Bayesian Inference

    • Prior: θ∼Beta(α,β)\theta \sim \text{Beta}(\alpha, \beta)θ∼Beta(α,β).
    • Posterior: θ∣data∼Beta(α+heads,β+tails)\theta | \text{data} \sim \text{Beta}(\alpha + \text{heads}, \beta + \text{tails})θ∣data∼Beta(α+heads,β+tails).
    • Posterior Mean: E[θ]=α+headsα+β+nE[\theta] = \frac{\alpha + \text{heads}}{\alpha + \beta + n}E[θ]=α+β+nα+heads​.

D. Neural Networks

  1. Single-Layer Neural Network

    • Activation Functions:

      • ReLU: ReLU(z)=max⁡(0,z)\text{ReLU}(z) = \max(0, z)ReLU(z)=max(0,z).

    • Forward Pass:

      • Hidden layer: h=ReLU(W(1)x+b(1))h = \text{ReLU}(W^{(1)} x + b^{(1)})h=ReLU(W(1)x+b(1)).
      • Output: y^=W(2)h+b(2)\hat{y} = W^{(2)} h + b^{(2)}y^​=W(2)h+b(2).

E. Dimensionality Reduction

  1. PCA vs. Kernel PCA

    • PCA: Linear projection to maximize variance.
    • Kernel PCA: Nonlinear projection using kernel functions.

4. Exam-Specific Insights

  1. Regularization (Q2, Q4):

    • Ridge shrinks coefficients; Lasso performs feature selection.

    • Weight vectors:

      • w3w_3w3​ (sparse) → Lasso.
      • w2w_2w2​ (large coefficients) → Linear Regression.
      • w1w_1w1​ (moderate coefficients) → Ridge.

  1. Decision Trees (Q3):

    • Pure node: All samples same class or entropy = 0.

  1. Clustering (Q5):

    • Recompute centroids after assignment to find new clusters.

  1. Kernel PCA (Q6):

    • Relationship x42=x1x2+x1x2x3x_4^2 = x_1 x_2 + x_1 x_2 x_3x42​=x1​x2​+x1​x2​x3​ suggests degree 3 polynomial kernel.

  1. AdaBoost (Q7, Q17, Q18):

    • Weak learners must perform better than random (error < 50%).
    • Lower training error → Higher weight in ensemble.

  1. Bias-Variance Tradeoff (Q8):

    • Model 1 (linear): High bias, low variance.
    • Model 2 (high-degree polynomial): Low bias, high variance.

  1. SVM Dual Problem (Q9):

    • αi=0\alpha_i = 0αi​=0: Correctly classified.

  1. Perceptron (Q10):

    • Converges for linearly separable data.
