Here’s a structured summary of core topics, concepts, principles, and equations for the "Diploma Level: Machine Learning Foundations" exam, along with Mermaid knowledge graphs to visualize relationships.

1. Core Topics & Concepts

A. Machine Learning Fundamentals

1. Supervised Learning

  • Classification (Binary/Multi-class):

    • Used for discrete outputs (e.g., loan approval: Yes/No).
    • Algorithms: Logistic Regression, Decision Trees, SVM, k-NN.

  • Regression:

    • Used for continuous outputs (e.g., predicting house prices).
    • Algorithms: Linear Regression, Polynomial Regression.

  • Loss Functions:

    • Squared Loss (MSE) for regression:
L(y,y^)=(y−y^)2L(y, \hat{y}) = (y - \hat{y})^2L(y,y^​)=(y−y^​)2
  • Log Loss (Cross-Entropy) for classification:
L(y,y^)=−[ylog⁡(y^)+(1−y)log⁡(1−y^)]L(y, \hat{y}) = -[y \log(\hat{y}) + (1-y) \log(1-\hat{y})]L(y,y^​)=−[ylog(y^​)+(1−y)log(1−y^​)]

2. Unsupervised Learning

  • Clustering (e.g., k-Means, Hierarchical Clustering).
  • Dimensionality Reduction (e.g., PCA, t-SNE).

B. Linear Algebra (Critical for ML)

1. Matrix Properties

  • Orthogonal Matrix: ATA=IA^T A = IATA=I (columns are orthonormal).
  • Invertible Matrix: det⁡(A)≠0\det(A) \neq 0det(A)=0, AA−1=IAA^{-1} = IAA−1=I.
  • Symmetric Matrix: A=ATA = A^TA=AT.

  • Eigenvalues & Eigenvectors:

    • For matrix AAA, Av=λvAv = \lambda vAv=λv.
    • Real Symmetric Matrices have real eigenvalues.

  • Diagonalizable Matrix:

    • A=PDP−1A = PDP^{-1}A=PDP−1 (if AAA has nnn linearly independent eigenvectors).
    • Not all diagonalizable matrices are invertible (e.g., zero eigenvalue).

2. Vector Spaces & Basis

  • Row Space: Spanned by rows of AAA.
  • Basis: Linearly independent vectors that span the space.
  • Rank: Dimension of row/column space.

3. Special Matrices

  • Idempotent Matrix: A2=AA^2 = AA2=A.
  • Nilpotent Matrix: Ak=0A^k = 0Ak=0 for some kkk.

C. Probability & Statistics (Implied in Questions)

  • Bayes’ Theorem (for classification):
P(y∣X)=P(X∣y)P(y)P(X)P(y|X) = \frac{P(X|y)P(y)}{P(X)}P(y∣X)=P(X)P(X∣y)P(y)​
  • Maximum Likelihood Estimation (MLE).

D. Optimization (Implied in Loss Minimization)

4. Exam-Specific Insights

  1. Classification vs. Regression:

    • Loan approval (Q2) → Classification (B).

  2. Matrix Properties:

    • Orthogonal matrices have ATA=IA^T A = IATA=I (Q12).
    • Symmetric matrices have real eigenvalues (Q15).
    • Diagonalizable ≠ Invertible (Q14, Q16).

  3. Basis & Vector Spaces:

    • Row space basis must span all rows (Q10).

  4. Eigenvalues:

    • Not all matrices have real eigenvalues (Q13).

  5. Loss Minimization:

    • Squared loss is key for regression (Q8).
