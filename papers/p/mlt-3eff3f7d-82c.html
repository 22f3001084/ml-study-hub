Core Topics & Concepts

1. Linear & Regularized Regression

  • Linear Regression:

    • Model: y=wTx+by = w^T x + by=wTx+b
    • Loss: Mean Squared Error (MSE) = 1n∑i=1n(yi−y^i)2\frac{1}{n} \sum_{i=1}^n (y_i - \hat{y}_i)^2n1​∑i=1n​(yi​−y^​i​)2

  • Ridge Regression (L2 Regularization):

    • Loss: MSE+λ∑j=1dwj2\text{MSE} + \lambda \sum_{j=1}^d w_j^2MSE+λ∑j=1d​wj2​
    • Penalizes large coefficients to reduce overfitting.

  • Lasso Regression (L1 Regularization):

    • Loss: MSE+λ∑j=1d∣wj∣\text{MSE} + \lambda \sum_{j=1}^d |w_j|MSE+λ∑j=1d​∣wj​∣
    • Forces sparse solutions (some coefficients = 0).

Key Insight:

  • Ridge shrinks coefficients, Lasso performs feature selection.
  • Example (Q4): w3w_3w3​ (sparse) → Lasso, w2w_2w2​ (large) → Ridge.

2. Decision Trees & Entropy

  • Pure Node: All samples belong to the same class.

  • Entropy: H(S)=−∑i=1cpilog⁡2piH(S) = -\sum_{i=1}^c p_i \log_2 p_iH(S)=−∑i=1c​pi​log2​pi​

    • H(S)=0H(S) = 0H(S)=0 → Pure node.

  • Information Gain: IG=H(parent)−∑i∣Si∣∣S∣H(Si)\text{IG} = H(\text{parent}) - \sum_{i} \frac{|S_i|}{|S|} H(S_i)IG=H(parent)−∑i​∣S∣∣Si​∣​H(Si​)

    • Higher IG → Better split.

Key Insight:

  • Pure node: Entropy = 0 or all samples same class (Q3).

3. Clustering (Lloyd’s Algorithm / K-Means)

  • Steps:

    1. Initialize centroids.
    2. Assign points to nearest centroid.
    3. Recompute centroids.
  • Convergence: When assignments stop changing.

  • Example (Q5):

    • After 1st iteration, recompute centroids and reassign points.

4. Dimensionality Reduction (PCA & Kernel PCA)

  • Standard PCA:

    • Maximizes variance in orthogonal directions.

  • Kernel PCA:

    • Uses kernel trick for nonlinear projections.
    • Polynomial kernel: K(x,x′)=(xTx′+c)dK(x, x') = (x^T x' + c)^dK(x,x′)=(xTx′+c)d

  • Example (Q6):

    • x42=x1x2+x1x2x3x_4^2 = x_1 x_2 + x_1 x_2 x_3x42​=x1​x2​+x1​x2​x3​ → Degree 3 polynomial kernel.

  • Weak Learners: Slightly better than random guessing (Q7).

  • AdaBoost:

    1. Train weak learner hth_tht​.
    2. Compute error ϵt\epsilon_tϵt​.

6. Support Vector Machines (SVM)

  • Soft-Margin SVM:

    • Minimize: 12∥w∥2+C∑ξi\frac{1}{2} \|w\|^2 + C \sum \xi_i21​∥w∥2+C∑ξi​
    • Dual problem: αi\alpha_iαi​ are Lagrange multipliers.

  • KKT Conditions:

    • If αi=0\alpha_i = 0αi​=0: Correctly classified.
    • If αi=C\alpha_i = Cαi​=C: Misclassified or margin violator.
    • If 0<αi<C0 < \alpha_i < C0<αi​<C: Lies on margin.
