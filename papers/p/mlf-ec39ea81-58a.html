Here’s a structured summary of core topics, concepts, principles, and equations for the "Diploma Level: Machine Learning Foundations" exam, along with Mermaid knowledge graphs to visualize relationships.

1. Core Topics & Concepts

A. Machine Learning Fundamentals

1. Supervised Learning

  • Classification (Binary/Multi-class):

    • Used for discrete outputs (e.g., loan approval: Yes/No).
    • Algorithms: Logistic Regression, Decision Trees, SVM, k-NN.

    • Loss Functions:

      • 0-1 Loss (misclassification error).
      • Log Loss (Cross-Entropy) for probabilistic outputs.
      • Hinge Loss (SVM).

    • Evaluation Metrics:

      • Accuracy, Precision, Recall, F1-Score, ROC-AUC.

  • Regression:

    • Used for continuous outputs (e.g., predicting house prices).
    • Algorithms: Linear Regression, Ridge/Lasso, Polynomial Regression.

    • Loss Functions:

      • Mean Squared Error (MSE):
MSE=1n∑i=1n(yi−y^i)2\text{MSE} = \frac{1}{n} \sum_{i=1}^n (y_i - \hat{y}_i)^2MSE=n1​i=1∑n​(yi​−y^​i​)2
  • Mean Absolute Error (MAE).

2. Unsupervised Learning

  • Clustering (e.g., k-Means, Hierarchical Clustering).
  • Dimensionality Reduction (e.g., PCA, t-SNE).

3. Model Evaluation

  • Train-Test Split, Cross-Validation.

  • Bias-Variance Tradeoff:

    • Underfitting (High bias) vs. Overfitting (High variance).
  • Regularization (L1/L2) to prevent overfitting.

B. Linear Algebra (Critical for ML)

1. Matrix Operations

  • Matrix Multiplication, Transpose, Inverse.
  • Determinant (for invertibility):
det(A)≠0  ⟹  A is invertible.\text{det}(A) \neq 0 \implies A \text{ is invertible.}det(A)=0⟹A is invertible.
  • Rank (dimension of column/row space).

2. Vector Spaces

  • Basis: Linearly independent vectors spanning a space.

    • Example: For R3\mathbb{R}^3R3, a basis could be {(1,0,0),(0,1,0),(0,0,1)}\{(1,0,0), (0,1,0), (0,0,1)\}{(1,0,0),(0,1,0),(0,0,1)}.
  • Row Space / Column Space / Null Space.

3. Eigenvalues & Eigenvectors

  • For a square matrix AAA:
Av=λvA \mathbf{v} = \lambda \mathbf{v}Av=λv
  • Real Symmetric Matrices: All eigenvalues are real.

  • Diagonalizable Matrices:

    • AAA is diagonalizable iff it has n linearly independent eigenvectors (not necessarily distinct eigenvalues).
    • If AAA has n distinct eigenvalues, it is diagonalizable.

4. Special Matrices

  • Orthogonal Matrix (ATA=IA^T A = IATA=I).
  • Symmetric Matrix (A=ATA = A^TA=AT).
  • Positive Definite Matrices (all eigenvalues > 0).

C. Probability & Statistics (Brief)

  • Bayes’ Theorem (for Naive Bayes classifier).
  • Maximum Likelihood Estimation (MLE).
  • Gaussian (Normal) Distribution.

D. Optimization (For ML Models)

  • Gradient Descent (for minimizing loss functions):
θnew=θold−η∇J(θ)\theta_{new} = \theta_{old} - \eta \nabla J(\theta)θnew​=θold​−η∇J(θ)

where η\etaη = learning rate, J(θ)J(\theta)J(θ) = loss function.

4. Exam-Specific Insights

  1. Question 2 (Loan Approval) → Classification (Binary).

  2. Questions 10, 12, 13, 15, 16 → Linear Algebra (Basis, Eigenvalues, Symmetric/Orthogonal Matrices).

    • A matrix is orthogonal if ATA=IA^T A = IATA=I.
    • A matrix is diagonalizable if it has n linearly independent eigenvectors (not necessarily distinct eigenvalues).
  3. Questions 5, 6, 7, 18 → Likely basic matrix computations (determinants, traces, or simple arithmetic).
  4. Question 8, 9 → Regression Loss Comparison (MSE for linear regression).
  5. Question 14 → Diagonalizable ≠ Invertible (a matrix can be diagonalizable but singular if it has a zero eigenvalue).
