F. Principal Component Analysis (PCA)

  • Goal: Reduce dimensionality while maximizing variance.

  • Steps:

    1. Center the data (subtract mean).
    2. Compute covariance matrix Σ\SigmaΣ.
    3. Find eigenvalues/eigenvectors of Σ\SigmaΣ.
    4. Project data onto top kkk eigenvectors (principal components).

  • Key Points (from Q12):

    • PCA maximizes variance of the projected data (not reconstruction error).
    • Used for dimensionality reduction.
