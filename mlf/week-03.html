The one-minute story

Think of it like this

You run a tiny shop and have recorded 3 days of sales: ads shown vs. items sold. The three dots almost sit on a line, but not quite. You want one straight line that is as close as possible to all three dots, so you can predict tomorrow.

No straight line passes through all three dots. So we cannot solve the problem exactly. What do we do? We find the line that is least wrong.

Here is the beautiful trick of this week: "least wrong" turns out to be the same thing as casting a shadow. The answer you want is the shadow of your real data on the set of things a line can produce. And shadows are found by dropping a perpendicular.

By the end of this week you can:

  • read a matrix as a machine that mixes vectors, and multiply matrices by vectors;
  • explain linear independence, span, basis, dimension and rank;
  • name the four fundamental subspaces and state their dimensions;
  • find the projection of a vector onto a line or a subspace;
  • fit a line (or any linear model) by least squares using the normal equations.

Words you need

Words you need
  • Matrix - a rectangle of numbers. An m×nm\times nm×n matrix has mmm rows and nnn columns.
  • Linear combination - "this much of vector A plus that much of vector B". Example: 2a+3b2\mathbf a+3\mathbf b2a+3b.
  • Span - everything you can build from some vectors using linear combinations.
  • Linearly independent - none of the vectors can be built from the others; each brings something new.
  • Basis - a smallest set of vectors that spans the space, i.e. independent and spanning.
  • Rank - how many independent columns a matrix has (the number of genuinely different directions it uses).
  • Projection - the shadow of a vector on a line or flat surface.
  • Residual - the leftover: the true value minus the fitted value.

Idea 1: A matrix mixes its columns

Think of it like this

Picture a juice bar with three juices: orange, apple, mango. A recipe says how many glasses of each go into a drink: (2,1,0)(2,1,0)(2,1,0) means 2 orange, 1 apple, 0 mango. The matrix has one column per juice (what is in each juice: sugar, vitamin C, ...). Multiplying the matrix by a recipe vector gives the total nutrition: you mix the columns in the amounts the recipe says.

For A=(1234)A=\begin{pmatrix}1&2\\3&4\end{pmatrix}A=(13​24​) and x=(56)\mathbf x=\begin{pmatrix}5\\6\end{pmatrix}x=(56​):

Ax=5(13)+6(24)=(1739)A\mathbf x=5\begin{pmatrix}1\\3\end{pmatrix}+6\begin{pmatrix}2\\4\end{pmatrix}=\begin{pmatrix}17\\39\end{pmatrix}Ax=5(13​)+6(24​)=(1739​)

Read AxA\mathbf xAx as "x1x_1x1​ times column 1, plus x2x_2x2​ times column 2". Everything in this week follows from that single sentence.

The set of all possible AxA\mathbf xAx (over all choices of x\mathbf xx) is called the column space of AAA. It is exactly the span of the columns.

Two things to remember about shape: AAA is m×nm\times nm×n means it takes vectors with nnn numbers and produces vectors with mmm numbers. And (AB)(AB)(AB) is allowed only when the inside sizes match: (m×n)(n×p)=m×p(m\times n)(n\times p)=m\times p(m×n)(n×p)=m×p.

Idea 2: Independence, span, basis, dimension, rank

The idea
  • Vectors are linearly independent if the only way to mix them into the zero vector is to use zero of each. If one can be written from the others, they are dependent.
  • A basis of a space is a set of independent vectors that spans it. Every basis of the same space has the same number of vectors, called its dimension.
  • The rank of a matrix is the number of independent columns, which always equals the number of independent rows.

Example. (12)\begin{pmatrix}1\\2\end{pmatrix}(12​) and (24)\begin{pmatrix}2\\4\end{pmatrix}(24​) are dependent (the second is twice the first), so together they only span a line, not the whole plane. A 2×22\times22×2 matrix with these as columns has rank 1.

The four fundamental subspaces

For an m×nm\times nm×n matrix AAA of rank rrr:

SpaceWhat it isLives inDimension
Column spaceall AxA\mathbf xAxRm\mathbb R^mRmrrr
Row spacespan of the rowsRn\mathbb R^nRnrrr
Null spaceall x\mathbf xx with Ax=0A\mathbf x=\mathbf 0Ax=0Rn\mathbb R^nRnn−rn-rn−r
Left null spaceall y\mathbf yy with ATy=0A^T\mathbf y=\mathbf 0ATy=0Rm\mathbb R^mRmm−rm-rm−r

Two perpendicularity facts: row space ⊥\perp⊥ null space, and column space ⊥\perp⊥ left null space. Also rank + nullity = number of columns: r+(n−r)=nr+(n-r)=nr+(n−r)=n.

Solved example: 1. Reading rank, nullity and dimensions

Question. AAA is a 6×46\times46×4 matrix with rank 4. Which statements are true? (a) the columns are independent; (b) the null space contains only 0\mathbf 00; (c) the row space is all of R4\mathbb R^4R4; (d) the left null space has dimension 2.

Solution. Rank 4 equals the number of columns, so all four columns are independent: (a) is true. Nullity =n−r=4−4=0=n-r=4-4=0=n−r=4−4=0, so only the zero vector solves Ax=0A\mathbf x=\mathbf 0Ax=0: (b) true. The row space has dimension 4 and lives in R4\mathbb R^4R4, so it fills it: (c) true. Left null space has dimension m−r=6−4=2m-r=6-4=2m−r=6−4=2: (d) true. All four are true.

The common slip is writing the left null space dimension as n−rn-rn−r. It is m−rm-rm−r (rows minus rank).

What a product does to row space and column space

Rows of ABABAB are mixtures of rows of BBB; columns of ABABAB are mixtures of columns of AAA. So rowspace(AB)⊆rowspace(B)\text{rowspace}(AB)\subseteq\text{rowspace}(B)rowspace(AB)⊆rowspace(B) and colspace(AB)⊆colspace(A)\text{colspace}(AB)\subseteq\text{colspace}(A)colspace(AB)⊆colspace(A), and rank(AB)≤min⁡(rankA,rankB)\text{rank}(AB)\le\min(\text{rank}A,\text{rank}B)rank(AB)≤min(rankA,rankB). Papers love to swap AAA and BBB here.

Idea 3: Projection is a shadow

Think of it like this

Hold a pencil above a table and shine a torch straight down. The pencil's shadow on the table is its projection. The shadow is the point on the table closest to the pencil's tip, and the torch beam hits the table at a right angle. Closest point = perpendicular drop. Remember that sentence; it is the heart of the week.

Try it yourself

Slide the tilt. Notice that the dashed stick always meets the line at a right angle, and that the squared lengths always add up to the same total.

Projection onto a line

Projecting x\mathbf xx onto the line through the direction a\mathbf aa:

proj⁡a(x)=a⋅xa⋅a a,P=aaTaTa\operatorname{proj}_{\mathbf a}(\mathbf x)=\frac{\mathbf a\cdot\mathbf x}{\mathbf a\cdot\mathbf a}\,\mathbf a,\qquad P=\frac{\mathbf a\mathbf a^T}{\mathbf a^T\mathbf a}proja​(x)=a⋅aa⋅x​a,P=aTaaaT​

The matrix PPP does the projecting for any x\mathbf xx: Px=proj⁡a(x)P\mathbf x=\operatorname{proj}_{\mathbf a}(\mathbf x)Px=proja​(x).

Why the formula looks like this: you want some multiple c ac\,\mathbf aca so that what is left over, x−ca\mathbf x-c\mathbf ax−ca, is perpendicular to a\mathbf aa. Perpendicular means dot product zero: a⋅(x−ca)=0\mathbf a\cdot(\mathbf x-c\mathbf a)=0a⋅(x−ca)=0, so c=a⋅xa⋅ac=\dfrac{\mathbf a\cdot\mathbf x}{\mathbf a\cdot\mathbf a}c=a⋅aa⋅x​.

Solved example: 2. Projecting a point onto a line

Question. Project x=(2,3)\mathbf x=(2,3)x=(2,3) onto the line through a=(1,1)\mathbf a=(1,1)a=(1,1). Then give the projection matrix onto the line y=2xy=2xy=2x and its trace.

Solution.

  1. a⋅x=5\mathbf a\cdot\mathbf x=5a⋅x=5 and a⋅a=2\mathbf a\cdot\mathbf a=2a⋅a=2, so c=52c=\frac52c=25​ and the shadow is 52(1,1)=(2.5, 2.5)\frac52(1,1)=(2.5,\,2.5)25​(1,1)=(2.5,2.5).
  2. The residual is (2,3)−(2.5,2.5)=(−0.5, 0.5)(2,3)-(2.5,2.5)=(-0.5,\,0.5)(2,3)−(2.5,2.5)=(−0.5,0.5). Check perpendicular: (1,1)⋅(−0.5,0.5)=0(1,1)\cdot(-0.5,0.5)=0(1,1)⋅(−0.5,0.5)=0.
  3. The line y=2xy=2xy=2x has direction a=(1,2)\mathbf a=(1,2)a=(1,2), so P=15(1224)P=\dfrac15\begin{pmatrix}1&2\\2&4\end{pmatrix}P=51​(12​24​). Its trace is 1+45=1\frac{1+4}{5}=\mathbf 151+4​=1.

Notice trace(P)=1\text{trace}(P)=1trace(P)=1: a projection onto a kkk-dimensional subspace always has trace kkk (its rank).

Four facts that every projection matrix obeys

  • P2=PP^2=PP2=P (projecting twice changes nothing: the shadow of a shadow is itself);
  • PT=PP^T=PPT=P (symmetric);
  • Pv=vP\mathbf v=\mathbf vPv=v for any v\mathbf vv already on the line (it is its own shadow);
  • eigenvalues are only 0 and 1, and rank(P)=trace(P)\text{rank}(P)=\text{trace}(P)rank(P)=trace(P).

So a projection matrix is symmetric and orthogonally diagonalisable, but it is not an orthogonal matrix (it squashes things) and it is not always rank 1 (that depends on what you project onto). Those two sentences answer a real exam MSQ.

Projection onto a whole subspace

If the subspace is the column space of AAA (columns independent), then

P=A(ATA)−1ATP=A(A^TA)^{-1}A^TP=A(ATA)−1AT

With one column a\mathbf aa this collapses to aaT/(aTa)\mathbf a\mathbf a^T/(\mathbf a^T\mathbf a)aaT/(aTa), the line formula. Same idea; you just solve for several amounts at once.

Idea 4: Least squares, or "closest I can get"

You want Aw=yA\mathbf w=\mathbf yAw=y but y\mathbf yy is not in the column space of AAA (too many equations, too few unknowns, noisy data), so no exact solution exists. The best compromise is the point in the column space closest to y\mathbf yy. That is the projection of y\mathbf yy onto the column space.

Try it yourself

Drag the slope and intercept to make the red sticks (the mistakes) as short as you can. Then press the button to see the least-squares line.

The shadow y^=Aw\hat{\mathbf y}=A\mathbf wy^​=Aw is closest exactly when the leftover y−Aw\mathbf y-A\mathbf wy−Aw is perpendicular to every column of AAA:

AT(y−Aw)=0    ⟹    ATA w=ATyA^T(\mathbf y-A\mathbf w)=\mathbf 0\;\;\Longrightarrow\;\;\boxed{A^TA\,\mathbf w=A^T\mathbf y}AT(y−Aw)=0⟹ATAw=ATy​

These are the normal equations ("normal" meaning perpendicular). If the columns of AAA are independent, ATAA^TAATA is invertible and

w=(ATA)−1ATy,y^=A(ATA)−1ATy=Py.\mathbf w=(A^TA)^{-1}A^T\mathbf y,\qquad \hat{\mathbf y}=A(A^TA)^{-1}A^T\mathbf y=P\mathbf y.w=(ATA)−1ATy,y^​=A(ATA)−1ATy=Py.

Equivalently, w\mathbf ww minimises the sum of squared errors ∥Aw−y∥2=∑i(y^i−yi)2\|A\mathbf w-\mathbf y\|^2=\sum_i(\hat y_i-y_i)^2∥Aw−y∥2=∑i​(y^​i​−yi​)2, the same squared loss you met in week 1. This is linear regression. For a line y=c+dxy=c+dxy=c+dx we use a column of ones for the intercept ccc and a column of xxx-values for the slope ddd.

Same problem, three languages

The idea
  • Geometry: y^\hat{\mathbf y}y^​ is the projection of y\mathbf yy onto the column space of AAA.
  • Algebra: solve ATAw=ATyA^TA\mathbf w=A^T\mathbf yATAw=ATy.
  • Calculus: set the gradient of ∥Aw−y∥2\|A\mathbf w-\mathbf y\|^2∥Aw−y∥2 to zero. You get the same equations. (We will use this in week 7.)

If AAA has mmm rows and nnn independent columns with m>nm>nm>n, then ATAA^TAATA is n×nn\times nn×n and invertible. If the columns are dependent, ATAA^TAATA is not invertible and the best w\mathbf ww is not unique. Later (MLT week 6) ridge regression fixes that.

Your turn: 4. Which statements about a projection matrix are true?

Watch out - real exam trap
  • Left null space has dimension m−rm-rm−r, not n−rn-rn−r.
  • rowspace(AB)⊆rowspace(B)\text{rowspace}(AB)\subseteq\text{rowspace}(B)rowspace(AB)⊆rowspace(B) but colspace(AB)⊆colspace(A)\text{colspace}(AB)\subseteq\text{colspace}(A)colspace(AB)⊆colspace(A). Do not swap.
  • Projection matrices are not orthogonal matrices.
  • In least squares, the residual is perpendicular to the columns of AAA (the features), not to y\mathbf yy.
  • (ATA)−1(A^TA)^{-1}(ATA)−1 exists only when the columns of AAA are independent.

Quick quiz

Quick quiz

A is 6 by 4 and has rank 4. What is the dimension of its left null space?

  • 4
  • 2
  • 0
  • 6
The left null space has dimension m - r = 6 - 4 = 2.

The projection matrix P onto the line through (1, 2) has trace...

  • 5
  • 2
  • 1
  • 0
P = (1/5)[[1,2],[2,4]], trace (1+4)/5 = 1. A projection onto a k-dimensional subspace always has trace k.

In least squares, the residual vector y - A w is...

  • parallel to y
  • equal to zero
  • perpendicular to every column of A
  • perpendicular to w
That is exactly the normal equation A^T (y - A w) = 0.

Select all TRUE statements about a projection matrix P. (select all that apply)

  • P squared equals P
  • P is symmetric
  • P is an orthogonal matrix
  • P always has rank 1
Projections are idempotent and symmetric. They are not orthogonal matrices, and the rank equals the dimension of the target subspace.

Recap

Remember this
  • AxA\mathbf xAx = a mixture of the columns of AAA. Rank = number of independent columns.
  • Four subspaces: column (rrr, in Rm\mathbb R^mRm), row (rrr, in Rn\mathbb R^nRn), null (n−rn-rn−r), left null (m−rm-rm−r). Row ⊥\perp⊥ null; column ⊥\perp⊥ left null.
  • Closest point = perpendicular drop. Projection onto a line: aaTaTa\frac{\mathbf a\mathbf a^T}{\mathbf a^T\mathbf a}aTaaaT​; onto a column space: A(ATA)−1ATA(A^TA)^{-1}A^TA(ATA)−1AT. Always P2=P=PTP^2=P=P^TP2=P=PT.
  • Least squares: solve ATAw=ATyA^TA\mathbf w=A^T\mathbf yATAw=ATy. The fitted values are the projection of y\mathbf yy; the residual is perpendicular to the columns.
